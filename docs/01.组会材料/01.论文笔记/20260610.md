# 2026-06-10组会内容

## HiPoser: 3D Human Pose Estimation with Hierarchical Shared Learning at Parts-Level Using Inertial Measurement Units

-   Paper Link: [https://haoxuanli-pku.github.io/papers/AAAI%2025%20-%20HiPoser%203D%20Human%20Pose%20Estimation%20with%20Hierarchical%20Shared%20Learning%20at%20Parts-Level%20Using%20Inertial%20Measurement%20Units.pdf](https://haoxuanli-pku.github.io/papers/AAAI%2025%20-%20HiPoser%203D%20Human%20Pose%20Estimation%20with%20Hierarchical%20Shared%20Learning%20at%20Parts-Level%20Using%20Inertial%20Measurement%20Units.pdf)

### 模型框架

首先看左下角的输入部分。模型输入是来自人体六个位置的 IMU 传感器数据，包括头部、双手、骨盆以及双脚，共六个 IMU。经过预处理后形成长度为 T的时序特征序列 X，作为整个网络的输入。输入序列首先进入层次化共享结构（Hierarchical Shared Structure）。这里作者没有采用 Transformer，而是使用 Mamba 作为核心时序编码器。整个网络由四个连续的子任务组成，每个子任务对应一个人体运动层级。

第一个子任务是躯干姿态估计（Torso Pose）。输入序列首先经过 Mamba Block 提取时序特征，得到隐藏表示。随后通过姿态回归头 预测躯干姿态参数 。第二个子任务是下肢姿态估计（Lower Limbs Pose）。这里不仅使用当前阶段提取的特征 ，同时还接收上一阶段预测得到的躯干姿态信息。作者将躯干信息作为先验共享给下肢预测任务，从而显式建模躯干与腿部之间的运动关联，最终输出下肢姿态 。第三个子任务是上肢姿态估计（Upper Limbs Pose）。与前一个阶段类似，上肢预测不仅利用当前特征 ，还接收前面两个阶段产生的躯干和下肢信息。因此网络能够利用已经估计出的身体状态作为条件，进一步预测双臂姿态。第四个子任务是全局位移估计（Global Translation）。该阶段在已有全身姿态信息基础上，利用隐藏特征预测人体的全局平移参数。

从图中的虚线连接可以看到，前一个任务的输出会不断传递给后续任务。因此整个结构并不是四个独立网络，而是一个逐级共享信息的层次化预测框架。作者认为人体运动本身具有层次依赖关系，因此采用“躯干→下肢→上肢→全局位移”的预测顺序更符合人体运动学规律。最后，在网络顶部，将四个阶段得到的预测结果进行拼接（Concatenate），组合成完整输出。整个网络的核心特点是将全身姿态估计拆解为多个具有运动学依赖关系的子任务，并通过层次化共享机制逐步完成全身人体运动重建。

## ASE: Large-Scale Reusable Adversarial Skill Embeddings for Physically Simulated Characters

-   Paper Link: [https://arxiv.org/abs/2205.01906](https://arxiv.org/abs/2205.01906)
-   Github Link: [https://github.com/nv-tlabs/ASE](https://github.com/nv-tlabs/ASE)
-   Project Link: [https://research.nvidia.com/labs/toronto-ai/ASE/](https://research.nvidia.com/labs/toronto-ai/ASE/)

### 模型框架图

在预训练阶段，首先从大规模动作数据集采样参考动作片段，系统通过 Encoder 将每段动作映射到一个低维潜在技能空间中的技能向量 z。这里的 z 可以理解为一种动作技能的抽象表示，它不再对应具体关节轨迹，而是表示动作背后的运动模式。随后，随机采样得到的技能向量 z 与当前角色状态 sₜ 一起输入到底层策略网络 Low-Level Policy，策略输出动作 aₜ 驱动仿真角色运动，从而产生新的状态轨迹。为了让生成动作保持真实自然的人体运动特征，ASE引入了对抗模仿学习机制。图中的 Discriminator 判别器同时接收数据集中的参考动作和策略生成的动作轨迹，并判断其是否来自真实数据。判别器输出的结果构成模仿奖励 rₜ，用于指导策略学习逼近真实动作分布。同时，Encoder 还承担技能一致性约束的作用，它会根据当前生成的状态轨迹重新预测对应的技能向量，并要求预测结果与最初输入的 z 保持一致。这样能够避免策略忽略技能变量，确保不同的 z 真正控制不同类型的运动行为。经过这一阶段训练后，模型获得了一个统一的技能空间以及一个能够执行大量运动技能的底层控制器。

下半部分展示的是任务训练阶段。在这一阶段中，预训练得到的 Low-Level Policy 被固定下来，不再继续学习。对于具体任务，例如导航、追踪目标或者与环境交互，系统新增一个 High-Level Policy。高层策略根据当前状态 sₜ 和任务目标 g 输出技能指令 zₜ，而不是直接输出关节控制信号。随后，底层策略接收状态和技能向量，自动生成对应的控制动作 aₜ 并作用于环境。也就是说，高层策略负责决定当前应该使用什么技能，而底层策略负责将技能转化为具体的人体运动。

从整体上看，ASE最大的创新在于将复杂的运动控制问题分解为“技能学习”和“技能调用”两个层次。预训练阶段利用海量动作数据构建连续的技能潜空间，并学习统一的技能执行器；任务训练阶段只需要在技能空间中进行决策，而无需重新学习底层运动控制。因此，高层策略能够直接复用已经掌握的大量运动能力，实现技能切换、技能组合以及技能插值，大幅提升复杂任务的学习效率和泛化能力。这也是 ASE 相比传统单技能策略方法最核心的贡献。

## Natural Humanoid Robot Locomotion with Generative Motion Prior

-   Paper Link: [https://arxiv.org/abs/2503.09015](https://arxiv.org/abs/2503.09015)
-   Porject Link: [https://sites.google.com/view/humanoid-gmp](https://sites.google.com/view/humanoid-gmp)

### 模型框架图

首先看图(a)，作者先进行 **Whole-body Motion Retargeting**。由于人类和机器人具有不同的骨骼结构、关节自由度以及运动约束，原始人体动作数据无法直接用于机器人控制。因此作者首先将大规模人体运动数据库中的动作序列通过运动重定向映射到机器人运动空间，从而得到与机器人结构一致的参考运动数据集。经过这一过程之后，原来的人体步态、转向、奔跑等动作被转换成机器人能够执行的关节轨迹，为后续运动先验学习提供训练数据。

接下来是图(b)，这是整篇论文最核心的部分——**Generative Motion Prior（GMP）**。作者采用一种类似条件变分自编码器（CVAE）的结构学习机器人运动分布。在训练阶段，上半部分使用真实机器人动作序列作为输入，Motion Encoder将当前姿态 mt 和下一时刻姿态 mt+1编码到潜变量空间 zt+1，随后Motion Decoder根据该潜变量重建未来姿态，从而学习运动数据中的时序演化规律。在训练完成后，推理阶段不再使用Motion Encoder，而是使用下方的Command Encoder。此时系统输入当前机器人姿态 mt 和用户控制指令 ct（例如前进速度、转向角速度等），Command Encoder直接生成潜变量 zt+1，再通过已经训练好的Motion Decoder预测未来动作。这样模型实际上学习到了“在给定运动指令条件下，人类风格运动应该如何自然演化”的运动分布。

然后看图(c)，作者利用训练好的 GMP 来指导强化学习控制。当前时刻机器人状态 mt和控制命令 ct 被输入到 Generative Motion Prior 中，模型不仅预测下一帧动作 mt+1，而且能够递归生成未来多个时刻的参考动作序列，即 Robot Future Reference Motion。这一点与 AMP 等方法存在本质区别。AMP 使用判别器判断动作是否像人类，而 GMP 直接生成未来应该执行的完整运动轨迹。因此强化学习策略不再学习“什么是自然动作”，而是学习如何跟踪 GMP 给出的参考运动。RL Policy 根据环境状态输出控制动作，机器人在仿真环境中执行，同时利用参考运动计算跟踪奖励，从而不断优化控制策略。

整个框架的核心思想可以概括为：作者先通过运动重定向获得机器人版本的人类动作数据，然后利用生成模型学习人类运动分布，构建能够根据控制指令在线生成未来参考轨迹的 Generative Motion Prior，最后使用这些参考轨迹引导强化学习训练机器人控制器。相比传统 AMP 只提供风格奖励的方式，GMP 直接生成未来运动目标，使强化学习获得更加密集、稳定且可解释的监督信号，从而实现更加自然的人形机器人步态控制。
