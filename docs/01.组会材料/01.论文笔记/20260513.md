## MLM: Learning Multi-task Loco-Manipulation  Whole-Body Control for Quadruped Robot with Arm

- Paper Link: [https://arxiv.org/pdf/2508.10538](https://arxiv.org/pdf/2508.10538)

### 论文介绍

这篇论文核心上是在四足机器人和机械臂，如何通过一个统一策略，同时完成移动和操作（manipulation），并且还能支持多任务切换。

### 模型框架

首先，作者通过遥操作采集机械臂末端 TCP 轨迹和图像数据，并训练扩散模型生成未来的操作轨迹，这些轨迹随后被构建成轨迹库，训练过程中，系统通过课程采样动态调整不同任务轨迹的采样概率，从简单任务到复杂任务来缓解多任务学习的任务干扰问题。

论文最核心的模块是 TVP，由于真实机器人属于部分可观测系统，仅依赖当前 observation 容易导致控制滞后和不稳定，因此作者利用历史 observation、历史 action 和 task trajectory 预测未来运动趋势，包括 future velocity 和 future trajectory latent，使策略具备 predictive control 能力。随后，整个系统采用 unified whole-body policy，同时输出机械臂和四足腿部动作。

论文采用非对称actor-critic 结构，actor 使用真实部署可获得的 proprioception 和 trajectory condition，critic 则额外利用 privileged state 和 terrain information 来提升稳定性。

## Humanoid Manipulation Interface: Humanoid Whole-Body Manipulation from Robot-Free Demonstrations

- Project Link: [https://humanoid-manipulation-interface.github.io/#/](https://humanoid-manipulation-interface.github.io/#/)
- Github Link: [https://github.com/Richard-coder-Nai/HuMI](https://github.com/Richard-coder-Nai/HuMI)
- Paper Link: [https://arxiv.org/pdf/2602.06643](https://arxiv.org/pdf/2602.06643)
- Data Link: [https://huggingface.co/collections/Richard-Nai/humi](https://huggingface.co/collections/Richard-Nai/humi)

### 论文介绍

HuMI 由两个组件组成:一个机器人自由演示系统和一个分层策略学习框架，首先,作者以全身轨迹和图像观察的形式收集人类演示数据。这些数据用于训练高层操作策略,其中扩散策略将图像观察映射为以目标关键点轨迹表示的动作。相同的数据也用于训练低层控制器,该控制器输出机器人关节角度以跟踪高层策略生成的目标轨迹。通过将高层策略与低层控制器集成,所得系统利用机载传感器观察实现人形全身操作。

### 模型框架

这篇论文提出了一个名为 HuMI 的人形机器人全身操作框架，核心目标是在不使用真实机器人的情况下，仅通过人类自然动作演示，让人形机器人学习复杂的全身协同操作能力。论文首先分析了两个关键难点：第一，人类动作无法直接映射到机器人，例如人类下蹲时的姿态在人形机器人上可能会出现关节折叠异常等不可执行问题；第二，人类与机器人在身体结构、关节长度和运动范围上存在明显差异，仅靠简单缩放会导致动作空间错位，因此需要专门的动作适配方法。

在数据采集部分，作者设计了一套轻量化的人体动作采集系统。操作者佩戴 HTC VIVE 动作追踪器获取全身姿态信息，同时双手持有手柄设备记录抓取和操作动作。系统能够同步采集人体的手臂、躯干和腿部运动，并通过人在回路中的运动学适配实时调整动作，使采集到的数据更加符合人形机器人的运动约束。相比传统依赖真实机器人遥操作的方法，这种方案成本更低、效率更高，而且能够更容易采集大幅度的全身动作。

在数据处理阶段，论文将训练数据分为高层数据和低层数据两部分。高层数据主要包括腕部摄像头图像以及人体关键点轨迹，用于学习任务相关的操作意图；低层训练数据则是通过逆运动学计算后得到的人形机器人全身运动数据，包括机器人各关节的位置、速度以及对应的全身姿态轨迹，将这些轨迹转换为机器人可执行的全身运动数据。这种分层处理方式既保留了视觉信息中的任务语义，又保证了机器人动作的稳定性与可实现性。

整个控制框架采用分层控制结构。高层使用扩散策略网络，根据腕部相机图像和机器人状态预测未来一段时间的目标动作轨迹；低层则使用全身控制器，以更高频率实时跟踪这些目标轨迹，并结合机器人当前的惯性信息、关节位置和速度，输出最终的关节控制指令。相比传统只关注机械臂末端控制的方法，该框架能够实现手臂、躯干和双腿之间的全身协同，从而完成下蹲抓取、动态操作以及移动中的复杂操作任务。

## DAGDiff: Guiding Dual-Arm Grasp Diffusion to Stable and  Collision-Free Grasps

- Project Link: [https://dag-diff.github.io/dagdiff/](https://dag-diff.github.io/dagdiff/)
- Paper Link: [https://dag-diff.github.io/dagdiff/static/images/dagdiff_paper_final.pdf](https://dag-diff.github.io/dagdiff/static/images/dagdiff_paper_final.pdf)
- Github Link: [https://github.com/DAG-Diff/dual-arm-grasp-diffusion](https://github.com/DAG-Diff/dual-arm-grasp-diffusion)

### 论文介绍

《DAGDiff》主要解决的是双臂机器人抓取中稳定抓取和双臂无碰撞协同难以同时满足的问题。传统单臂抓取方法通常只优化单个夹爪与物体之间的接触质量，而双臂场景中还需要考虑两个机械臂之间、机械臂与物体之间以及环境之间的复杂几何约束。已有方法很多依赖采样+优化或者启发式搜索，不仅推理速度慢，而且容易陷入局部最优。论文因此提出一种基于扩散模型（Diffusion Model）的双臂抓取生成框架，希望直接生成可执行、稳定且无碰撞的双臂抓取姿态。

### 模型框架

这篇论文的方法整体可以分为几何特征编码和扩散生成引导两部分。首先，系统输入的是物体点云以及一组双臂抓取位姿。这里的双臂抓取位姿表示左右机械臂夹爪在空间中的位置与姿态。论文首先使用一种具有旋转等变性的点云网络对物体进行编码，提取物体几何特征。随后，将点云特征投影到多个二维平面中，形成多平面特征图，再通过一个类似编码器—解码器结构的网络进行特征融合，最终得到稠密的空间几何特征场。

接下来，论文并不是直接预测机械臂关节动作，而是先随机初始化一组双臂抓取姿态，再将固定的夹爪模板点云通过当前抓取位姿变换到物体周围空间中，形成查询点。这样模型实际上是在观察当前抓取姿态与物体局部几何之间的关系。之后，从前面得到的多平面特征图中对这些查询点进行特征采样，并结合当前扩散时间步，一起输入主网络进行处理。

主网络主要输出两类信息。第一类是查询点对应的符号距离场，用来描述当前抓取点与物体表面的空间关系，例如是否接触、距离远近以及是否进入物体内部。第二类是隐含特征向量，这部分特征会进一步送入三个预测分支。第一个分支用于预测当前抓取的能量值，它决定扩散过程中的主要生成方向；第二个分支用于预测当前双臂抓取是否满足力闭合条件，也就是是否能够形成稳定抓取；第三个分支用于预测当前抓取是否存在碰撞，包括机械臂之间以及机械臂与物体之间的碰撞情况。

在推理阶段，系统从随机抓取开始，通过扩散模型不断去噪优化抓取姿态。开始时，夹爪位置是杂乱分布在物体周围的；随着迭代进行，模型逐渐将夹爪移动到更加合理的位置。这里能量分支负责整体生成趋势，而稳定抓取分支和碰撞分支则作为约束信号，对生成方向进行修正。如果当前抓取不稳定，模型会朝更稳定的方向调整；如果存在碰撞，则会主动远离碰撞区域。最终在迭代结束时，系统能够生成既稳定、又无碰撞的双臂抓取结果。整个方法的核心，本质上是在扩散生成过程中显式加入物理稳定性与几何约束，使生成结果能够直接用于机器人执行。
