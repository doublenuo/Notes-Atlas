## AdaptManip: Learning Adaptive Whole-Body Object Lifting and Delivery with Online Recurrent State Estimation

- Project Link：[https://morganbyrd03.github.io/adaptmanip/](https://morganbyrd03.github.io/adaptmanip/)
- Paper Link: [https://morganbyrd03.github.io/adaptmanip/AdaptManip-Arxiv.pdf](https://morganbyrd03.github.io/adaptmanip/AdaptManip-Arxiv.pdf)

### 论文介绍

![AdaptManip论文介绍](https://raw.githubusercontent.com/doublenuo/ubuntu-image/main/image/20260520160018723.png)

### 模型框架

这篇论文提出了一个分阶段训练的自适应全身搬运框架，核心目标是在未知负载条件下实现稳定的举起、搬运与递送。整个方法首先训练一个基础全身控制策略 π_wbc。在这一阶段，机器人并不进行搬运任务，而是在大量随机速度指令下学习稳定行走与全身平衡控制。策略输入主要是机器人本体感觉信息，例如关节状态、IMU以及足端接触信息，输出则是全身关节动作。通过强化学习训练后，机器人获得了稳定的 locomotion 和 whole-body coordination 能力，相当于先学习“如何稳定运动”。

在此基础上，论文进一步训练一个 manipulation residual policy，也就是残差操作策略 π_res。这里作者并没有重新训练整个控制器，而是在基础策略输出动作 a_t 的基础上，再额外学习一个补偿动作 Δa_t，最终控制量为 a_t + Δa_t。训练过程中，机器人开始执行真实搬运任务，并随机化物体质量、重心以及惯性等参数。残差策略主要学习如何针对负载变化进行动态补偿，例如调整身体前倾、改变步态宽度以及稳定上半身姿态。这样做的好处是，基础 locomotion 能力不会被破坏，而 manipulation policy 只需要关注负载适应问题，从而提高训练稳定性与泛化能力。

此外，论文还设计了一个基于 LSTM 的在线循环状态估计器，用于实时估计未知物体的动力学状态。估计器输入包括视觉观测以及机器人本体感觉信息，例如身体振动、关节力矩和运动响应等，再通过 LSTM 建模历史时序信息，最终输出估计的物体状态，例如质量、重心和惯性。这个估计结果会实时输入残差策略 π_res，使机器人能够在搬运过程中动态调整动作。因此整个系统形成了“在线估计 + 自适应补偿”的闭环控制框架，实现了未知负载条件下的自适应全身搬运。

## BAT: Balancing Agility and Stability via Online Policy Switching for Long-Horizon Whole-Body Humanoid Control

- Paper Link：[https://arxiv.org/pdf/2604.01064](https://arxiv.org/pdf/2604.01064)

### 模型框架

这篇论文的核心思想是，通过“在线策略切换”实现人形机器人运动中敏捷性与稳定性的动态平衡。作者没有训练一个统一的全身控制器，而是分别训练了两种不同风格的低层控制策略：一种是偏向动态能力的敏捷控制器，另一种是偏向鲁棒性的稳定控制器。系统在运动过程中会根据当前状态在线决定使用哪一个控制器，从而在不同运动阶段动态切换控制模式。例如，在跳跃、快速运动等高动态场景下，系统会倾向选择敏捷控制器；而在恢复平衡、稳定行走等场景下，则会切换到稳定控制器。论文的核心目标就是通过这种多策略协同方式，实现长时域全身运动中的稳定性与动态性的统一。

首先是 **(1) Option-Aware VQ-VAE（可感知选项的向量量化自编码器）**，它负责从原始运动数据集 $\mathcal{M}$ 中学习离散的潜空间表示。通过编码器将运动数据映射到 Codebooks（码本），并在传统解码重建运动 $\hat{\mathcal{M}}$ 的基础上，引入了“下一Token预测”与“选项预测（Option Prediction）”的分支，利用监督学习在数据集 $\mathcal{D}_{Op}$ 的引导下，让模型能够感知并预测当前的底层运动行为属性。

第二部分是 **(2) Offline Data Construction（离线数据构建）**，这里我们将针对不同任务训练好的敏捷策略 $\pi_D$（如动态跳跃）和稳定策略 $\pi_C$（如稳健行走）的重定向运动数据集进行滑动视窗下的策略预评估，并通过惯性化（Inertialization）技术进行运动融合，从而构建出包含策略切换边界信息的离线数据集 $\mathcal{D}_{Op}$，为前述的量化编码器提供数据支撑。

在右侧的层次化强化学习框架中，高层策略负责决定当前使用哪一种控制器，低层策略负责真正执行全身运动控制。高层根据机器人状态信息输出一个离散决策，即当前选择敏捷控制器还是稳定控制器，从而将复杂的全身控制问题转化为了“策略调度问题”。随后低层控制器再完成关节控制、全身协调以及动作执行等任务。此外，论文还利用前面离线生成的专家切换数据对高层策略进行行为克隆训练，使系统先学习模仿专家切换行为，再通过强化学习进一步优化，从而提升训练稳定性和收敛效率。

**第三部分是** **(3) Option-Guided Hierarchical RL（选项引导的分层强化学习）**，这是在线控制的核心。高层的 Switching Policy（切换策略）接收包含本体感受、历史状态、运动参考和策略 ID 在内的综合观测信息，动态输出离散动作，决定激活敏捷策略 $\pi_D$ 还是稳定策略 $\pi_C$。低层策略管理器据此驱动物理仿真中的人型机器人执行具体的全身控制。同时，来自高层的选项感知引导通过行为克隆（BC）机制为整个强化学习过程提供正则化约束。

最后，这两大核心能力在 **(4) Fusion Phase（融合阶段）** 汇合，通过决策融合模块（Decision Fusion Module）将 Option-Aware VQ-VAE 预测出的动作选项、离线构建的数据分布特性以及高层切换策略的实时输出进行有机融合，从而实现人型机器人在长周期、复杂控制任务中敏捷与稳定状态的平滑、高效在线切换。

## ResMimic: From General Motion Tracking to Humanoid Whole-Body Loco-Manipulation via Residual Learning

- Project Link: [https://resmimic.github.io/](https://resmimic.github.io/)
- Github Link: [https://github.com/amazon-far/ResMimic](https://github.com/amazon-far/ResMimic)
- Paper Link: [https://resmimic.github.io/file/ResMimic_paper.pdf](https://resmimic.github.io/file/ResMimic_paper.pdf)

### 模型框架

这篇论文的核心方法，其实就是利用“残差学习”的方式，把通用人体动作模仿能力扩展到真实的 humanoid 全身交互任务中。结合这张框架图来看，整个系统首先在 Stage 1 中训练一个通用动作跟踪策略，也就是图中的 πGMT\pi_{GMT}πGMT。作者先利用大规模人体动作数据，通过 retarget 映射到 humanoid 骨架，再通过强化学习训练一个 General Motion Tracking Policy，使机器人具备稳定的人形运动能力，例如行走、下蹲、转身、弯腰以及动态平衡等。这一步本质上是在学习“人体运动先验”，让机器人先学会“像人一样运动”。但是这种 tracking policy 存在明显问题，它只能复现人体动作，并不能真正理解任务目标，也不会处理真实物体交互，例如搬箱子时需要根据物体重量调整重心、根据接触状态调节施力方向等。因此作者在 Stage 2 中提出了最核心的 Residual Policy Training。这里冻结已经训练好的 πGMT\pi_{GMT}πGMT，再额外训练一个 residual policy，也就是 πRes\pi_{Res}πRes。最终动作不是由 residual policy 单独生成，而是在原始 tracking action 基础上增加一个 residual correction：at=atgmt+Δatresa_t = a_t^{gmt} + \Delta a_t^{res}at=atgmt+Δatres 其中 atgmta_t^{gmt}atgmt 表示基础动作策略输出，Δatres\Delta a_t^{res}Δatres 表示残差修正。这个设计的意义非常重要，因为 humanoid locomotion 本身已经极其困难，如果直接让强化学习从零学习 whole-body manipulation，训练会非常不稳定。而在 ResMimic 中，基础策略已经提供了自然、稳定的人体运动能力，因此 residual policy 不需要重新学习走路和平衡，它只需要学习“如何为了完成任务而偏离参考动作”。例如在搬运物体时，机器人需要额外调整 torso 姿态、改变脚步位置、增加手臂施力、补偿重心偏移等，这些都由 residual policy 完成。因此整个学习空间会被大幅压缩，训练效率和稳定性都会明显提高。从图右侧可以看到，论文还专门设计了 interaction-aware reward，包括 Object Tracking Reward 与 Contact Reward。其中 Object Tracking Reward 用来约束真实物体轨迹与参考物体轨迹之间的误差，使机器人不仅动作像人，而且物体运动也符合目标轨迹；而 Contact Reward 则约束人与物体之间的接触模式，因为 manipulation 的核心并不仅仅是姿态，而是接触行为，例如什么时候接触、接触位置在哪里、接触持续多久以及施力方向如何变化。此外论文还在训练早期引入了 Virtual Force 来辅助机器人学习稳定交互，从而降低探索难度。最终在 Stage 3 中，训练好的 πResMimic\pi_{ResMimic}πResMimic 可以直接部署到真实 humanoid 上，只依赖 proprioception 与 object state 就能完成 whole-body loco-manipulation。整体来看，这篇论文最大的贡献，就是提出了一种“通用人体动作先验 + 残差任务修正”的统一框架，使 humanoid 同时具备自然的人类运动风格与真实环境中的任务执行能力，从而实现 locomotion 与 manipulation 的统一全身协同控制。
