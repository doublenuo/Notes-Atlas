# 2026-06-03组会内容

## HumanoidMimicGen: Data Generation for Loco-Manipulation via Whole-Body Planning

- Project Link: [https://humanoidmimicgen.github.io/](https://humanoidmimicgen.github.io/)
- Paper Link: [https://arxiv.org/pdf/2605.27724](https://arxiv.org/pdf/2605.27724)

### 论文介绍

![HumanoidMimicGen论文介绍图](https://raw.githubusercontent.com/doublenuo/ubuntu-image/main/image/20260602134052588.png)

### 模型框架

这篇工作主要关注人形机器人移动操作任务中的数据生成问题。与传统 MimicGen 面向固定机械臂不同，这篇工作首次将 MimicGen 的数据生成思想扩展到人形机器人全身操作场景，使机器人能够同时处理行走、平衡以及双臂操作等复杂任务

首先看框架图左侧部分。作者从少量人类示教数据出发，对示教轨迹进行技能级别的拆分和标注，也就是图中的 Human Skill Annotations and Constraints。这里不仅包含具体的操作动作，例如接近物体、双手抓取、抬升、搬运以及放置等技能，还会构建技能之间的约束关系。图中上方的有向图实际上表示技能执行顺序约束，例如必须先完成抓取动作才能执行抬升动作；同时还包含协调约束，例如双手抓取箱子时左右手需要同步执行，不能单独完成。这种基于技能图的表示方式能够将复杂长时序任务分解为多个可复用的技能模块，为后续的数据生成提供结构化先验。

完成技能标注之后，系统进入图中间上方的 Infer Target Pose(s) from Constraints 模块。这里的核心思想来源于 MimicGen 的对象中心表示方法。作者并不直接记录机器人末端执行器在世界坐标系中的绝对位置，而是记录双手相对于目标物体坐标系的相对位姿关系。当场景发生变化时，例如箱子的位置、朝向或者桌面布局发生变化，系统能够根据约束关系自动推断新的目标抓取位姿。图中显示的左右手坐标轴实际上就是重新计算得到的目标末端位姿。通过这种方式，一条原始示教可以适配到大量新的环境配置中，从而实现数据扩增。

在得到新的目标抓取位姿之后，进入图中最核心的 Whole-Body Planning 模块。对于机械臂系统而言，只需要求解手臂运动即可，但对于人形机器人来说，仅仅知道双手应该到达哪里是不够的，机器人还需要决定身体应该站在什么位置、躯干如何调整以及双腿如何配合移动。因此作者引入了全身逆运动学求解。系统根据目标末端位姿计算满足约束条件的全身目标姿态，同时保证机器人处于稳定平衡状态，并满足关节限制以及碰撞约束。图中展示的多个机器人姿态实际上就是规划过程中求解得到的全身配置状态。

接下来，作者将全身规划进一步分解为移动规划和操作规划两个阶段。图右侧对应 Execute Locomotion Plan with Whole-Body Control 模块。在这一阶段，系统主要解决机器人如何从当前位置移动到合适的操作位置。作者利用预训练的行走策略生成腿部运动轨迹，实现稳定的步态控制。图中的橙色箭头表示机器人通过行走逐渐接近目标区域。在这一过程中，控制重点放在下肢运动和平衡保持上，从而降低高维全身规划的复杂度。

当机器人到达目标位置后，系统进入图下方右侧的 Execute Arm Plan(s) with Upper Body Control 模块。此时行走任务已经完成，控制重点转移到上半身操作。系统根据之前计算得到的目标位姿生成手臂运动轨迹，通过双臂协同完成接近、抓取和搬运等操作动作。由于机器人已经处于合适的站位，因此上肢规划可以更加专注于精细操作，而无需同时处理复杂的步态协调问题。

最后，系统执行图下方的 Execute Adapted Skill Segment(s) 模块。对于每一个经过适配后的技能片段，系统都会利用逆运动学和碰撞检测生成新的全身轨迹，并按照技能图中的执行顺序依次完成任务。例如完成抓取技能后自动切换到抬升技能，再切换到搬运技能，最终完成放置动作。整个过程中，机器人不断重复“目标位姿推断—全身规划—行走控制—操作执行”的流程，从而将少量人类示教自动扩展为大量高质量的人形机器人全身操作轨迹。

从框架上看，这篇工作的关键贡献并不在于设计新的控制策略，而是在于构建了一套完整的数据生成流水线。它通过技能级表示、对象中心技能适配以及全身运动规划，将原本只能用于机械臂的 MimicGen 思想扩展到人形机器人移动操作场景，为后续训练视觉运动策略、模仿学习策略以及 VLA 模型提供了大规模、高质量的全身操作数据。

## Sim-to-Real Reinforcement Learning for Vision-Based Dexterous Manipulation on Humanoids

- Project Link：[https://toruowo.github.io/recipe/](https://toruowo.github.io/recipe/)
- Paper Link：[http://arxiv.org/abs/2502.20396](http://arxiv.org/abs/2502.20396)

### 论文介绍

![论文介绍图](https://raw.githubusercontent.com/doublenuo/ubuntu-image/main/image/20260602134328952.png)

### 模型框架

首先是 A 模块 Real-to-Sim Modeling，也就是现实到仿真的建模过程。作者认为仿真与现实之间最大的差异来源于机器人动力学参数的不准确，因此提出了自动化参数校准方法。具体来说，首先在真实机器人上采集运动数据，然后在仿真环境中使用不同参数进行重放，通过比较真实轨迹与仿真轨迹之间的均方误差，不断优化机器人模型参数，包括关节刚度、关节阻尼、电机输出能力以及连杆质量等参数，最终找到误差最小的一组参数，从而获得与真实机器人更加一致的仿真环境。同时，对于操作物体，作者并没有追求高精度几何建模，而是采用球体、圆柱体、立方体等简单几何体进行近似表示，以降低建模成本并增强策略泛化能力。

接下来是 B 模块 Generalizable Reward Design，也就是通用奖励函数设计。作者发现，大多数操作任务本质上都可以被拆解为两个目标。第一个是 Contact Goal，即机器人是否与目标物体建立了正确接触；第二个是 Object Goal，即物体是否达到了期望状态。因此作者将操作任务奖励统一表示为 Contact Goal 和 Object Goal 两部分的组合。在图中可以看到，作者使用 Contact Markers 来定义物体上的关键接触区域，当机器人手部接触这些区域时获得接触奖励；而当物体被移动到目标位置、达到目标高度或者完成双手交接时，则获得目标奖励。这样无论是抓取、搬运、举箱子还是双手交接任务，都能够使用统一的奖励设计框架，避免针对每个任务重新设计复杂奖励函数。

然后是 C 模块 Sample Efficient Policy Learning，也就是高样本效率策略学习。由于人形机器人具有大量自由度，如果直接训练一个统一策略，强化学习的探索空间非常大，训练效率较低。因此作者采用了 Divide-and-Conquer Distillation 的思想。首先将复杂任务划分为多个子任务，例如接近物体、建立抓取、抬升物体等，并分别训练对应的专家策略，也就是图中的 Sub-task Specialists。随后通过轨迹筛选机制保留高质量专家轨迹，并利用蒸馏方法将多个专家策略融合为一个统一的 Generalist Policy。除此之外，作者还设计了 Task-Aware Hand Pose Initialization，根据任务类型初始化手部位置，使机器人在训练开始时双手已经位于合理区域附近，从而减少无效探索并提高训练效率。

最后是 D 模块 Vision-Based Sim-to-Real Transfer，也就是基于视觉的仿真到现实迁移。作者希望最终策略能够直接利用视觉输入完成操作，因此采用 RGB-D 相机作为主要感知来源。具体流程是先利用 Segment Anything 2 对目标物体进行分割，从 RGB 图像中提取目标区域，同时结合深度图生成对应的分割深度信息，从而获得物体的稠密视觉特征。除此之外，作者还提取了物体三维质心位置，也就是图中的三维中心坐标，作为一种稀疏状态表示。最终将稠密视觉特征和稀疏状态信息进行融合，形成 Hybrid Object Representation，并作为策略网络输入。通过这种方式，策略既能够利用视觉感知能力，又能够获得稳定的低维状态信息，从而提升视觉策略在真实环境中的迁移性能。

整个训练流程可以概括为：首先通过自动参数校准建立高保真仿真环境，然后利用接触目标与物体目标构建统一奖励函数，在此基础上采用分治式专家学习与策略蒸馏获得高效的通用策略，最后结合视觉感知与物体状态融合实现从仿真到真实机器人的迁移部署，最终完成双手抓取、搬运以及双手交接等复杂人形机器人操作任务。

## CLONE: Closed-Loop Whole-Body Humanoid Teleoperation for Long-Horizon Tasks

- Project Link： [https://humanoid-clone.github.io/](https://humanoid-clone.github.io/)
- Paper Link: [https://arxiv.org/abs/2506.08931](https://arxiv.org/abs/2506.08931)
- Github Link：[https://github.com/humanoid-clone/CLONE/](https://github.com/humanoid-clone/CLONE/)

### 论文介绍

![CLONE论文介绍图 ](https://raw.githubusercontent.com/doublenuo/ubuntu-image/main/image/20260602141434787.png)

### 模型框架

从框架图来看，CLONE的方法主要分为四个阶段。首先在数据准备阶段，作者利用大规模开源人体运动数据构建训练数据集。具体来说，先将人体动作重定向到机器人骨骼结构上，然后通过数据过滤去除超出机器人运动能力范围的动作。接着针对遥操作场景进行手腕轨迹采样，因为实际部署时VR系统只能稳定获取头部、左手和右手三个关键点位姿，因此作者提取这些关键控制信号，并通过动作编辑将不同动作片段进行组合，最终得到适用于全身遥操作训练的CLONED数据集。

在教师策略训练阶段，作者采用AMP框架训练一个高质量全身运动控制器。图中可以看到，教师策略的输入包括任务观测 、环境观测 、当前动作以及教师状态信息。策略输出下一时刻动作，驱动机器人在仿真环境中执行。与此同时，AMP中的判别器不断比较机器人生成的动作与数据集中真实人类动作之间的差异，并提供奖励信号。在这种对抗训练机制下，教师策略逐渐学习到与人类运动风格一致的全身协调控制能力。

获得教师策略之后，作者进一步进行学生策略蒸馏。这里的核心设计是MoE结构。学生策略不再依赖完整人体状态，而是仅使用头部和双手三个关键点作为任务输入，同时结合过去25帧的机器人状态和动作历史作为时序信息。首先由Router模块根据当前任务状态计算各个专家网络的激活权重，然后不同专家分别学习不同行为模式，例如行走、转身、下蹲和操作等。最后通过加权求和得到最终控制动作输出。由于不同运动模式对应不同动力学特性，MoE结构相比单一网络能够更好地处理复杂的全身协同动作。

为了进一步提高蒸馏后的策略鲁棒性，作者在训练过程中引入DAgger蒸馏机制。具体而言，学生策略在环境中自主执行产生状态分布，然后教师策略对这些状态重新生成动作标签，并不断加入训练数据进行迭代优化。这样可以有效缓解传统行为克隆中的分布偏移问题，避免测试阶段误差不断累积。

在真实机器人部署阶段，系统通过VR设备获取操作者头部和双手位姿，同时利用LiDAR里程计实时估计机器人在全局坐标系中的位置。学生策略输出的关节目标经过1000Hz的PD控制器执行到机器人本体上。与传统开放环遥操作不同，CLONE在这里构建了闭环全局位姿反馈机制。机器人通过LiDAR持续获得自身真实位姿，并与操作者目标位姿进行比较，计算全局位置误差。这个误差会反馈到控制系统中，对后续动作进行实时修正，从而形成“VR输入—策略生成—机器人执行—LiDAR定位—误差反馈”的闭环控制链路。这样即使在长距离移动过程中出现打滑、模型误差或环境扰动，机器人也能够持续修正自身位置，显著降低长期任务中的累积漂移，实现稳定的长时程全身遥操作。
