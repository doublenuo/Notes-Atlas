# 2026-06-24组会内容

## HANDOFF: Humanoid Agentic Task-Space Whole-Body Control via Distilled Complementary Teachers

-   Github Link：[https://github.com/lzyang2000/HANDOFF](https://github.com/lzyang2000/HANDOFF)
-   Paper Link: [https://arxiv.org/pdf/2606.06493](https://arxiv.org/pdf/2606.06493)
-   Project Link: [https://lzyang2000.github.io/HANDOFF/](https://lzyang2000.github.io/HANDOFF/)

### 模型框架

整个系统的目标是学习一个统一的人形机器人控制策略，使机器人能够同时具备全身操作、行走以及跌倒恢复能力。

首先看系统输入。HANDOFF并不直接接收关节轨迹或者全身动作序列，而是接收一个低维任务空间指令：
$$
c_t=[v_x,v_y,\omega_z,z,p_L^P,p_R^P]
$$

其中 $(v_x,v_y,\omega_z)$分别表示机器人前后移动速度、横向移动速度以及转向角速度；$z$ 表示机器人骨盆高度；$p_L^P$和 $p_R^P$ 分别表示左右手腕在骨盆坐标系下的目标位置。因此，上层 Agent 或 Planner 只需要告诉机器人应该往哪个方向移动，以及双手应该到达什么位置，而不需要规划具体的关节运动轨迹。除了任务指令之外，系统还接收机器人本体状态信息，包括关节位置、关节速度以及历史观测信息。

在训练阶段，作者首先构建了三个能力互补的 Teacher Policy。

-   第一个 Teacher 是 WBC Tracker，主要负责全身动作跟踪和操作任务，通过模仿人体动作数据学习复杂的全身协调运动。
-   第二个 Teacher 是 Locomotion Policy，主要负责机器人移动能力，通过速度跟踪任务学习稳定行走和转向。
-   第三个 Teacher 是 Recovery Policy，主要负责跌倒恢复，使机器人能够在受到扰动或跌倒后重新站立。

三个 Teacher 分别学习不同技能，然后通过知识蒸馏训练统一 Student Policy。对于 WBC Tracker 和 Locomotion Teacher，作者采用身体局部蒸馏策略，仅对对应身体部分进行 KL 散度约束。同时引入 Velocity-gated Blending 机制，根据机器人当前运动速度动态调整两个 Teacher 的权重。当机器人基本静止时，更依赖操作 Teacher；当机器人处于移动状态时，则更多依赖 Locomotion Teacher，从而实现操作与移动能力的平滑切换。Recovery Teacher 则采用全身蒸馏方式，将恢复能力迁移到 Student 中。

Student Policy 内部采用 Mixture of Experts 架构。机器人状态和任务指令首先经过共享编码器提取特征，然后输入 Softmax Gate 网络。Gate 根据当前状态自动计算各 Expert 的权重。Student 中包含三个 Expert：

-   Expert WBC，负责全身操作和动作跟踪；
-   Expert Locomanipulation，负责移动与操作协同；
-   Expert Recovery，负责恢复能力。

Gate 网络会根据当前场景动态决定各 Expert 的贡献比例。例如机器人在正常操作时主要激活 WBC Expert，在移动过程中增加 Locomanipulation Expert 权重，在跌倒状态下则更多激活 Recovery Expert。

最终所有 Expert 的输出经过加权融合，生成统一的动作输出：$a \in \mathbb{R}^{29}$即机器人 29 个自由度的关节控制信号，并直接发送给机器人执行。
