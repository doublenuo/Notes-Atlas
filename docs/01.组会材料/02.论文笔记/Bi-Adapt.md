# **Bi-Adapt**: Few-shot **Bi**manual **Adapt**ation for Novel Categories of 3D Objects via Semantic Correspondence

- Project Link: [https://biadapt-project.github.io/](https://biadapt-project.github.io/)
- Github Link: [https://github.com/isabella4444x/Biadapt](https://github.com/isabella4444x/Biadapt)
- Paper Link: [https://arxiv.org/pdf/2602.08425v2](https://arxiv.org/pdf/2602.08425v2)

## 模型框架图


这篇 **Bi-Adapt** 主要解决的是这样一个问题：双臂机器人在训练阶段只接触过一些特定类别的物体，当遇到训练中完全没有见过的新类别物体时，如果直接重新训练操作策略，就需要大量的数据。作者希望通过**已有的双臂操作知识 + 视觉语义对应 + 少量新物体交互数据**，让机器人快速学会操作新类别物体。结合这张框架图，整个方法可以理解成四个连续阶段。首先在左侧，作者利用已经具有操作数据的物体类别学习双臂操作先验。输入是物体的三维点云，通过 **PointNet++** 提取物体特征，同时从成功的双臂操作数据中得到两只机械臂与物体的接触位置。作者并不是直接学习完整的关节运动轨迹，而是把动作简化成“**在哪里接触，以及接触以后朝哪个方向运动**”，从而学习一种与具体物体类别相对解耦的双臂操作知识。

下面的两个机械臂动作学习模块分别负责两只手的动作预测。每个模块又包含两个部分：**动作生成**和**动作评价**。动作生成根据接触位置产生一些可能的操作姿态，动作评价则判断这些动作成功的可能性。由于双臂操作不是两个机械臂各做各的，而是存在明显的配合关系，所以作者让第二只手的动作参考第一只手的动作，也就是先确定第一只手怎么操作，再根据第一只手的动作决定第二只手如何配合。这样训练出来的并不是针对某一个具体物体的固定轨迹，而是一种更加通用的双臂操作规律，也就是知道“**在什么位置接触，以及两只手应该怎样配合**”。

接下来进入中间的**操作位置迁移**阶段，这是整篇论文比较关键的地方。当机器人遇到一个训练过程中从来没有见过的新类别物体时，之前物体上的接触位置显然不能直接复制过来。因此作者利用视觉基础模型建立新旧物体之间的对应关系。具体来说，首先找到训练物体上成功操作时的接触位置，然后提取训练物体和新物体的视觉特征，在两个物体之间寻找语义上相似的区域。也就是说，作者不是简单地按照几何位置把旧物体上的点移动到新物体上，而是在视觉特征空间中寻找“**功能上相似的位置**”。例如，原来物体上的某个位置是机器人操作时需要抓住或者推动的位置，那么在新类别物体上，就寻找视觉和功能上与它对应的位置，从而得到新物体上的候选接触位置。

得到新物体上的对应位置之后，还需要把视觉中的位置转换成真实三维空间中的位置，然后将这些新的三维接触位置输入前面已经训练好的双臂动作学习网络。这里得到的动作虽然已经具有一定合理性，但不一定能够直接成功，因为视觉模型只能帮助机器人找到“**看起来应该操作的位置**”，并不能完全保证这个位置在真实物理交互中一定可行。因此作者又加入了**少量数据适应**。机器人利用视觉模型找到的接触位置产生动作，然后在真实环境中执行，并根据执行结果得到成功或者失败的反馈。利用这些非常少的新类别交互数据，对原来的操作网络进行进一步调整，让模型逐渐适应这个新的物体类别。

最后进入执行阶段。经过少量数据调整以后，机器人就获得了针对这个新类别的操作能力。值得注意的是，作者最终测试的并不是刚才用于适应的那个物体，而是**同一新类别中的其他未见过的物体实例**。因此，只需要针对一个新类别收集少量交互数据，机器人就能够把学到的操作知识推广到这个类别中不同尺寸、外观和形状的其他物体上。整体来看，Bi-Adapt的核心思路就是：**先学习通用的双臂操作知识，再利用视觉基础模型把旧物体上的操作位置迁移到新物体上，最后通过少量真实交互数据进行修正，最终泛化到新类别中的其他物体。**它的重点不是为每一个新物体重新训练一个完整的双臂策略，而是把“**怎么操作**”和“**新物体上应该在哪里操作**”这两个问题分开解决，从而显著减少面对新类别时所需要的训练数据。
