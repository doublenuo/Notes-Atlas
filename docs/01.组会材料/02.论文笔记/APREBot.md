# APREBot: Active Perception System for Reflexive Evasion Robot

-   Project Link: [https://sites.google.com/view/aprebot/](https://sites.google.com/view/aprebot/)
-   Paper Link: [https://arxiv.org/abs/2509.24733](https://arxiv.org/abs/2509.24733)

## 论文介绍

这篇论文的目标是让机器人具备反射级的避险能力，即在高速、突发、不可预测危险出现时，机器人能够像生物一样先躲开，再思考，核心思想是机器人主动改变观察方式，只获取是否危险的最小信息，并直接触发反射动作。
