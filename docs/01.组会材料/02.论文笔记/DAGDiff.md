# DAGDiff: Guiding Dual-Arm Grasp Diffusion to Stable and  Collision-Free Grasps

- Project Link: [https://dag-diff.github.io/dagdiff/](https://dag-diff.github.io/dagdiff/)
- Paper Link: [https://dag-diff.github.io/dagdiff/static/images/dagdiff_paper_final.pdf](https://dag-diff.github.io/dagdiff/static/images/dagdiff_paper_final.pdf)
- Github Link: [https://github.com/DAG-Diff/dual-arm-grasp-diffusion](https://github.com/DAG-Diff/dual-arm-grasp-diffusion)
## 论文介绍

《DAGDiff》主要解决的是双臂机器人抓取中稳定抓取和双臂无碰撞协同难以同时满足的问题。传统单臂抓取方法通常只优化单个夹爪与物体之间的接触质量，而双臂场景中还需要考虑两个机械臂之间、机械臂与物体之间以及环境之间的复杂几何约束。已有方法很多依赖采样+优化或者启发式搜索，不仅推理速度慢，而且容易陷入局部最优。论文因此提出一种基于扩散模型（Diffusion Model）的双臂抓取生成框架，希望直接生成可执行、稳定且无碰撞的双臂抓取姿态。

## 模型框架

这篇论文的方法整体可以分为几何特征编码和扩散生成引导两部分。首先，系统输入的是物体点云以及一组双臂抓取位姿。这里的双臂抓取位姿表示左右机械臂夹爪在空间中的位置与姿态。论文首先使用一种具有旋转等变性的点云网络对物体进行编码，提取物体几何特征。随后，将点云特征投影到多个二维平面中，形成多平面特征图，再通过一个类似编码器—解码器结构的网络进行特征融合，最终得到稠密的空间几何特征场。

接下来，论文并不是直接预测机械臂关节动作，而是先随机初始化一组双臂抓取姿态，再将固定的夹爪模板点云通过当前抓取位姿变换到物体周围空间中，形成查询点。这样模型实际上是在观察当前抓取姿态与物体局部几何之间的关系。之后，从前面得到的多平面特征图中对这些查询点进行特征采样，并结合当前扩散时间步，一起输入主网络进行处理。

主网络主要输出两类信息。第一类是查询点对应的符号距离场，用来描述当前抓取点与物体表面的空间关系，例如是否接触、距离远近以及是否进入物体内部。第二类是隐含特征向量，这部分特征会进一步送入三个预测分支。第一个分支用于预测当前抓取的能量值，它决定扩散过程中的主要生成方向；第二个分支用于预测当前双臂抓取是否满足力闭合条件，也就是是否能够形成稳定抓取；第三个分支用于预测当前抓取是否存在碰撞，包括机械臂之间以及机械臂与物体之间的碰撞情况。

在推理阶段，系统从随机抓取开始，通过扩散模型不断去噪优化抓取姿态。开始时，夹爪位置是杂乱分布在物体周围的；随着迭代进行，模型逐渐将夹爪移动到更加合理的位置。这里能量分支负责整体生成趋势，而稳定抓取分支和碰撞分支则作为约束信号，对生成方向进行修正。如果当前抓取不稳定，模型会朝更稳定的方向调整；如果存在碰撞，则会主动远离碰撞区域。最终在迭代结束时，系统能够生成既稳定、又无碰撞的双臂抓取结果。整个方法的核心，本质上是在扩散生成过程中显式加入物理稳定性与几何约束，使生成结果能够直接用于机器人执行。
