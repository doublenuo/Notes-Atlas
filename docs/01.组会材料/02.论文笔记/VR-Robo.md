# VR-Robo: A Real-to-Sim-to-Real Framework for Visual Robot Navigation and Locomotion

-   Project Link: [https://vr-robo.github.io/](https://vr-robo.github.io/)
-   Github Link:[https://github.com/zst1406217/VR-Robo](https://github.com/zst1406217/VR-Robo)
-   Paper Link: [https://arxiv.org/abs/2502.01536](https://arxiv.org/abs/2502.01536)

## 论文介绍

这篇论文的核心思想是先用真实世界数据建立视觉真实感，再在仿真中进行大规模强化学习，最后无缝迁回真实机器人。
