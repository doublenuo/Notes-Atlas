# HumanoidMimicGen: Data Generation for Loco-Manipulation via Whole-Body Planning

## 模型框架

这篇工作主要关注人形机器人移动操作任务中的数据生成问题。与传统 MimicGen 面向固定机械臂不同，这篇工作首次将 MimicGen 的数据生成思想扩展到人形机器人全身操作场景，使机器人能够同时处理行走、平衡以及双臂操作等复杂任务

首先看框架图左侧部分。作者从少量人类示教数据出发，对示教轨迹进行技能级别的拆分和标注，也就是图中的 Human Skill Annotations and Constraints。这里不仅包含具体的操作动作，例如接近物体、双手抓取、抬升、搬运以及放置等技能，还会构建技能之间的约束关系。图中上方的有向图实际上表示技能执行顺序约束，例如必须先完成抓取动作才能执行抬升动作；同时还包含协调约束，例如双手抓取箱子时左右手需要同步执行，不能单独完成。这种基于技能图的表示方式能够将复杂长时序任务分解为多个可复用的技能模块，为后续的数据生成提供结构化先验。

完成技能标注之后，系统进入图中间上方的 Infer Target Pose(s) from Constraints 模块。这里的核心思想来源于 MimicGen 的对象中心表示方法。作者并不直接记录机器人末端执行器在世界坐标系中的绝对位置，而是记录双手相对于目标物体坐标系的相对位姿关系。当场景发生变化时，例如箱子的位置、朝向或者桌面布局发生变化，系统能够根据约束关系自动推断新的目标抓取位姿。图中显示的左右手坐标轴实际上就是重新计算得到的目标末端位姿。通过这种方式，一条原始示教可以适配到大量新的环境配置中，从而实现数据扩增。

在得到新的目标抓取位姿之后，进入图中最核心的 Whole-Body Planning 模块。对于机械臂系统而言，只需要求解手臂运动即可，但对于人形机器人来说，仅仅知道双手应该到达哪里是不够的，机器人还需要决定身体应该站在什么位置、躯干如何调整以及双腿如何配合移动。因此作者引入了全身逆运动学求解。系统根据目标末端位姿计算满足约束条件的全身目标姿态，同时保证机器人处于稳定平衡状态，并满足关节限制以及碰撞约束。图中展示的多个机器人姿态实际上就是规划过程中求解得到的全身配置状态。

接下来，作者将全身规划进一步分解为移动规划和操作规划两个阶段。图右侧对应 Execute Locomotion Plan with Whole-Body Control 模块。在这一阶段，系统主要解决机器人如何从当前位置移动到合适的操作位置。作者利用预训练的行走策略生成腿部运动轨迹，实现稳定的步态控制。图中的橙色箭头表示机器人通过行走逐渐接近目标区域。在这一过程中，控制重点放在下肢运动和平衡保持上，从而降低高维全身规划的复杂度。

当机器人到达目标位置后，系统进入图下方右侧的 Execute Arm Plan(s) with Upper Body Control 模块。此时行走任务已经完成，控制重点转移到上半身操作。系统根据之前计算得到的目标位姿生成手臂运动轨迹，通过双臂协同完成接近、抓取和搬运等操作动作。由于机器人已经处于合适的站位，因此上肢规划可以更加专注于精细操作，而无需同时处理复杂的步态协调问题。

最后，系统执行图下方的 Execute Adapted Skill Segment(s) 模块。对于每一个经过适配后的技能片段，系统都会利用逆运动学和碰撞检测生成新的全身轨迹，并按照技能图中的执行顺序依次完成任务。例如完成抓取技能后自动切换到抬升技能，再切换到搬运技能，最终完成放置动作。整个过程中，机器人不断重复“目标位姿推断—全身规划—行走控制—操作执行”的流程，从而将少量人类示教自动扩展为大量高质量的人形机器人全身操作轨迹。

从框架上看，这篇工作的关键贡献并不在于设计新的控制策略，而是在于构建了一套完整的数据生成流水线。它通过技能级表示、对象中心技能适配以及全身运动规划，将原本只能用于机械臂的 MimicGen 思想扩展到人形机器人移动操作场景，为后续训练视觉运动策略、模仿学习策略以及 VLA 模型提供了大规模、高质量的全身操作数据。
