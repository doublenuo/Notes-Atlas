# ADAPT: Analytical Disturbance-Aware Policy Training for Humanoid Locomotion

- Project Link: [https://blyu413.github.io/adapt-locomotion/](https://blyu413.github.io/adapt-locomotion/)
- Github Link: [https://github.com/blyu413/ADAPT](https://github.com/blyu413/ADAPT)
- Paper Link: [https://arxiv.org/pdf/2606.16542](https://arxiv.org/pdf/2606.16542)
## 模型框架图

这篇工作的核心是让人形机器人具备“感知并主动应对全身扰动”的能力。传统的强化学习行走方法在受到外力或者突然增加负载时，通常只能通过姿态、速度等自身状态的变化，间接判断机器人是不是受到了扰动，因此策略需要自己从这些状态变化中推断扰动来源和大小。ADAPT 的主要创新就在于，它没有单纯依靠强化学习策略自己去“猜”扰动，而是在强化学习控制器前面增加了一个基于机器人动力学的扰动观测器。

具体来说，机器人首先通过自身的传感器获取关节位置、速度以及身体运动状态，同时结合机器人的动力学模型和电机输出情况，实时计算机器人正常情况下应该产生的运动变化。然后将理论运动和实际运动进行比较，把两者无法解释的差异看作机器人当前受到的外界扰动。这样就能够在不额外安装力传感器的情况下，实时估计机器人全身受到的扰动力，并且不仅能够反映身体受到的外力，也能够反映由于负载变化产生的关节额外受力。

这里最核心的创新，是把原本隐藏在机器人状态变化中的“扰动信息”显式提取出来，再作为额外的状态输入强化学习策略。也就是说，传统方法需要策略自己根据“身体发生了什么变化”去推测“是不是有人推我、是不是突然增加了负载”，而 ADAPT 直接把估计得到的扰动信息提供给策略，让策略明确知道当前机器人正在受到什么样的干扰。因此策略可以针对不同扰动采取不同的补偿动作，而不是只能依靠大量随机扰动训练来获得这种能力。

在此基础上，作者又设计了针对扰动的奖励机制，让机器人不仅追求能够抵抗外力、保持不倒，还能够学习更加平稳、柔和的运动方式。最终论文主要从三个方面验证了这种方法：第一，在受到不同方向外力冲击时，机器人能够主动调整身体和步态进行抵抗；第二，在左右两侧负载不对称的情况下，机器人能够根据当前扰动主动恢复身体姿态；第三，通过加入针对扰动的奖励，使机器人在行走过程中减少不必要的剧烈动作，从而获得更加柔和、稳定的运动效果。
