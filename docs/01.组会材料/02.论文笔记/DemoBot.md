# DemoBot: Efficient Learning of Bimanual Manipulation with Dexterous Hands From Third-Person Human Videos

-   Project Link: [https://demobot-seed.github.io/](https://demobot-seed.github.io/)
-   Paper Link: [https://arxiv.org/abs/2601.01651v1](https://arxiv.org/abs/2601.01651v1)

## 模型框架图

这张图展示的是 DemoBot 的整体框架，其核心思想是让机器人仅通过观看一段第三人称人类演示视频，就能够学习复杂的双臂灵巧操作任务。整个框架主要由数据处理模块和修正残差强化学习模块两部分组成。首先在数据处理阶段，系统输入的是一段深度视觉人类演示视频。由于完整视频包含大量冗余信息，因此作者首先从视频中筛选出能够反映任务关键状态变化的关键帧，例如抓取、抬升以及插入等重要操作阶段。随后利用手部与物体位姿估计方法，从这些关键帧中恢复双手和操作物体的三维运动轨迹。其中，作者采用了基于目标分割感知的物体位姿估计技术，从而能够更加准确地获取物体在操作过程中的位置和姿态变化。通过这一过程，系统获得了完整的人类双手轨迹以及物体轨迹，为后续机器人学习提供基础。

获得人类演示轨迹之后，系统需要解决人手与机器人手之间存在的结构差异问题。由于机器人灵巧手的关节结构、自由度分布以及运动范围与人手并不一致，因此无法直接执行恢复出来的人类动作轨迹。为此，作者引入了动作映射技术，将人类双手动作映射到机器人双臂灵巧手的运动空间中，生成机器人可执行的全身运动轨迹。同时，作者将整个长时序操作任务划分为多个阶段，例如图中所示的接近与抓取、姿态调整、插入前对准以及最终插入等阶段。这样做的目的是将原本复杂的长时序任务分解为若干更容易学习的子任务，为后续强化学习提供结构化的任务先验，从而降低学习难度并提高训练效率。

右侧展示的是论文最核心的创新模块——修正残差强化学习。虽然通过前面的步骤已经得到了机器人参考轨迹，但这些轨迹本质上来源于视觉估计，只反映了运动信息，而缺乏真实的接触力、摩擦力以及碰撞反馈等物理交互信息。因此，即使轨迹在几何层面是正确的，机器人在实际执行时仍然可能无法完成插入或装配等接触丰富的操作任务。针对这一问题，作者并没有采用传统强化学习从零开始探索，而是在演示轨迹的基础上学习一个修正量。图中的公式表明，机器人最终执行的动作由演示动作与强化学习产生的修正动作共同组成。换句话说，强化学习只需要学习如何对已有轨迹进行微调，而不需要重新学习整个操作过程。这种设计显著缩小了搜索空间，提高了学习效率和训练稳定性，同时能够更好地适应真实物理环境中的接触变化。

此外，为了进一步解决长时序双臂任务中的学习难题，作者还设计了三项关键机制。首先是基于时间阶段划分的残差强化学习，使每个阶段分别学习对应的修正策略，从而缓解长时序任务中的阶段错位问题。其次是成功门控重置策略，当机器人已经掌握前面阶段的技能后，训练可以直接从后续阶段开始，避免每次都从任务起点重新执行，从而提高样本利用效率。最后是事件驱动奖励课程学习，作者将接近目标、成功抓取、完成抬升、完成对准以及最终插入等关键事件设计为中间奖励，从而有效缓解装配任务中奖励稀疏的问题。通过上述设计，DemoBot实现了从单个第三人称人类视频到双臂灵巧机器人操作策略的高效迁移，为利用大规模人类演示视频学习复杂双臂操作任务提供了一种新的解决思路。
