# Omni-Perception: Omnidirectional Collision Avoidance for Legged Locomotion in Dynamic Environments

- Project Link: [https://acodedog.github.io/OmniPerceptionPages/](https://acodedog.github.io/OmniPerceptionPages/)
- Github Link:[https://github.com/aCodeDog/OmniPerception](https://github.com/aCodeDog/OmniPerception)
- Paper Link: [https://arxiv.org/abs/2505.19214](https://arxiv.org/abs/2505.19214)

## 论文介绍

腿式机器人在动态环境中高速运动时，由于感知视野有限，无法及时避免来自任意方向的碰撞问题，这篇论文就是为了解决这个问题的。
