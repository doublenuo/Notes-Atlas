## 研究问题

人形机器人在非结构化环境中需要将**全身控制与物体交互**结合起来：伸手够物、抓握支撑以稳定身体、推动可移动物体，都要求机器人在运动、姿态和接触之间根据场景做出协调。大规模人类运动数据能够提供自然的全身运动先验，但这类先验本身并不告诉机器人在哪里、如何与特定场景交互；把运动先验有效迁移到感知驱动的物体交互上，仍然是一个瓶颈。

iGPC 的核心思路是：**不从头学习交互技能，也不在部署时丢弃运动先验**。它把 GPC（Generative Pretrained Controller）从自由空间运动控制扩展到物体感知的全身交互，并在迁移到机载感知时保留预训练的运动骨干与解码器，只学习“如何从传感器估计 GPC 所需的输入”。

## 核心方法

iGPC 包含两个阶段。
1. **物体感知的交互专家**。 以 GPC 的运动基础为起点，保留其 FSQ（finite scalar quantization）运动 token 表示、自回归先验以及条件低秩适配机制。专家在 GPC 先验的基础上额外以场景可供性线索为条件，包括物体几何、接触状态和机器人稳定性描述符；先利用与支撑场景配对的人类交互运动进行交互与可供性预训练，再用强化学习优化任务特定行为。专家在训练时可以使用特权状态信息，但执行时不需要参考运动，交互行为由策略根据任务条件与场景线索生成。
2. **感知驱动的学生策略**。 学生保留专家的 GPC 运动先验与解码器，不替换为单独学习的动作策略，而是学习一个从机载感知到专家输入空间的“接口”。学生使用深度、LiDAR 和本体感知来估计 GPC 所需的交互上下文与身体状态，并通过蒸馏目标同时匹配专家的运动决策（motor tokens）和由此产生的关节目标；此外还学习校准传递给运动先验的估计信息，以减轻不完美传感器估计对 token 选择的影响，最后再用强化学习细化任务行为。
