# WEAVE：从人-物交互中学习全身灵巧移动操作

- Project Link: [https://xiaohu-art.github.io/Weave/](https://xiaohu-art.github.io/Weave/)

## 1. 要解决的问题

如何将人体与物体交互的动作捕捉数据，迁移为人形机器人可执行的完整技能：走近物体、建立接触、抓取并搬运。难点在于人体与机器人形态不同，且全身平衡、移动、手指接触和物体运动相互耦合。

## 2. 核心方法

WEAVE 分为两步：

1. **参考轨迹构造**
   - 用全身逆运动学将 SMPL-X 人体动作重定向到 Unitree G1；
   - 用接触感知的手部优化调整指尖位置；
   - 加入力闭合目标，避免“碰到但抓不住”；
   - 惩罚手指穿透物体；
   - 用 Kimodo 补全走向物体的 locomotion 前缀；
   - 为轨迹标注接触、非接触等状态。
2. **策略学习**
   - 输入机器人本体状态、物体位姿与几何特征、短时参考轨迹；
   - 输出身体和手指关节位置目标；
   - 使用 PPO 联合学习全身跟踪、物体跟踪和接触控制。

## 3. 奖励设计

- 机器人跟踪：骨盆、身体 link 的位置和方向；
- 物体跟踪：物体位置和方向，权重高于一般身体跟踪；
- 抓取约束：手指对向性、接触状态匹配；
- 正则项：足部滑动、动作变化率、关节限位。

核心思想是：机器人不必逐关节复刻人体，而应在保持交互意图和接触关系的前提下，找到自身可执行的动作。

## 4. 实验结果

实验平台为 Unitree G1 和 Inspire 灵巧手，覆盖 9 类物体，共约 23 小时数据。

| 设置 | 成功率 | 进度率 |
| --- | ---: | ---: |
| 训练序列 | 92.45% | 96.30% |
| 未见测试序列 | 64.98% | 84.52% |

多物体统一策略在测试集上的成功率为 **95.26%**，高于相同训练预算下的单物体专家策略 **91.48%**。单物体专家虽然多数跟踪误差更小，但任务成功率反而更低，说明“动作更像参考”不等于“交互更成功”。

## 5. 主要贡献

- 建立从人体交互数据到机器人全身灵巧操作的完整流程；
- 将接触、物体几何和力闭合显式加入重定向与策略学习；
- 统一处理 locomotion 和 manipulation；
- 证明多物体联合训练可以优于多个单物体策略；
- 发布带接触标注的机器人-物体交互数据。

## 6. 局限与思考

- 测试主要是训练过的物体类别上的新序列，对完全未知物体的泛化仍不明确；
- 方法依赖人体动作、物体几何和接触标注，数据构造成本较高；
- 力闭合和接触模型仍是近似，仿真结果与真实硬件之间可能存在差距；
- 策略依赖参考轨迹，尚不是完全自主的任务规划器。

**总结：** WEAVE 的关键不是让机器人“像人一样运动”，而是让机器人学习人与物体之间的接触关系和任务意图。对于全身机器人操作，物体状态、接触稳定性和任务成功率比单纯的姿态跟踪误差更重要。
