# 关于导航下拉菜单设计

## 目标

将站点的站点信息入口统一收纳到一个“关于”下拉菜单中，并移除当前位于顶层导航的 RSS 订阅入口。同时补齐“关于作者”页面，保证下拉菜单中的每个入口都有明确目标。

## 现状

- 顶层导航位于 `docs/.vitepress/config.ts`。
- 当前 RSS 订阅以顶层导航项 `/feed.xml` 展示。
- `/about`、`/privacy`、`/disclaimer` 页面已存在于 `docs/@pages/`。
- 尚无作者介绍页面。
- RSS 文件由 `docs/.vitepress/plugins/rss.ts` 在构建时生成，生成逻辑不需要改变。
- Teek 页脚已经有“关于”和“内容”分组，本次不调整页脚结构。

## 方案

采用 VitePress 原生导航下拉菜单，不新增自定义导航组件：

1. 删除 `themeConfig.nav` 中独立的 RSS 订阅项。
2. 在 `CV` 后、`快速访问` 前新增“关于”项。
3. “关于”子项按以下顺序排列：
   - 关于本站：`/about`
   - 关于作者：`/author`
   - 隐私政策：`/privacy`
   - 免责声明：`/disclaimer`
   - RSS订阅：`/feed.xml`
4. 新建 `docs/@pages/author.md`：
   - 标题为“关于作者”；
   - permalink 为 `/author`；
   - 提供简短的作者介绍，覆盖 AI、机器人、深度学习和 Linux 等学习方向；
   - 说明本站用于长期知识沉淀；
   - 保留现有 GitHub 和邮箱联系方式。

使用原生 `items` 配置可复用 VitePress 的桌面端下拉和移动端折叠行为，并保持主题的可访问性与既有样式。

## 验证

- 检查配置中顶层导航不再包含 RSS 订阅。
- 检查“关于”子菜单包含 5 个入口，顺序与需求一致。
- 构建站点，确认 `/author` 页面生成且 `feed.xml` 仍然生成。
- 运行现有测试，确认导航调整没有破坏既有行为。

## 范围边界

- 不修改 RSS 生成插件。
- 不移动或重写已有的关于本站、隐私政策和免责声明页面。
- 不调整 Teek 页脚已有分组。
- 不修改工作区中与本需求无关的未跟踪文件 `docs/01.组会材料/02.论文笔记/HOI-Retarget.md`。
