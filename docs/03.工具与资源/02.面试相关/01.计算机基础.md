# 计算机基础面试题

## 操作系统

1. 线程与进程的关系
2. 进程和线程的区别？用户态和内核态区别？多进程/多线程/多协程的区别？
3. 进程间通信（IPC）有哪些方式？
4. 死锁产生的原因、怎么避免和解决？死锁的四个必要条件是什么？
5. 为什么要有虚拟内存？
6. 内存泄漏和内存溢出有什么区别？
7. select / poll / epoll 的区别和原理？epoll 的 LT 和 ET 模式区别？

## 计算机网络

8. 输入网址到页面展示的全过程？如果是 HTTPS 呢？
9. TCP 和 UDP 区别？TCP 怎么保证可靠传输？
10. TCP 三次握手为什么不能少一次？TIME_WAIT / CLOSE_WAIT 是什么？
11. TCP 的流量控制和拥塞控制分别是什么？
12. HTTP 和 HTTPS 的区别？HTTPS 是如何保证安全的？
13. 半连接队列和全连接队列是什么？
14. 零拷贝的原理是什么？
