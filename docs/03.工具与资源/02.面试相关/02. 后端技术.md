# 后端技术面试题

## MySQL

1. 索引为什么用 B+ 树，而不用 B 树或二叉树？B+ 树的叶子节点和非叶子节点分别存什么？
2. 索引失效有哪些场景？联合索引 (A,B,C) 下 WHERE A ORDER BY C 走不走索引？
3. 事务隔离级别有哪些？可重复读解决了什么问题？幻读怎么解决？MVCC 的原理是什么？
4. MySQL 有哪些日志？binlog 和 redo log 的区别？二阶段提交谁先提交？
5. 慢 SQL 怎么排查优化？explain 主要看哪几个字段？
6. 左连接和右连接的区别？内连接中 ON 和 WHERE 的区别？

## Redis

7. Redis 为什么快？常见数据结构有哪些？zset 底层的跳表为什么快？
8. Redis 持久化方式有哪些？RDB 和 AOF 的区别？fork 子进程为什么能实现快照（写时复制 COW）？
9. 缓存击穿、缓存穿透、缓存雪崩分别是什么？怎么解决？
10. 缓存一致性怎么保证？先删缓存还是先更新数据库？删缓存失败怎么办？
11. Redis 分布式锁的原理？看门狗机制是什么？锁的 key 误删场景怎么处理？
12. 大 key / 热 key 有什么问题？怎么探测和设计热 key 方案？

## 消息队列

13. Kafka 怎么保证消息不丢失、不重复、有序？消息堆积怎么处理？
14. Kafka / RabbitMQ / RocketMQ 三大 MQ 的优缺点？死信队列怎么处理？
15. 为什么一个分区只能被同一消费者组内的一个消费者消费？

## 场景与设计题

16. 秒杀 / 超时订单关闭的架构怎么设计？幂等怎么保证？
17. 什么是限流？你实现过的 RPC 接口限流过程是怎样的？
