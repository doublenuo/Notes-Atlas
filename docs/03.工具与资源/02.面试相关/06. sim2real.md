# Sim2Real 面试常见问题

## Reality Gap 与迁移策略

1. Sim2Real 中的 reality gap 主要来源有哪些？如何系统性解决？
2. Domain Randomization（域随机化）是什么？为什么能缩小 reality gap？
3. Automatic Domain Randomization（ADR）是什么？比手动 DR 好在哪里？
4. Domain Adaptation 和 Domain Randomization 是什么关系？各自的应用场景？
5. 仿真到真机的 zero-shot transfer 和 fine-tuning transfer 有何区别？哪种更常用？
6. Digital Twin 在 sim2real 中的作用？与传统 DR 方法有什么区别？
7. 操作任务的 sim2real 和运动控制的 sim2real 有何核心区别？

## 训练与自适应方法

8. Teacher-Student 框架在 sim2real 中怎么用？privileged observation 是什么？
9. RMA（Rapid Motor Adaptation）的核心思路是什么？为什么比纯 DR 更鲁棒？
10. curriculum learning 在 sim2real 中怎么用？常见的课程设计策略有哪些？
11. 什么是系统辨识（System Identification）？如何与 DR 结合？
12. 仿真器的 actuator 模型如何影响 sim2real？PD 控制和 torque 控制怎么选？

## 仿真器与工程

13. Isaac Gym 和 Isaac Lab 的关系？与 MuJoCo 在仿真精度/速度上如何对比？
14. MuJoCo、PyBullet、SAPIEN、Genesis 各自的特点和适用场景？
15. GPU 并行仿真（tensorized envs）的原理和关键优势是什么？
16. URDF / MJCF / USD 三种机器人描述格式有什么区别？
17. 接触模型（contact model）对 sim2real 有什么影响？为什么抓取任务特别难？
18. 人形机器人的 sim2real 面临哪些特有挑战？和四足有何不同？
