# 基础控制算法面试题

## 经典控制与 PID

1. 常用的控制方法有哪些？能否举例说明（如 PID、LQR）？
2. PID 的三个参数分别起什么作用？工程上 PID 参数怎么选取？
3. 为什么内环常选 PD 控制？有什么物理影响因素？
4. 速度环控制器参数的选取有什么物理影响因素？
5. 劳斯（Routh）稳定判据是什么？如何判断系统稳定性？
6. 非标准二阶系统的阻尼比怎么计算？阻尼比对系统响应有什么影响？
7. Z 变换是什么？和拉普拉斯变换是什么关系？
8. 什么时候选择 MPC 而不是 PID？（机械臂控制场景）

## 最优控制与数值优化

9. LQR 有几种求解方法？简单讲讲推导过程。
10. LQR 和 MPC 的区别是什么？MPC 的实现原理是什么？
11. iLQR 的推导过程是什么？开发中遇到过哪些实际问题？
12. QP（二次规划）问题由哪些部分构成？对矩阵有什么要求？为什么常把控制问题构造成 QP？
13. 无约束优化的求解方法有哪些？梯度法、牛顿法、拟牛顿法分别讲讲。
14. 内点法是什么？
15. 常用的离散化方法有哪些？各自的特点？
16. 常用的正则化方法有哪些？

## 状态估计与决策

17. 能观性和能控性是什么？状态方程与传递函数如何互相转化？
18. 龙伯格（Luenberger）观测器怎么设计？
19. 机器人常用的决策方法有哪些？状态机、行为树能否举例说明？
