# 我的Ubuntu桌面

我用Ubuntu Desktop 24.04 LTS也很长时间了，对新手而言还是强烈推荐Ubuntu系统。重点说GNOME桌面，尤其是它的Workspace，默认按住Super就能看到所有虚拟桌面，左右滑动，丝滑如触控板，可以一个桌面开浏览器查资料，一个桌面写代码，一个桌面挂微信和音乐，**这也是我用gnome桌面的重大原因**。

## 办公软件

平时的办公软件主要涉及到以下软件：
- 基础文档处理
  - WPS：多文档处理器
  - Okular：PDF阅读器
  - Typora：Markdown编辑器
- 沟通软件
  - 微信
  - QQ
  - 腾讯会议
  - Thunderbird：邮件客户端
- 信息管理
  - 百度网盘
  - Xmind：思维导图软件
  - Zotero：文献管理软件
  - 飞书
  - SimpleTex: 数学公式识别器
- 图片与视频处理
  - GIMP：图片编辑器
  - VLC：视频播放器
  - Shotwell：照片管理器
  - PicGo：图片上传工具
