# 朋友圈动态说明

本目录下的每个 Markdown 文件就是一条动态（`README.md` 本身除外），由主题在构建时聚合到 `/moments` 页面的时间线里，不生成独立页面。

## 文件模板

文件名建议以日期开头（如 `2026-10-30-hello.md`），内容示例：

```md
---
title: 可选标题
date: 2026-10-30 22:08
location: 杭州
images:
  - /coffee.png
  - /tx.jpg
video: /video.mp4
visible: true
---

正文文字，支持 Markdown，也可以只有图片/视频不带文字。
```

## 字段说明

| 字段 | 说明 |
| ---- | ---- |
| `title` | 卡片标题，省略时只显示正文 |
| `date` | 排序与显示时间，可只写日期、也可精确到分钟；缺省回退文件名开头的日期 |
| `images` | 图片列表（`- ` 列表或 `[/a.jpg, /b.jpg]` 行内写法均可），九宫格展示、点击放大 |
| `location` | 位置文字，带定位图标显示在卡片底部 |
| `video` | 视频地址，显示在图片之后 |
| `visible` | 设为 `false` 隐藏这条动态（可当草稿用），缺省显示 |

## 约定

- 图片、视频放到 `docs/public/` 下，用 `/` 开头的绝对路径引用（如 `/coffee.png`）。
- 正文、图片、视频全空的文件会被忽略。
- 新增或修改文件后重新构建即自动聚合，开发模式下热更新直接可见。
