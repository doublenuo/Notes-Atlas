# 朋友圈动态说明

本目录下的每个 Markdown 文件就是一条动态（`README.md` 本身除外），由主题在构建时聚合到 `/moments` 页面的时间线里，不生成独立页面。

## 文件模板

文件名建议以日期开头（如 `2026-10-30-hello.md`），内容示例：

```md
---
title: 可选标题
date: 2026-10-30 22:08
location: 杭州
images:
  - https://static.lovetulin.cn/images/2026/11/09/coffee-1794220831-Iult.webp
  - /tx.jpg
video: /video.mp4
visible: true
---

正文文字，支持 Markdown，也可以只有图片/视频不带文字。
```

## 字段说明

| 字段 | 说明 |
| ---- | ---- |
| `title` | 卡片标题，省略时只显示正文 |
| `date` | 排序与显示时间，可只写日期、也可精确到分钟；缺省回退文件名开头的日期 |
| `images` | 图片列表（`- ` 列表或 `[/a.jpg, /b.jpg]` 行内写法均可），支持 `/` 本地路径和 `https://` CDN 地址，九宫格展示、点击放大 |
| `location` | 位置文字，带定位图标显示在卡片底部 |
| `video` | 视频地址，显示在图片之后 |
| `visible` | 设为 `false` 隐藏这条动态（可当草稿用），缺省显示 |

## 约定

- 图片上传后直接使用 API 返回的 CDN URL；本地文件只作为上传命令的输入，不再作为页面资源引用。
- 正文、图片、视频全空的文件会被忽略。
- 新增或修改文件后重新构建即自动聚合，开发模式下热更新直接可见。

## 点赞与评论

页面已改成朋友圈式信息流，每条动态下方都有「赞 / 评论」：

- **点赞**：保存在当前浏览器的 `localStorage`（键名 `moments-likes-v1`），换设备不会同步。这是纯前端轻互动，不写评论后端。
- **评论**：接入站点现有的 Twikoo 评论服务。所有评论落在 Twikoo 的 `/moments` 页面下，评论正文开头用
  `[[moment:<文件名>]]` 标记归属，前端渲染前会剥掉标记。请勿在 Twikoo 后台手动修改或删除该前缀，
  否则评论会归错动态或不再显示。
- 评论昵称会保存在当前浏览器（`moments-nickname`）；`mail` 留空，因此评论使用默认头像，页面里只显示昵称。
- 修改某个动态的文件名等于修改了它的评论归属 ID，历史评论不会自动跟随。需要迁移时，可在 Twikoo
  后台把对应评论里的 `[[moment:旧文件名]]` 改成新文件名。

## 页面展示

- 封面取本页 frontmatter 的 `cover`；未配置时复用首页 Banner 背景，加载失败再回退到 `/tx.jpg`。
- 头像、昵称由 `MomentsTimeline.vue` 的 props 控制（当前默认 `/logo.png` 和 `weno`）。
- 签名取本页 frontmatter 的 `signature`，缺省回退 `desc`；也可以给组件传 `signature` 覆盖。
