# 关于作者

我是 weno，本科毕业于中国矿业大学（北京），现在在深圳大学读计算机。

目前主要关注人工智能与机器人，具体一点，是强化学习、机器人运动控制和具身智能。平时会读论文、跑实验、调代码，也会把过程中遇到的问题记下来。相比把概念整理得很漂亮，我更在意它能不能真的跑起来，能不能解释清楚一个现象。

## 现在在做什么

大部分时间在学习和做项目：看论文，复现一些感兴趣的工作，调机器人或强化学习相关的实验，也会整理开发环境和工具链。遇到的问题通常不会立刻有答案，所以我会先把过程记下来，等理解更深一点再回头补。

## 怎么写

这个博客里的很多文章，其实是我学习过程的中间产物：有些是刚想明白一点的笔记，有些是踩坑之后留下的记录，还有些问题到现在也没有完全解决。我会尽量把“怎么做”和“为什么这么做”都写下来，而不是只放一个结论。

除了技术，我也会写一点读书笔记和生活记录。它们不一定有用，但也是我生活的一部分。
