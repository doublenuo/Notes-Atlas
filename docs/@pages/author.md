# 关于作者

你好，我是 **doublenuo**，也常用 **weno** 这个名字。

我主要关注 **人工智能、机器人、深度学习和 Linux**，也会记录在学习、论文阅读与项目实践中的思考和经验。

## 为什么维护这个站点

本站是一个持续积累的个人知识库，用来整理真正理解过的内容、复盘遇到的问题，并把零散的学习记录逐渐连接成可以长期回看的知识体系。

这里的内容可能并不完美，也会随着新的理解不断修订，但希望每一次记录都能为未来的学习和实践提供一点帮助。
