## Prompt 的本质

###  Prompt 是什么

Prompt 是开发者向模型描述任务、提供上下文、制定规则和约束的方式。在传统软件开发中，开发者通过代码告诉计算机应该如何执行，计算机会严格执行每一条代码指令，而在 LLM 应用中是概率性的，开发者通过 Prompt 告诉模型应该如何**思考和输出**。

每个prompt不管简单与复杂，都离不开**意图**、**上下文**、**约束**和**输出格式**这四个维度，可以大致认为：

>   清晰意图＋上下文＋约束+一致的输出格式＝一致的高质量输出

### Role

Role（角色）是控制模型**身份、行为准则和对话上下文**的核心机制，
