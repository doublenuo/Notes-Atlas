# 模仿学习

强化学习有一个隐含的前提：**你能写出奖励函数**。四足机器人走路，奖励速度跟踪；机械臂抓取，奖励靠近目标；下围棋，赢了给正分。但现实中，很多任务的奖励函数根本写不出来。

想象一下让机器人学会倒茶。什么叫倒得好？茶水不能洒出来，杯子要稳稳地拿住，水流要均匀，倒的量要刚好，倒完还要把茶壶放回原位。这些条件你能写成奖励函数吗？可以，但每一项都需要精心设计，而且它们之间会互相冲突——你奖励“倒得快”，机器人可能把水泼出来；你奖励“不洒水”，机器人可能一滴一滴地倒，花十分钟才倒满。奖励设计的复杂度，可能比任务本身还高。

再比如自动驾驶。“开得好”怎么定义？安全、平滑、遵守交规、不挡别人的路、乘客不晕车——这些你都知道，但写成数学公式，每一项的权重怎么定？紧急避让时，安全和遵守交规冲突了怎么办？奖励函数写不出来，强化学习就无从下手。

但人类是怎么学会倒茶的？不是靠奖励函数，而是靠**看别人倒**。你看父母倒茶，看老师示范，看视频教程，然后自己模仿。你不需要知道“这一秒手腕该转多少度”，你只需要知道“大概像那样做”。这就是模仿学习的核心思想：**不写奖励，直接学专家的行为。**

模仿学习（Imitation Learning）是一类从专家示范中学习策略的方法。专家可以是人类，可以是另一个控制器，可以是一个已经训练好的强化学习策略。你提供状态-动作对 $(s,a)$，让智能体学会“在这个状态下，专家会这么做”。它绕开了奖励设计的难题，直接把“怎么做”教给智能体。

## 行为克隆

模仿学习最直接的形式是**行为克隆**（Behavior Cloning，BC）。它的想法简单到几乎不像一个算法：把专家示范当成监督学习的数据集，状态是输入，动作是标签，训练一个策略网络去拟合。

假设专家在状态 $s$ 下选择了动作 $a$，我们就希望策略网络 $\pi_\theta(s)$ 的输出也接近 $a$。对于连续动作，损失函数就是均方误差：

$$
\mathcal{L}(\theta) = \mathbb{E}_{(s,a) \sim \mathcal{D}}\left[\|\pi_\theta(s) - a\|^2\right]
$$

对于离散动作，损失函数是交叉熵：

$$
\mathcal{L}(\theta) = -\mathbb{E}_{(s,a) \sim \mathcal{D}}\left[\log \pi_\theta(a|s)\right]
$$

其中 $\mathcal{D}$ 是专家示范数据集。训练过程就是标准的监督学习：采样一个 batch，计算损失，梯度下降，重复。

行为克隆的实现非常简洁：

```python
class BehaviorCloning:
    def __init__(self, state_dim, action_dim, lr=1e-3):
        self.policy = PolicyNetwork(state_dim, action_dim)
        self.optimizer = torch.optim.Adam(self.policy.parameters(), lr=lr)

    def train(self, expert_data, epochs=100, batch_size=64):
        states = torch.FloatTensor(expert_data['states'])
        actions = torch.FloatTensor(expert_data['actions'])
        dataset = TensorDataset(states, actions)
        loader = DataLoader(dataset, batch_size=batch_size, shuffle=True)

        for epoch in range(epochs):
            for s_batch, a_batch in loader:
                pred = self.policy(s_batch)
                loss = F.mse_loss(pred, a_batch)

                self.optimizer.zero_grad()
                loss.backward()
                self.optimizer.step()
```

行为克隆的优点是简单、稳定、样本效率高。它就是一个监督学习问题，所有成熟的技巧——数据增强、正则化、学习率调度——都可以直接用。在机器人控制里，如果你有足够的高质量示范，行为克隆能很快学出一个可用的策略。

但行为克隆有一个致命的缺陷：**复合误差**。

### 复合误差

行为克隆假设专家示范覆盖了智能体可能遇到的所有状态。但训练时智能体看到的状态分布，和它部署时实际遇到的状态分布，是不一样的。

假设你教一个机器人沿直线走。专家示范里，机器人始终在直线附近，状态分布很窄。行为克隆学会了“在直线附近微调方向”。但部署时，机器人一开始稍微偏了一点，这个状态在训练数据里很少见，策略输出一个不够准的动作，偏得更远。下一步偏得更远，再下一步更远，最后完全跑偏，摔出专家的状态分布。而一旦出了分布，策略就彻底不知道该怎么办了，因为它从没见过这些状态。

这个现象被称为**复合误差**（Compounding Error）。误差会随着时间累积，每一步的小误差都被放大，最后导致轨迹完全偏离。理论分析表明，行为克隆的误差随时间步长呈 $O(T^2)$ 增长——轨迹越长，误差越大。对于机器人控制这种需要几百步甚至几千步的任务，复合误差是致命的。

用一个比喻来说：行为克隆像一个只背了标准答案的学生。考试题目和标准答案一模一样时，他能考满分；但题目稍微变一下，他就完全不会了。而强化学习像一个理解了原理的学生，题目变了也能应对。问题是，理解原理需要奖励函数，而奖励函数写不出来，所以你只能背答案——但背答案又不够用。

复合误差引出了一个问题：**能不能让智能体在训练时也遇到它部署时会遇到的状态？** 这就是 DAgger 的出发点。

## DAgger算法

DAgger，全称 Dataset Aggregation，是 2011 年提出的模仿学习算法。它的核心思想非常直接：**既然智能体部署时会偏离专家轨迹，那就在训练时让它偏离，然后请专家来纠正。**

DAgger 的流程如下：

1. 用当前策略 $\pi_\theta$ 在环境中跑，收集它实际访问到的状态；
2. 对每一个状态，请专家标注“在这个状态下应该做什么动作”；
3. 把这些新数据加入数据集 $\mathcal{D}$；
4. 在更新后的数据集上重新训练策略；
5. 重复以上过程。

和行為克隆的关键区别是：行为克隆用的是专家访问的状态分布，DAgger 用的是**智能体自己访问的状态分布**。智能体在训练时就会遇到那些它容易出错的状态，专家在这些状态下给出正确动作，智能体就能学会如何从错误中恢复。

DAgger 的伪代码：

```python
def dagger(env, expert, policy, iterations=10):
    dataset = {'states': [], 'actions': []}

    # 先用专家示范初始化
    for _ in range(initial_demos):
        s = env.reset()
        done = False
        while not done:
            a = expert(s)
            dataset['states'].append(s)
            dataset['actions'].append(a)
            s, _, done, _ = env.step(a)

    for i in range(iterations):
        # 用当前策略跑，收集状态
        new_states = []
        s = env.reset()
        done = False
        while not done:
            a = policy(s)
            new_states.append(s)
            s, _, done, _ = env.step(a)

        # 请专家标注这些状态
        for s in new_states:
            a_expert = expert(s)
            dataset['states'].append(s)
            dataset['actions'].append(a_expert)

        # 在聚合数据集上重新训练
        policy.train(dataset)

    return policy
```

DAgger 的理论保证比行为克隆强得多。在合适的假设下，DAgger 的误差随时间步长呈 $O(T)$ 增长，而不是 $O(T^2)$。这个改进是本质性的：它让模仿学习从“只能处理短任务”变成了“可以处理长任务”。

但 DAgger 有一个实际的困难：**它需要专家在训练过程中持续在线**。行为克隆只需要一份离线数据集，专家标注完就可以走了。DAgger 需要专家在每一轮训练中，对智能体访问到的新状态实时标注。如果专家是人类，这意味着人类要坐在电脑前，看着机器人一次次跑偏，然后一次次纠正。这个成本很高，而且在机器人控制里，人类专家未必能对每一个状态都给出精确的动作——你能看着一个四足机器人的关节角度和IMU读数，说出“现在左前腿髋关节应该转多少度”吗？很难。

所以 DAgger 在实践中通常用在专家是另一个控制器（比如 MPC 或 PD 控制器）的场景里。控制器可以实时输出动作，不需要人类介入，DAgger 就可以自动化运行。

## 逆强化学习

行为克隆和 DAgger 都是直接学策略：状态进，动作出。但它们有一个共同的局限：它们只学了“怎么做”，没学“为什么这么做”。这意味着它们很难泛化到专家示范之外的情况。

**逆强化学习**（Inverse Reinforcement Learning，IRL）换了一个思路：**不直接学策略，而是从专家行为中反推出奖励函数，然后用这个奖励函数去训练强化学习。**

IRL 的核心假设是：专家的行为是最优的，即专家在最大化某个未知的奖励函数 $R^*(s,a)$。如果我们能从专家的示范中推断出 $R^*$，那就可以用标准的强化学习算法去优化它，学出一个比行为克隆更鲁棒的策略。因为策略是从奖励函数里“推导”出来的，而不是从数据里“拟合”出来的，它天然具有泛化能力。

IRL 的形式化定义是：给定专家示范 $\mathcal{D} = \{(s_1,a_1), (s_2,a_2), \ldots\}$，找到一个奖励函数 $R$，使得专家策略 $\pi_E$ 在这个奖励下是最优的：

$$
\mathbb{E}_{\pi_E}\left[\sum_t \gamma^t R(s_t,a_t)\right] \geq \mathbb{E}_{\pi}\left[\sum_t \gamma^t R(s_t,a_t)\right], \quad \forall \pi
$$

但这个问题是**不适定的**：有无数个奖励函数可以让专家策略最优。比如 $R(s,a) = 0$ 对所有状态动作都成立，专家策略当然也是最优的（所有策略都一样好）。所以 IRL 需要额外的偏好或正则化来选出“合理”的奖励函数。

最经典的 IRL 算法是 **最大熵逆强化学习**（Maximum Entropy IRL）。它的思想是：在所有能让专家策略最优的奖励函数中，选那个让专家轨迹概率最大的。具体来说，它假设专家行为遵循 Boltzmann 分布：

$$
P(\tau|\theta) = \frac{1}{Z(\theta)} \exp\left(\sum_t R_\theta(s_t,a_t)\right)
$$

其中 $R_\theta$ 是用参数 $\theta$ 表示的奖励函数，$Z(\theta)$ 是归一化常数。然后最大化专家轨迹的似然：

$$
\max_\theta \mathbb{E}_{\tau \sim \mathcal{D}}\left[\log P(\tau|\theta)\right]
$$

这个目标的直觉是：**专家的行为应该是最可能的，而不是随机的。** 如果一个奖励函数让专家轨迹的概率很低，那它就不是一个好的奖励函数。

IRL 的魅力在于，它学出来的奖励函数可以用于强化学习，从而得到一个能泛化的策略。但它的代价也很明显：IRL 的计算非常昂贵，因为它需要在每一轮迭代中求解一个完整的强化学习问题。而且，IRL 的奖励函数往往学得不够好，导致学出来的策略反而不如行为克隆。所以在实践中，IRL 更多用于奖励函数的设计和可解释性分析，而不是直接用于策略学习。

## GAIL算法

**生成对抗模仿学习**（Generative Adversarial Imitation Learning，GAIL）是 2016 年提出的方法，它把模仿学习和生成对抗网络（GAN）结合了起来。GAIL 的核心思想是：**不显式地学奖励函数，而是用一个判别器来区分“专家行为”和“智能体行为”，然后用这个判别器的输出作为奖励信号。**

GAIL 的结构包含两个网络：**策略网络** $\pi_\theta$ 和**判别器** $D_\phi$。判别器接收 $(s,a)$ 对，输出一个概率，表示“这个状态动作对是专家产生的还是智能体产生的”。策略网络的目标是让判别器分不清自己和专家，判别器的目标是尽可能分清楚。

判别器的损失是标准的二分类交叉熵：

$$
\mathcal{L}_D = -\mathbb{E}_{(s,a) \sim \mathcal{D}}\left[\log D_\phi(s,a)\right] - \mathbb{E}_{(s,a) \sim \pi_\theta}\left[\log(1 - D_\phi(s,a))\right]
$$

策略网络的奖励信号来自判别器：

$$
r_t = -\log(1 - D_\phi(s_t,a_t))
$$

这个奖励的含义是：如果判别器认为这个动作很像专家，$D_\phi$ 接近 1，$-\log(1-D_\phi)$ 就很大，奖励就高；如果判别器认为这个动作不像专家，奖励就低。策略网络用这个奖励做强化学习（通常用 PPO 或 TRPO），不断提升自己，让判别器越来越分不清。

GAIL 的优势在于：它不需要显式的奖励函数，也不需要专家在训练中在线标注（只需要一份专家示范数据集），而且它的策略是在强化学习框架下训练的，泛化能力比行为克隆强。它的样本效率也还不错，因为它不依赖于对环境的精确建模。

GAIL 在机器人控制里应用广泛。机械臂操作、四足行走、自动驾驶，都有 GAIL 的成功案例。它的一个经典应用是“从人类视频中学习”：人类演示的视频里没有动作标签，但可以通过视觉观测对齐，用 GAIL 让机器人的行为在状态分布上和人类演示匹配。

但 GAIL 也有它的问题。判别器可能被“欺骗”：策略找到一种判别器没见过的行为模式，判别器给高分，但实际上并不像专家。这种现象在 GAN 里被称为模式坍塌，在 GAIL 里也存在。而且 GAIL 的训练不稳定，需要精心调节判别器和策略网络的训练节奏。

## 模仿学习与强化学习的结合

模仿学习和强化学习不是对立的，它们可以结合使用，各取所长。

**用模仿学习做初始化，用强化学习做微调。** 先用行为克隆或 GAIL 训练一个还不错的策略，然后把它作为强化学习的起点，用真实的奖励函数继续优化。这样既利用了模仿学习的高样本效率，又利用了强化学习能超越专家的能力。在机器人控制里，这被称为“示范引导的强化学习”（demonstration-guided RL）。它解决了强化学习从零探索的难题——如果机器人完全随机探索，它可能永远学不会走路；但如果从模仿学习出发，它已经会“大致走”了，强化学习只需要微调。

**用模仿学习做安全约束。** 在那些强化学习探索代价极高的任务里，可以用模仿学习先学一个“安全策略”，然后在安全策略附近做强化学习。这样即使强化学习走偏，也不会做出危险动作。

**用模仿学习提供奖励信号。** 前面讲过，奖励函数很难写。但你可以请人类专家做几次示范，然后用 IRL 或 GAIL 从示范中反推奖励。这个奖励可以用于后续的强化学习训练，也可以用于分析专家行为。

**用强化学习改进模仿学习。** DAgger 需要专家在线纠正，但如果专家是另一个强化学习策略呢？你可以先用行为克隆训练一个初始策略，然后用它和环境交互，收集失败案例，再用强化学习在这些失败案例上微调。这本质上是一种“自模仿”的闭环。

## 总结

模仿学习是强化学习之外的另一条路。它不写奖励函数，直接从专家示范中学习策略。行为克隆是最简单的形式，把模仿当成监督学习，但它有复合误差，轨迹一长就跑偏。DAgger 通过在训练中让专家纠正智能体的错误，把误差从 $O(T^2)$ 降到 $O(T)$，但需要专家在线。逆强化学习从行为反推奖励，再用奖励训练强化学习，泛化能力更强但计算昂贵。GAIL 用对抗学习做模仿，不显式学奖励，训练稳定性和样本效率都很好。

模仿学习和强化学习各有长短。模仿学习样本效率高、不需要奖励函数，但受限于专家的水平，很难超越专家。强化学习能超越专家、能发现新策略，但需要精心设计的奖励函数，而且样本效率低。在实践中，最好的方法往往是两者结合：用模仿学习做初始化和安全约束，用强化学习做微调和超越。

在机器人运动控制里，模仿学习正在从“替代方案”变成“核心方法”。当奖励函数写不出来时，当强化学习探索太慢时，当仿真和现实有差距时，模仿学习提供了一条务实的路径。它让机器人可以像人一样，通过观察和模仿来学习，而不是通过无数次的试错。这也让我们离“通用机器人”的梦想更近了一步——因为人类学习的方式，从来不只是试错，更是观察、模仿、理解。
