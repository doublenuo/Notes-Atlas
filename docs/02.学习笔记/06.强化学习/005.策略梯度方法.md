# 策略梯度方法

## 策略梯度算法

在前面几章里，我们一直在和 Q 值打交道。Q-learning、DQN、Double DQN、Dueling DQN——这些算法的核心思路是一样的：先学会给每个动作打分，然后挑分数最高的那个。这条路线在离散动作空间里非常成功，DQN 甚至在 Atari 游戏上达到了人类水平。但当我们把它搬到机器人控制的任务上，问题就来了。

第一个问题是连续动作。四足机器人有 12 个关节，每个关节的角度是连续的。如果每个关节离散成 100 档，12 个关节的组合就是$100^{12}$，这个数字比宇宙中的原子还多。你没法枚举所有动作，更没法对它们逐一求$\arg\max$，基于价值的方法在这里直接撞墙。

第二个问题是随机策略。有些任务的最优策略本身就是随机的。比如猜拳游戏，如果策略是确定性的，对手一旦摸清你的规律就能稳赢。最优策略应该是以$\frac{1}{3}$3 的概率随机出石头剪刀布。Q-learning 学出来的是确定性策略（总是选 Q 值最大的），它天然无法表示这种随机性。虽然$\epsilon$-greedy能带来一些随机，但那是外部强加的噪声，不是策略本身学出来的。

第三个问题是策略的表示。基于价值的方法学的是 Q 函数，策略是从 Q 函数里推导出来的。这意味着策略是隐式的，你没法直接控制它的形态。如果你想让策略满足某种约束，比如平滑性、安全性，你只能通过奖励函数间接影响它，而不能直接对它下手。

策略梯度方法换了一条路走。**它不学打分，直接学策略本身**。 策略用一个神经网络参数化，输入状态，输出动作分布。训练的目标就是调整参数，让好的动作更常发生，差的动作更少发生。这条路天然支持连续动作，天然支持随机策略，也让策略的表示变得直接而灵活。

### 策略的参数化

我们先来定义策略长什么样。在策略梯度方法里，策略记作$\pi_{\theta}(a|s)$， 其中$\theta$是神经网络的参数。它接收状态$s$，输出动作$a$的概率分布。

对于离散动作空间，策略网络的最后一层通常接 softmax，输出每个动作的概率：

$$\pi_\theta(a|s)=\frac{\exp(h_\theta(s,a))}{\sum_{a^{\prime}}\exp(h_\theta(s,a^{\prime}))}$$

其中$h_\theta(s,a)$是网络在动作$a$上的输出值。

对于连续动作空间，策略网络通常输出一个高斯分布的均值和标准差：

$$\pi_\theta(a|s)=\mathcal{N}\left(a;\mu_\theta(s),\sigma_\theta(s)^2\right)$$

均值$\mu_\theta(s)$告诉你“当前认为最好的动作在哪”，标准差$\sigma_\theta(s)^2$告诉你“有多不确定”。训练时从高斯分布里采样动作，所以策略自带随机性；部署时取均值，动作平滑确定。

这里有一个关键的设计选择。标准差有两种处理方式：一种是直接让网络输出$\sigma_\theta(s)$，另一种是让网络输出$\log\sigma_\theta(s)$然后用指数还原。后者更常用，因为它保证了标准差永远为正，而且数值更稳定。有的实现把标准差设成与状态无关的可学习参数，简单但表达力弱；也有的实现让标准差随状态变化，更灵活但更难训练。
