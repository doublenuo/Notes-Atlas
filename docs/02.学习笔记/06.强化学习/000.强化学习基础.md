# 强化学习基础

## 机器学习范式的对比

机器学习通常被分成三大范式：监督学习、无监督学习和强化学习。

- **监督学习**是指有人提前标好了答案，模型从 `(输入, 标签)` 对中学习映射关系，例如训练数据中会有`(图片1, 猫),(图片2, 狗)`,它的目标就是最小化预测与标签之间的误差，本质上是拟合一个静态的映射函数$f: x \to y$，且数据是独立同分布的；
- **无监督学习**就是没有标签，让模型自己发现数据的结构，聚类、降维、生成模型都属此类；
- **强化学习**没有标签，但有反馈，通过与环境交互来学习最优策略。

## 强化学习的定义

强化学习（reinforcement learning，RL）讨论的问题是智能体怎么在复杂、不确定的环境中最大化它能获得的奖励。强化学习由两部分组成：智能体和环境。在强化学习过程中，智能体与环境一直在交互。

### 核心循环

想象一下，你正在教一个机器人走路。你不能直接告诉它“大腿抬 30 度、膝盖弯 45 度”，因为你也不知道在每一个瞬间到底该怎么做。你能做的，只是给它一个目标，并在它做得好时给一个奖励，做得差时给一个惩罚。机器人会一次次尝试，逐渐摸索出哪些动作能带来更多奖励。这就是强化学习的本质：没有标准答案，只有奖励信号。

在交互过程中，智能体首先观察环境给出的某个**状态（State）**，然后根据这个状态输出一个**动作（Action）**，这个动作也称为决策。环境接收到动作后，会执行它，并因此转移到下一个状态，同时返回一个**奖励（Reward）**。这个奖励是一个标量，是环境对智能体刚才那个动作的唯一反馈。

整个交互过程是一个不断重复的循环：
1. 智能体观察到当前状态$S_t$,选择动作$A_t$;
2. 环境执行动作，转移到新状态$S_{t+1}$, 返回奖励$R_{t+1}$;
3. 重复以上过程。

![](https://ubuntu-picupload-1330431167.cos.ap-guangzhou.myqcloud.com/images/20260924213123668.png)

这个循环就会产生一串序列数据$(S_0,A_0,R_0,S_1,A_1,R_1,\cdots)$，这串数据被称为**轨迹（Trajectory）**。强化学习正是一类解决**序列决策问题**的计算方法，智能体处在某个环境中，在每个时刻观察环境的状态，据此选择一个动作；环境接收动作后转移到新状态，并给智能体一个标量奖励作为唯一的反馈信号。智能体的目标，就是最大化整个交互过程中的**累积奖励**。

关于奖励，如果只看眼前的单步奖励，智能体就会变得非常“短视”。比如，一个机器人如果只追求当下不摔倒，它可能永远不敢迈步；一个下棋程序如果只想着吃掉对方一个子，它可能输掉整盘棋。因此，智能体真正关心的目标是**累积回报（Return）**，也就是从当前时刻 $t$ 开始，直到一局游戏结束，未来所有奖励的总和。但是，把未来的奖励直接加起来有一个问题，越远未来的奖励越不确定，为了未来的奖励不如现在的奖励更值得，可以引入折扣因子$\gamma$（$\gamma$取值在$0\sim 1$之间,通常为$0.95\sim 0.99$），未来的奖励在加和时就会被打个折扣，越远的奖励折扣越大。这既符合直觉，也能在数学上保证无穷级数收敛。

于是，从时刻$t$开始的累积回报$G_t$定义为
$$
G_t=r_{t+1}+\gamma r_{t+2}+\gamma^2 r_{t+3}+\cdots =\sum_{k=0}^{+\infty}\gamma^kr_{t+k+1}
$$

智能体通常会面临**即时奖励和远期奖励的权衡**，在机器人运动控制里，这种权衡尤其明显，一只四足机器人站在起点，它可以选择原地不动 每一步都稳稳当当，获得姿态稳定奖励，永远不会摔倒，但也永远不会到达目标；它也可以选择往前走，前几步会因为动作不稳定获得惩罚，但是它会有远期的速度跟踪奖励。

这个时候折扣因子$\gamma$的大小就决定了即时奖励与远期奖励的权衡；
- $\gamma$比较小，远期奖励在智能体眼里的价值会被大打折扣，于是智能体选择即时奖励；
- $\gamma$比较大，远期奖励的折扣很小，智能体更有远见，愿意为了未来更大的奖励而放弃眼前的小利。

因此在机器人运动控制中，通常$\gamma$会设置的非常大，比如0.99甚至0.995，因为机器人运动控制不是单步的任务，而是未来几百步的事情。

### 策略

前面我们搞清楚了状态、动作、奖励和回报，但它们都只是舞台和道具，真正决定机器人怎么动的，是策略。

策略是智能体的大脑，是 $S\to A$ 的映射。数学上，策略通常记作$\pi$，如果动作是离散的，策略就是一个概率分布:

$$
\pi(a|s)=P(A_t=a|S_t=s)
$$

意思是在状态$s$下，选择动作$a$的概率有多大。如果策略是确定性的，也可以直接写成$a=\mu(s)$.但在机器人运动控制中，我们更常用随机策略，尤其是连续动作空间。比如四足机器人的 12 个关节，策略网络会输出一个高斯分布：

$$
\pi_{\theta}(a|s)=\mathcal{N}(a;\mu_{\theta}(s),\sigma_{\theta}(s)^2)
$$

训练时，机器人从这个分布里采样动作，所以它会尝试不同的关节角度，部署时，我们通常直接取均值$\mu_{\theta}(s)$，让动作平滑确定。至于为什么不用纯确定性策略？因为训练初期机器人什么都不会，如果动作永远确定，它很容易卡在某个局部最优里。随机策略给了它探索的机会：这一下腿抬高点，那一下腿抬低点，摔了几次之后，它才知道哪种动作能拿到更多奖励。

策略通常用神经网络参数化，输入是状态$S$, 比如关节角度、关节速度、躯干姿态、IMU 读数、速度指令；输出是动作分布的参数，例如一个简化的策略网络是这样的。

```python
class PolicyNet(nn.Module):
    def __init__(self, obs_dim, act_dim, hidden=256):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(obs_dim, hidden), nn.Tanh(),
            nn.Linear(hidden, hidden), nn.Tanh(),
        )
        self.mean = nn.Linear(hidden, act_dim)
        self.log_std = nn.Parameter(torch.zeros(act_dim))

    def forward(self, s):
        h = self.net(s)
        mean = self.mean(h)
        std = torch.exp(self.log_std).expand_as(mean)
        return mean, std
```

### 强化学习算法分类

所有强化学习算法都在回答同一个问题：如何选择动作以最大化累积回报？所谓累积回报 $G_t$，就是智能体从时刻 $t$ 起获得的所有奖励之和:

$$
G_t=r_{t+1}+\gamma r_{t+2}+\gamma^2 r_{t+3}+\cdots =\sum_{k=0}^{+\infty}\gamma^kr_{t+k+1}
$$

训练的最终目标就是找到最优策略，即给定状态输出动作的函数。最优策略的训练有两种不同的路线：

**基于价值的**：它的核心思想是不直接学策略，而是学每个状态或每个动作到底值多少分，然后，策略就是选分数最高的那个动作

$$
\pi(s)=\arg\max_a Q(s,a)
$$

这里的$Q(s,a)$就是动作价值函数，表示在状态$s$下做动作$a$之后一直用最优策略，能拿到的期望累积回报。

$$
Q(s,a)=\mathbb{E}[G_t|S_t=s,A_t=a]
$$

机器人不需要显式地学一个策略网络，它的策略是从**价值函数**里推导出来的，从 Q-learning 到 DQN，核心都是用贝尔曼最优方程去逼近$Q^*$：

$$
Q^*(s,a)=\mathbb{E}[r+\gamma \max_{a^{\prime}}Q^{*}(s^{\prime},a^{\prime})]
$$

每走一步，就用即时奖励与下一步最大价值的折扣去更新当前的估计，也就是当前的$Q$值=即时奖励+下一步的$Q$值。

**基于策略的**：它的核心思想是不学打分，直接学策略本身，策略网络输出动作，好就强化，差就弱化，策略用神经网络参数化$\pi_{\theta}(a|s)$，输入状态$s$，输出动作分布。训练时，机器人按照当前策略采样动作，走完一段轨迹，然后根据累积回报来调整$\theta$:
- 如果某条轨迹的回报高，就提高这条轨迹里所有动作的概率;
- 如果回报低，就降低它们的概率。

这就是策略梯度定理，它的直觉非常直接，让高回报的动作更常发生，让低回报的动作更少发生。
$$
\nabla_{\theta}J(\theta)=\mathbb{E_{\pi_\theta}}[\nabla_{\theta}\log{\pi_{\theta}(a_t|s_t)}.G_t]
$$

这一条路线的代表算法是从基础的 REINFORCE 发展到现在广泛使用的PPO算法，**Actor-Critic框架**把二者组合在一起，用基于价值的方法训练一个Critic来评估每个动作的好坏，再用基于策略的方法训练一个Actor来选择动作，具体来说：

- Critic 是一个价值网络，负责估计当前状态或状态动作对的价值；
- Actor 是一个策略网络，责输出动作分布。

例如四足机器人学走路的交互过程是这样的，它观察到状态，包括关节角度、躯干姿态和速度指令，Actor 输出动作分布并采样得到一个动作，也就是十二个关节的目标位置。动作被执行后，机器人转移到新状态，获得奖励，这个奖励可能是速度跟踪成功给的正分，也可能是姿态失衡给的负分。接着 Critic 接收前后两个状态，计算两个估计值，然后用时序差分误差来评估刚才那个动作到底好不好。这个误差等于实际奖励加上折扣后的下一状态价值，再减去当前状态价值。如果误差大于零，说明实际收获比预期好，Actor 刚才的动作值得鼓励；如果误差小于零，说明实际收获不如预期，Actor 刚才的动作需要抑制。然后 Actor 用这个误差来更新自己的参数，优势为正就提高这个动作的概率，优势为负就降低它的概率。与此同时，Critic 也不断被更新，用真实奖励去逼近价值。就这样，Actor 和 Critic 在每一轮交互中互相推动，Critic 打分越来越准，Actor 动作越来越好。

在强化学习的术语中，根据是否学习环境的运作规律，算法还可以分为另外两类：
- **无模型的方法**：它把环境当成一个黑箱，智能体通过与环境的不断交互获得状态、动作、奖励和下一状态，然后直接用这些经验去估计价值函数或优化策略；
- **有模型的方法**：它则试图先理解世界，再决定怎么做。智能体要么已知环境的动力学模型，要么从数据中学习一个模型，用它预测“如果我做这个动作，下一步状态和奖励会怎样”，有了模型，它就可以在“大脑”里预演未来很多步，通过规划或轨迹优化来选择动作，也可以生成虚拟经验来加速无模型学习。

## 探索与利用的平衡

不管是基于价值还是基于策略的方法，都需要解决一个核心困境，探索与利用的平衡。利用，是使用你已经知道的好选项；探索，是尝试你还不知道的选项，去获取新信息。到底是利用已知最好的动作稳拿奖励，还是冒险尝试未知动作以发现更好的策略，探索太多浪费资源，太少则容易陷入次优策略。为什么这个问题如此根本？因为智能体唯一的信息来源就是**它自己的经历**。它不知道环境的全貌，不知道哪个动作真正最好，它只能通过尝试来了解。如果它永远只做已知最好的动作，它就永远不知道有没有更好的动作存在，可能一辈子卡在一个次优的策略里。

### $\epsilon$-Greedy算法

完全贪婪算法就是在每一时刻采取期望奖励估值最大的动作，这就是纯粹的利用，而没有探索，比较经典的一种方法为$\epsilon$-Greedy算法，它在完全贪婪算法的基础上添加了噪声，每次以概率$1-\epsilon$选择以往经验中期望奖励估值最大的动作，以概率$\epsilon$随机选择一个动作。

$$
a_t=\begin{cases}
\arg\max_{a}Q(s,a), 1-\epsilon \\
a_{\mathrm{rand}}\sim \mathcal{U}(A),\epsilon
\end{cases}
$$

随着探索次数的不断增加，我们对各个动作的奖励估计得越来越准，此时我们就没必要继续花大力气进行探索，可以令$\epsilon$随时间衰减，即探索的概率将会不断降低。

```python
class EpsilonGreedy:
    def __init__(self, n_actions, epsilon=1.0, epsilon_min=0.01, epsilon_decay=0.995):
        self.n_actions = n_actions
        self.epsilon = epsilon
        self.epsilon_min = epsilon_min
        self.epsilon_decay = epsilon_decay

    def select_action(self, q_values):
        if np.random.rand() < self.epsilon:
            return np.random.randint(self.n_actions)
        return int(np.argmax(q_values))

    def decay(self):
        self.epsilon = max(self.epsilon_min, self.epsilon * self.epsilon_decay)
```

### 基于策略的方法

基于策略的方法是内部带随机，探索是策略本身的一部分，不用外挂，它天生就会。最核心的实现方式，是让策略网络输出的不是一个确定的动作，而是一个概率分布的参数。在连续控制里，这个分布通常是高斯分布。策略网络接收状态$s$，输出两个东西均值$\mu_{\theta}(s)$和标准差$\sigma_{\theta}(s)$，然后在训练时，从这个高斯分布里采样得到动作：

$$
a_t\sim \mathcal{N}(\mu_{\theta}(s_t),\sigma_{\theta}(s_t)^2)
$$

这个**采样过程本身就是探索**。均值告诉你“当前认为最好的动作在哪”，标准差告诉你“我有多不确定”。如果标准差大，采样出来的动作就会在均值附近大幅波动，机器人会尝试各种各样的关节角度，探索就充分；如果标准差小，采样出来的动作就集中在均值附近，几乎等于直接用均值，利用就占主导。训练初期，标准差自然较大，因为网络还没学到什么确定的东西；随着训练进行，策略梯度会自动调整标准差，如果某个方向上的探索能带来更高回报，网络就会保留那个方向上的方差；如果探索纯粹是浪费，方差就会收缩。这是一个学出来的、自适应的探索强度，不需要你手动调一个。

但光靠这个还不够，因为**策略梯度容易过早收敛**。训练一段时间后，标准差可能会坍缩到很小，策略变得几乎确定性，探索就停了。机器人可能卡在一个次优的策略里，比如永远用小碎步走，永远发现不了大跨步甚至跳跃。所以第二类实现方式是显式地在目标函数里加一项，逼着策略保持随机性。最著名的就是 SAC，它的目标是最大化回报加上熵：

$$
J(\theta)=\mathbb{E}[\sum_{t}\gamma^t(r_t+\alpha \mathcal{H}(\pi_\theta(.|s_t)))]
$$

其中$\mathcal{H}$是策略分布的熵，$\alpha$是温度系数，用于控制好奇心的权重，熵越大，策略越随机，探索越充分，SAC 不是让策略自由地选择确定性，而是要求既要拿高分，也要保持一定的混乱，SAC 会设定一个目标熵，如果当前策略的熵低于目标，就增大$\alpha$,逼它多探索；如果高于目标，就减小$\alpha$，让它多利用。这样探索强度就变成了一个自动闭环，不需要人工调参。
