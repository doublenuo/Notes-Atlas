# 模型预测控制

强化学习学会走路的方式，是摔无数次跟头。它在仿真里跌跌撞撞，靠奖励信号一点点调整策略，最终长出一套条件反射。这条路很强大，但也很慢。它需要海量数据，需要在仿真里反复试错，需要在真机上小心翼翼。而模型预测控制（Model Predictive Control，MPC）走的是另一条路：**它不试错，它预演。**

MPC 的核心思想是：如果你知道世界怎么运转，你就能在脑子里预演未来。机器人不需要真的摔倒，它只需要在内部模型里模拟“如果我现在施加这个力矩，接下来几步会怎样”。然后它挑出最优的那一串动作，只执行第一步，再重新预演。这就像下棋时你会往后想好几步，而不是每走一步都靠试错。MPC 是控制领域的经典方法，它在化工、航天、自动驾驶里已经用了几十年。最近几年，它和强化学习、模仿学习走到了一起，成了机器人运动控制里不可或缺的一环。

## 预测模型：MPC 的大脑

MPC 需要一个**模型**。这个模型描述的是：在当前状态 $s$ 下，施加动作 $a$，下一步状态会变成什么。用数学语言说，就是状态转移函数：

$$
s_{t+1} = f(s_t, a_t)
$$

在机器人控制里，$f$ 可以是物理方程——刚体动力学、接触模型、电机模型；也可以是从数据里学出来的神经网络模型。如果 $f$ 精确，MPC 的预演就准；如果 $f$ 有误差，MPC 的预演就会偏，但因为它每一步都在重新预测，误差不会累积太久。这也是 MPC 比纯开环控制更鲁棒的原因。

MPC 和强化学习里的“有模型方法”有亲缘关系。Dyna、世界模型、MuZero 都是在学一个 $f$，然后在内部模型里做规划。区别在于，强化学习通常用神经网络学 $f$，而 MPC 通常用已知的物理方程，或者用系统辨识方法拟合一个参数化模型。强化学习的模型是为了生成虚拟经验来训练策略，MPC 的模型是为了直接在线优化动作。

## 滚动时域优化

MPC 最核心的特征是**滚动时域**（Receding Horizon）。它在每一个时刻做三件事：

1. **预测**：从当前状态出发，用模型往前推演 $H$ 步，得到一个预测轨迹；
2. **优化**：在这 $H$ 步里，找到一串动作 $a_t, a_{t+1}, \ldots, a_{t+H-1}$，让某个代价函数最小；
3. **执行**：只执行这串动作里的第一个动作 $a_t$，然后进入下一个时刻，重新预测、重新优化。

为什么只执行第一步？因为预测永远不完美。环境会变，模型会有误差，外部扰动会进来。如果你把未来 $H$ 步的动作全执行了，一旦第一步之后世界偏离了预测，后面的动作就全错了。滚动时域让 MPC 每一步都根据最新状态重新规划，像一个不断修正方向的司机。

这个“预演未来、只走一步”的模式，和强化学习里的“规划”很像。区别在于，MPC 的规划是**在线**的，每一步都要求解一个优化问题；强化学习的规划通常是**离线**的，训练出一个策略后，部署时只做前向传播。MPC 更准但更慢，强化学习更快但更依赖训练质量。

## 代价函数与约束

MPC 的优化目标是一个**代价函数**，而不是奖励函数。它通常写成：

$$
J = \sum_{k=0}^{H-1} \left( \|s_{t+k} - s_{\text{ref}}\|_Q^2 + \|a_{t+k}\|_R^2 \right) + \|s_{t+H} - s_{\text{ref}}\|_P^2
$$

第一项惩罚状态偏离参考轨迹，第二项惩罚动作太大，最后一项惩罚终端状态偏离参考。$Q$、$R$、$P$ 是权重矩阵，决定了 MPC “更在乎跟踪精度”还是“更在乎省力”。这就像强化学习里的奖励函数，只不过 MPC 把“好”定义成“代价小”，而且通常是二次型，方便求导和优化。

MPC 还有一个强化学习很难直接处理的东西：**约束**。机器人有关节角度限制、力矩上限、速度上限、避障要求，这些在 MPC 里可以写成硬约束：

$$
a_{\min} \leq a_{t+k} \leq a_{\max}, \quad s_{t+k} \in \mathcal{S}_{\text{safe}}
$$

硬约束保证了机器人永远不会做出危险动作。强化学习通常只能通过奖励惩罚来软性引导，但惩罚不能保证绝对安全。这是 MPC 在安全关键场景里的巨大优势。

### 倒立摆

用倒立摆来感受 MPC。状态是角度 $\theta$ 和角速度 $\dot{\theta}$，动作是施加的力矩 $u$。模型是：

$$
\ddot{\theta} = \frac{g}{l}\sin\theta + \frac{1}{m l^2} u
$$

MPC 在每一步：

1. 测量当前 $\theta$ 和 $\dot{\theta}$；
2. 用模型预测未来 20 步，假设力矩在这 20 步里变化；
3. 优化力矩序列，让摆角尽量回到 0，同时力矩不要太大；
4. 只施加第一个力矩；
5. 下一步重新测量，重新优化。

这个过程中，MPC 不需要“学习”。它只需要模型和优化器。如果模型准确，它就能稳住倒立摆。强化学习则需要成千上万次试验才能学会同样的任务。这就是 MPC 样本效率高的原因：**它把学习负担转移到了模型和优化上，而不是试错上。**

### MPC 与强化学习的对比

| 维度 | MPC | 强化学习 |
|:---|:---|:---|
| 需要模型 | 是，显式模型 | 无模型方法不需要，有模型方法需要 |
| 优化方式 | 在线优化 | 离线训练策略 |
| 样本效率 | 极高，几乎不需要试错 | 低，需要大量交互 |
| 计算开销 | 每一步都要解优化问题 | 部署时只需前向传播 |
| 约束处理 | 天然支持硬约束 | 通常用惩罚软约束 |
| 泛化能力 | 依赖模型精度 | 依赖训练分布 |
| 安全性 | 可保证 | 难以保证 |
| 实时性 | 计算量大时可能跟不上 | 前向传播快，实时性好 |

MPC 像一位精算师，每一步都要重新计算最优路径；强化学习像一位老司机，靠经验和直觉开车。精算师更准，但算得慢；老司机更快，但可能遇到没见过的情况就慌了。

### MPC 与强化学习的结合

最直接的一种结合是：**用 MPC 当老师，用强化学习当学生。** MPC 可以生成高质量的轨迹，这些轨迹被用来训练一个神经网络策略。学生策略部署时只做前向传播，比 MPC 快得多。这就是模仿学习里的行为克隆或 DAgger。在四足机器人上，这个思路取得了很好的效果：MPC 在仿真里生成稳定行走的轨迹，神经网络学会这些轨迹，然后部署到真机上，实时性远好于 MPC。

另一种结合是：**用强化学习改进 MPC 的模型。** MPC 的模型不准，强化学习可以从数据里学一个残差模型，补偿物理模型的误差。或者，用强化学习直接学一个策略，然后用 MPC 做安全过滤——策略输出的动作如果违反约束，MPC 就修正它。这被称为“安全强化学习”或“带约束的强化学习”。

还有一种更激进的结合：**用强化学习代替 MPC 的优化器。** MPC 每一步都要解一个优化问题，如果这个问题很复杂，实时性会受影响。有些工作训练一个神经网络来近似 MPC 的解，让它又快又准。这本质上是把 MPC 的知识蒸馏进神经网络。

## 总结

MPC 是控制领域的经典方法，它用模型预演未来，用优化选择动作，用滚动时域应对不确定性。它样本效率高、能处理约束、安全性好，但依赖模型精度、计算开销大。强化学习不需要模型、部署快、能处理高维感知，但样本效率低、约束处理弱、安全性难保证。

两者不是对立的。MPC 擅长“已知模型下的精细控制”，强化学习擅长“未知环境下的自适应学习”。最好的系统往往是两者的混血：用 MPC 生成示范，用强化学习加速；用强化学习补偿模型误差，用 MPC 保证安全；或者，用强化学习训练一个快速策略，用 MPC 做它的后备。

在机器人运动控制里，MPC 和强化学习正在从竞争走向合作。MPC 让机器人走得稳，强化学习让机器人学得快。而最终的目标，是让机器人既有 MPC 的精确，又有强化学习的灵活——像一个既会精算、又会直觉的老司机，在复杂的世界里稳稳前行。
