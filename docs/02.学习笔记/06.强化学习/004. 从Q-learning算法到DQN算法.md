# 从 Q-Learning 到 DQN

DQN（Deep Q-Network，深度 Q 网络）是深度强化学习中的经典算法。它将传统 Q-Learning 与深度神经网络结合起来，使智能体能够在连续状态空间、图像输入等复杂环境中学习动作价值，并通过价值评估选择动作。

理解 DQN，不能只记住它的损失函数，还需要理解三个核心问题：
- 为什么传统 Q-Learning 需要被神经网络替代？
- 为什么直接使用神经网络拟合 Q 值容易导致训练不稳定？
- Double DQN、Dueling DQN、优先经验回放等改进分别解决了什么问题？

## Q函数

Q 函数又称动作价值函数，用于评估智能体在状态 $s$ 下执行动作 $a$，随后按照策略行动所能获得的期望累积回报。

对于策略$\pi$，其动作价值函数定义为：

$$
Q^\pi(s,a)=\mathbb{E}_\pi\left[\sum_{k=0}^{\infty}\gamma^k r_{t+k}\mid s_t=s,a_t=a\right]
$$

直观来说，Q 值回答的是**在当前状态下，如果采取某个动作，长期来看这个动作有多好**？如果这些值来自最优动作价值函数$Q^*$，那么智能体可以通过选择 Q 值最大的动作来获得最优策略：

$$\pi^*=\arg\max_a Q(s,a)$$

需要注意，训练过程中的 Q 值通常只是当前估计，并不一定准确反映真实的长期回报。

### Q-Learning 如何更新 Q 值

传统 Q-Learning 使用一张 Q 表记录不同状态和动作对应的价值。

其更新公式为：

$$Q(s_t,a_t)\leftarrow Q(s_t,a_t)
+\alpha
\left[
r_t+\gamma\max_{a'}Q(s_{t+1},a')
-Q(s_t,a_t)
\right]$$

为了理解这个公式，可以把它拆成三个步骤。
1. **构造 TD 目标**：

$$y_t=r_t+\gamma\max_{a'}Q(s_{t+1},a')$$

TD目标由当前的真实奖励与下一状态的估计价值组成，如果下一状态已经终止，则不再计算未来价值，此时目标通常为$r_t$.

2. **计算 TD 误差**：

$$\delta_t=y_t-Q(s_t,a_t)=r_t+\gamma\max_{a'}Q(s_{t+1},a')-Q(s_t,a_t)$$

TD 误差表示当前预测与学习目标之间的差距，当$\delta_t>0$时，说明当前$Q$值偏低，需要向上调整，反之说明$Q$值偏高，需要往下调整。

3. **更新 $Q$ 值**

$$Q_{\text{new}}=Q_{\text{old}}+\alpha\delta_t$$

Q-Learning 不会直接把旧值替换为目标，而是按照学习率逐步修正。

### 为什么 Q-Learning 不够用

Q-Learning 的核心问题不在于更新公式，而在于$Q$表的表示能力有限。假设一个环境有$N$个离散状态和$A$个离散动作，那么 Q 表需要存储$N\times A$个数值。

在小型网格世界中，这没有问题。但在机器人环境中，状态中既有连续变量，也可能包含高维图像，连续状态通常有无限多个可能取值，无法为每个状态单独分配一个表格单元，因此，需要一种能够从**已有经验中泛化到相似状态**的方法。

### DQN的核心思想

DQN 用神经网络近似$Q$函数：

$$Q(s,a;\theta)\approx Q^*(s,a)$$

其中，$\theta$是神经网络的参数。网络输入当前状态，输出每个离散动作对应的$Q$值，例如，假设环境有 4 个离散动作：

$$s\xrightarrow{\text{Q 网络}}
[Q(s,a_1),Q(s,a_2),Q(s,a_3),Q(s,a_4)]$$

智能体选择$Q$值最大的动作，或者在训练阶段采用探索策略随机选择动作。

DQN 与 Q-Learning 的核心区别如下：

|对比维度|	Q-Learning|	DQN|
|:---:|:---:|:---:|
|Q 值表示方式|	Q 表|	神经网络
|状态空间|	通常要求有限、可枚举|	可以处理连续状态输入
|泛化能力|	不同表格状态之间没有直接共享参数|	相似状态可以共享|网络参数
|数据利用|	每次交互通常直接更新表格|	可以重复使用历史经验
|训练稳定性|	表格场景下相对容易分析|	需要处理函数逼近带来的不稳定性

这里需要明确：DQN 能够接收连续状态输入，但标准 DQN 仍然要求动作空间是有限的离散集合。它并不能直接解决任意连续动作控制问题。

## DQN 的数学原理

### 从贝尔曼最优方程出发

最优动作价值函数满足贝尔曼最优方程：

$$Q^* (s,a)=\mathbb{E}\left[r+\gamma\max_{a'}Q^*(s',a')\mid s,a\right]$$

这条公式表达了一个重要思想：当前动作的长期价值，等于当前奖励与下一状态最优长期价值的折扣和的期望。

DQN 并没有改变 Q-Learning 的基本学习目标，而是将原本保存在表格中的$Q$值改为由神经网络预测。由于实际训练时并不知道真实的$Q^*$，只能利用当前网络的估计构造学习目标。

### 构造TD目标

DQN 使用一个独立的目标网络估计下一状态的价值。在线网络参数为$\theta$，目标网络参数为$\theta^-$。一步 TD 目标为：

$$y_t=r_t+\gamma(1-d_t)\max_{a'}Q(s_{t+1},a';\theta^-)$$

其中，$d_t$是终止标记，若当前转移对应真正的终止状态，则$d_t=1$，否则为0，目标网络的作用是计算学习目标，而不是直接接受每一次梯度更新。

### 构造损失函数

对于一个经验样本，DQN 希望当前网络对实际执行动作的预测值接近 TD 目标。因此，可以定义平方 TD 误差：

$$L(\theta)=\mathbb{E}_{(s,a,r,s',d)\sim\mathcal D}\left[\left(y-Q(s,a;\theta)\right)^2\right]$$

其中，$\mathcal{D}$是经验回放池所代表的数据分布。实际训练时，从回放池中抽取一个包含$B$条经验的批次：

$$L(\theta)=\frac{1}{B}\sum_{i=1}^{B}\left(y_i-Q(s_i,a_i;\theta)\right)^2$$

随后使用反向传播计算梯度，并使用 Adam 等优化器更新在线网络参数：

$$
\theta\leftarrow\theta-\eta\nabla_\theta L(\theta)
$$

这里的$\eta$是神经网络优化器的学习率，不要与 Q-Learning 表格更新公式中的$\alpha$混淆。

### DQN训练的问题

如果只是把 Q 表换成神经网络，训练未必能够稳定进行，主要有两个原因。
- **连续采样的经验具有相关性**：智能体在相邻时刻采集的状态通常非常相似。如果每一步都立即使用最新样本更新网络，训练数据就会受到近期轨迹的强烈影响，导致梯度更新方向不稳定；
- **学习目标本身会不断变化**：DQN 的 TD 目标包含下一状态的 Q 值，而这个 Q 值也由神经网络估计。如果同一个网络既负责预测当前 Q 值，又不断改变未来价值的估计，学习目标就会随着参数更新而持续变化。这意味着 DQN 不仅在拟合数据，还在拟合一个由自身预测不断生成的目标。

为了解决这些问题，经典 DQN 引入了两个重要机制：
- **经验回放**（Experience Replay）：降低样本之间的时间相关性，并提高样本利用率。
- **目标网络**（Target Network）：暂时固定 TD 目标的估计参数，减少目标快速变化带来的不稳定。

## DQN的核心组件

### Q网络

Q 网络负责估计当前状态下所有离散动作的价值。对于低维状态，通常使用多层感知机MLP；对于图像输入，可以使用卷积神经网络CNN提取视觉特征。

$$
Q(s,\cdot;\theta)=W_2\operatorname{ReLU}(W_1s+b_1)+b_2
$$

输出层的维度等于离散动作数量。需要注意，Q 网络输出的是各动作的价值估计，而不是动作概率，因此一般不需要对输出使用 Softmax。

训练时，网络只取出实际执行动作对应的 Q 值进行损失计算$Q(s,a;\theta)$，而不是让所有动作的 Q 值都直接拟合当前样本的奖励。

### 经验回放

在标准 Q-Learning 中，智能体是一步一步走的，连续产生的数据高度相关：第$t$步的状态和$t+1$步的状态只有一点点差别，第$t$步拿到的奖励和$t+1$步的奖励往往同增同减。如果直接用这些连续样本来训练神经网络，网络会被最近的经验牵着走——就像你学开车，只看最近三秒钟的录像，每三秒换一条路，你永远学不会应对各种路况。这种数据相关性会让梯度估计产生严重偏差，训练极易震荡甚至发散。

经验回放的解决方案非常优雅：把智能体过去的所有经验$(s_t,a_t,r_{t+1},s_{t+1},a_{t+1},r_{t+2},\cdots)$存进一个**经验回放池**,训练时不再使用最新的连续数据，而是从池子里随机抽取一小批样本。随机采样打破了样本之间的时间相关性，让每批数据都像是从经验分布中独立同分布地抽取出来的。这相当于把“只看最近三秒的录像”变成了“从整个驾驶生涯中随机抽查片段”，网络可以在每一批数据中看到各种不同的路况，学习更加稳定。

经验回放还带来了一个额外的好处：**每条经验可以被反复利用**。在标准 Q-Learning 中，一条经验用过一次就被丢掉了。但在经验回放池中，这条经验可能在几百次训练中被反复采样，每次都对网络参数的更新贡献一份力量。这大大提高了样本效率——在机器人控制中，这意味着你需要更少的真实交互就能训练出可用的策略。

经验回放的实现很简单：维护一个固定容量的队列，新经验存进去，旧经验自动挤出去，训练时随机采样一个 batch。但容量大小的选择需要平衡：太小，经验多样性不足；太大，旧经验可能已经过时，而且采样效率降低。实践中，Atari 游戏通常用 100 万条经验，机器人控制任务用 10 万到 100 万条不等。

```python
class ReplayBuffer:
    def __init__(self, capacity):
        self.buffer = deque(maxlen=capacity)

    def push(self, state, action, reward, next_state, done):
        self.buffer.append((state, action, reward, next_state, done))

    def sample(self, batch_size):
        batch = random.sample(self.buffer, batch_size)
        states, actions, rewards, next_states, dones = zip(*batch)
        return (np.array(states), np.array(actions), np.array(rewards),
                np.array(next_states), np.array(dones))

    def __len__(self):
        return len(self.buffer)
```

### 目标网络

在 Q-Learning 中，更新目标$y=r+\gamma \max_{a^{\prime}}Q(s^{\prime},a^{\prime})$里的$Q(s^{\prime},a^{\prime})$就是网络自己的预测。也就是说，网络在用自己当前的估计去更新自己，这被称为**自举**（bootstrapping）。监督学习里标签是固定的，但 DQN 的“标准答案”来自网络自己对未来的估计。当网络参数更新时，目标值也在不断变化，网络就像在追一个自己一直在移动的目标，很容易陷入震荡甚至发散。

目标网络的解决方案是：用两个网络，**一个负责预测，一个负责生成目标**。 预测网络$Q(s,a;\theta)$每一步都在更新，负责估计当前状态动作的价值；目标网络$Q(s,a;\theta^-)$的参数每隔一段时间才从预测网络复制一次，在两次复制之间保持不变。这样，训练目标在一段时间内是冻结的，网络可以朝着一个相对稳定的方向去逼近，训练稳定性大幅提升。

目标网络的更新有两种方式。**硬更新**是每$C$ 步把预测网络的参数直接复制给目标网络：

$$\theta^-\leftarrow \theta$$

这是原始 DQN 的做法，$C$通常取几千步。

**软更新**是每一步都让目标网络慢慢向预测网络靠拢：

$$\theta^-\leftarrow \tau\theta+(1-\tau)\theta^-$$

其中$\tau$是一个很小的数，软更新让目标网络变化更平滑，通常训练更稳定，但收敛速度可能稍慢。

把经验回放和目标网络放在一起，DQN 的完整训练流程如下：
1. 初始化预测网络$Q(s,a;\theta)$和目标网络$Q(s,a;\theta^-)$，让$\theta^-=\theta$;
2. 初始化经验回放池$\mathcal{D}$，容量为$N$;
3. 对每个回合：
   1. 观察初始状态$s_0$;
   2. 对于每个时间步$t$：
      1. 用$\epsilon$-greedy策略选择动作$a_t$;
      2. 执行动作，观察奖励$r_t$和新状态$s_{t+1};
      3. 把$(s_t,a_t,r_t,s_{t+1})$存入回放池；
      4. 从回放池中随机采样一个 batch；
      5. 用目标网络计算 TD 目标$y=r+\gamma\max_{a^\prime}Q(s^\prime,a^\prime;\theta^-)$；
      6. 计算损失$L=(y-Q(s,a;\theta))^2$,做梯度下降；
      7. 每隔$C$步，把预测网络的参数复制给目标网络;
   3. 衰减$\epsilon$

## 过估计问题与 Double DQN

DQN 虽然强大，但并非没有缺陷。训练一段时间后，研究者注意到一个奇怪的现象：$Q$值会莫名其妙地增长到很大，智能体变得异常自信，坚信某些动作价值极高。实际跑起来却发现这些“黄金动作”根本靠不住，部分游戏的表现甚至开始崩盘。

DQN 的目标值是 $y=r+\gamma\max_{a^\prime}Q(s^\prime,a^\prime;\theta^-)$，这里有一个致命问题：用同一套 Q 值既做动作选择，又做价值评估。当 Q 值本身带噪声时，$\max$操作会系统性地挑出那些被高估的值，就像让 10 个人猜股价，真实价格 50 块，猜测结果分散在 45 到 55 之间，取最大值 55 肯定会偏高。数学上，这是 Jensen 不等式的结果：

$$\mathbb{E}\left[\max(X_1,X_2,\ldots,X_n)\right]\geq\max\left(\mathbb{E}[X_1],\mathbb{E}[X_2],\ldots,\mathbb{E}[X_n]\right)$$

最大值的期望总是大于等于期望的最大值。过估计会导致收敛变慢，智能体把时间浪费在探索那些被高估的动作上；策略质量打折扣，高噪声的动作可能比真正好的动作更受青睐；更糟的是过估计会不断累积，导致训练发散。

Double DQN 的解决方案非常巧妙：把动作选择和动作评估拆开，用两个不同的网络来做。 具体来说，用预测网络$Q(s^\prime,a^\prime;\theta)$来选择最优动作，用目标网络$Q(s^\prime,a^\prime;\theta^-)$来评估这个动作的价值。

$$y=r+\gamma Q(s^{\prime},\arg\max_{a^{\prime}}Q(s^{\prime},a^{\prime};\theta);\theta^-)$$

为什么有效呢？假设预测网络把动作$a$的价值估高了，目标网络（参数不同）大概率不会犯同样的错。两个网络的误差相互独立，倾向于抵消而非累加。最通俗的解释是：DQN 像是自己给菜打分、自己挑菜吃，烂菜可能就混进来了；Double DQN 让朋友打分、你来挑，两边的误差对冲掉了。

## Dueling DQN

Double DQN 解决了过估计，但还有一个更深层的问题：在某些状态下，动作之间的价值差异很小，真正重要的是状态本身好不好。比如在一条直路上开车，无论你稍微偏左还是偏右，价值都差不多；但如果前面是悬崖，无论你怎么打方向盘，价值都很低。DQN 的单一$Q$输出把“状态本身好不好”和“某个动作相对其他动作好多少”混在一起，导致学习效率不高。

Dueling DQN 把$Q$值拆成两部分：状态价值$V(s)$和动作优势函数$A(s,a)$。

![](https://picupload-1330431167.cos.ap-guangzhou.myqcloud.com/images/20261009164234718.png)

状态价值衡量“处于这个状态本身有多好”，动作优势衡量“在这个状态下选择某个动作比平均水平好多少”，$Q$值是两者的组合。

$$Q(s,a;\theta,\alpha,\beta)=V(s;\theta,\beta)+A(s,a;\theta,\alpha)$$

其中$\theta$代表网络结构，$\alpha$和$\beta$表示两个全连接层的网络参数，不再让神经网络直接输出$Q$值，而是训练神经网络的最后几层的两个分支，分别输出状态价值函数和优势函数，再求和得到$Q$值。

它存在对于$V$值和$A$值建模不唯一的问题，例如，对于同样的$Q$值，如果将$V$值加上任意常数$C$，再将所有$A$值减去$C$，则得到的$Q$值依然不变，这就导致了训练的不稳定性。

为了解决这个问题，Dueling DQN强制最优动作的优势函数的实际输出为0，即

$$Q(s,a;\theta,\alpha,\beta)=V(s;\theta,\beta)+(A(s,a;\theta,\alpha)-\max_{a^{\prime}\in\mathcal{A}}A(s,a^\prime;\theta,\alpha))$$

此时的$V(s;\theta,\beta)=\max_{a}Q(s,a;\theta,\alpha,\beta)$，也就是
$$a^*=\arg\max_{a^{\prime}\in\mathcal{A}}Q\left(s,a^{\prime};\theta,\alpha,\beta\right)=\arg\max_{a^{\prime}\in\mathcal{A}}A\left(s,a^{\prime};\theta,\alpha\right)$$

这样可以确保$V$值建模的唯一性。在实现过程中，我们还可以用平均代替最大化操作:

$$Q(s,a)=V(s)+A(s,a)-\frac{1}{|\mathcal{A}|}\sum_{a^{\prime}}A(s,a^{\prime})$$

## 优先经验回放

经验回放随机采样虽然打破了相关性，但它有一个隐含的假设：所有经验同等重要。实际上，有些经验比另一些更有价值，那些 TD 误差大的经验，意味着网络对它们的预测严重偏离了目标，正是最需要学习的样本。

优先经验回放（Prioritized Experience Replay）用 TD 误差来衡量每条经验的重要性，采样概率与 TD 误差的绝对值成正比。

$$p_i=|\delta_i|+\epsilon$$

其中$\delta_i$是第$i$条经验的TD误差， $\epsilon$是一个很小的正数，确保每条经验都有被采样的可能。采样概率为：

$$P(i)=\frac{p_i^\alpha}{\sum_j p_j^\alpha}$$

其中$\alpha$ 控制优先级的影响程度，$\alpha=0$退化为均匀采样，$\alpha=1$则完全按 TD 误差采样，实际上通常取$\alpha=0.6$在重点学习难样本和不忽略简单样本之间取得平衡。

由于优先级采样改变了数据的分布，会引入偏差，所以需要用重要性采样权重来修正：

$$w_i=\left(\frac{1}{N\cdot P(i)}\right)^\beta$$

$\beta$从初始值（比如 0.4）逐渐增大到 1，训练初期偏差修正较弱，后期逐渐加强，优先经验回放通常能让 DQN 收敛更快。
