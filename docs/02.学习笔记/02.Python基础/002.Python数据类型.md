# Python 的数据类型到底该怎么选？一篇讲清楚

这篇文章系统地讲一遍 Python 内置的数据类型：数字、字符串、字节、布尔、容器，以及它们背后的实现细节和常见坑。适合刚入门、或者「会写但总觉得某些行为很玄学」的同学。读完你至少能掌握三件事：**各类型怎么选、为什么有些代码结果出乎意料、如何避开那些经典坑**。

## 数字类型

### int / float / complex

**是什么**：Python 内置三种数字类型——整数 `int`、浮点数 `float`、复数 `complex`。日常写代码里 90% 用到的是前两个，复数在做科学计算、信号处理时会碰到。

```python
a = 10          # int
b = 3.14        # float
c = 1 + 2j      # complex

print(type(a), type(b), type(c))
# <class 'int'> <class 'float'> <class 'complex'>

print(isinstance(a, int))     # True
print(isinstance(b, float))   # True
print(isinstance(c, complex)) # True

# 复数取实部 / 虚部
print(c.real, c.imag)
# 1.0 2.0

# 常用算术运算
print(5 / 2)     # 2.5   普通除法，总是返回 float
print(5 // 2)    # 2     整除（向下取整）
print(5 % 2)     # 1     取余
print(2 ** 3)    # 8     幂
```

**注意点**：

- `/` 即使两个整数相除也返回 `float`，要得到整数用 `//`。
- `//` 是「向下取整」，所以 `-5 // 2` 结果是 `-3` 而不是 `-2`。

```python
print(-5 // 2)   # -3  向下取整
print(-5 / 2)    # -2.5
```

### int 的任意精度与小整数缓存

**是什么**：这是 Python `int` 最反直觉的两点，也是面试高频。

**CPython 实现细节①：小整数缓存**。CPython 启动时会**预先创建好 `-5` 到 `256` 这一批整数对象**，之后用到这些值时直接复用同一个对象，不再新建。

```python
a = 256
b = 256
print(a is b)   # True  # 落在 [-5, 256]，复用同一对象

# 注意：不能直接写 x = 257; y = 257，那样会被编译器合并成同一个常量
def make_257():
    n = 256
    return n + 1     # 运行时才算出的 257，不在缓存内

x = make_257()
y = make_257()
print(x is y)   # False # 超出缓存，每次新建对象
```

**CPython 实现细节②：任意精度整数**。C 语言的 `int` 通常是 32 位、`long` 是 64 位，会溢出。但 Python 的 `int` 是**任意精度**的——只要内存够，你想写多大的整数都行，不存在「溢出」。底层用变长的 `PyLongObject` 存储（本质是一个 30 位一组的数字数组）。

```python
big = 2 ** 1000
print(len(str(big)))      # 302  一个 302 位的大整数，没有溢出
print(big.bit_length())   # 1001 二进制占 1001 位
```

**注意点**：

- `is` 比较的是**对象身份**（是不是同一个对象），`==` 比较的是**值**（内容相不相等）。判断数值请永远用 `==`，别用 `is`——小整数缓存只是 CPython 的实现细节，换实现或换版本就可能不一样。
- 虽然 `int` 不会溢出，但大整数运算**更慢、更占内存**，能不做超大整数就不要做。

### float 的 IEEE 754 陷阱

**是什么**：`float` 底层是 **IEEE 754 双精度浮点数**（64 位）。它是**二进制**浮点，而很多十进制小数（比如 `0.1`）在二进制里是无限循环小数，只能截断存储，于是产生误差。

**常见误区一（可运行反例）**：

```python
print(0.1 + 0.2)            # 0.30000000000000004
print(0.1 + 0.2 == 0.3)     # False  # 直觉上应该是 True，结果不是！
```

**正确比较姿势**：

```python
import math
print(math.isclose(0.1 + 0.2, 0.3))   # True  用近似相等来判断
```

**注意点**：

- 浮点数之间**不要用 `==` 做相等判断**，用 `math.isclose`（或自己写误差容差）。
- 需要精确十进制（比如金额）的场景，请看下面的 `Decimal`。
- `float` 还能表示 `inf`（无穷大）、`nan`（非数），且 `nan != nan` 恒为 `True`。

```python
print(float("inf"))   # inf
print(float("nan"))   # nan
print(float("nan") == float("nan"))  # False
```

### Decimal 与 Fraction：需要「精确」时再用

**是什么**：

- `Decimal`：十进制浮点数，能**精确**表示 `0.1`、`0.2` 这类十进制小数，适合**金融、货币**等要求精确的场景。
- `Fraction`：用分子/分母表示**有理数**，适合需要做精确分数运算（如 `1/3`）的场景。

```python
from decimal import Decimal
print(Decimal("0.1") + Decimal("0.2"))   # 0.3  # 精确

from fractions import Fraction
print(Fraction(1, 3) + Fraction(1, 6))   # 1/2  # 精确有理数
```

**注意点**：

- `Decimal` 一定要用**字符串**构造：`Decimal("0.1")`。如果用 `Decimal(0.1)`，传入的 `0.1` 已经是失真的 float，误差会被带进来。

```python
print(Decimal(0.1))        # 0.1000000000000000055511151231257827021181583404541015625
print(Decimal("0.1"))      # 0.1
```

- `Decimal` 和 `Fraction` 计算速度远慢于 `int`/`float`，只有真需要精确时才用。

## 字符串与字节

### 字符串的不可变性

**是什么**：`str` 表示 Unicode 文本。字符串一旦创建就**不能原地修改**，所有看起来「改了」的操作，其实都是**返回一个新字符串**。

```python
s = "hello"
# s[0] = "H"   # TypeError: 'str' object does not support item assignment

s2 = s.replace("h", "H")
print(s)    # hello  原对象没变
print(s2)   # Hello  新对象
```

**注意点**：因为不可变，**频繁拼接**字符串时，用 `+` 会不断创建中间对象，性能差；应优先用 `"".join(...)`。

```python
parts = ["a", "b", "c"]
print("".join(parts))   # abc
```

### 编码：str 与 bytes 的桥梁

**是什么**：`str` 是抽象的「字符」，存到磁盘或网络传输时要变成字节序列，这一步叫编码 `encode`；反过来叫解码 `decode`。最常用的编码是 UTF-8。

```python
s = "你好"
b = s.encode("utf-8")
print(b)                    # b'\xe4\xbd\xa0\xe5\xa5\xbd'
print(b.decode("utf-8"))    # 你好
print(len(s), len(b))       # 2 6  一个中文字符在 UTF-8 里占 3 字节
```

**注意点**：`len` 对 `str` 数的是**字符数**，对 `bytes` 数的是**字节数**，别搞混。

### 常用方法

```python
s = "Hello, World"

print(s.lower())          # hello, world
print(s.upper())          # HELLO, WORLD
print(s.strip())          # Hello, World  去首尾空白
print(s.split(", "))      # ['Hello', 'World']
print(", ".join(["a", "b"]))  # a, b
print(s.startswith("He"))     # True
print(s.find("World"))        # 7  找不到返回 -1
print(s.count("o"))           # 2
print(s.isdigit())            # False
```

### f-string

**是什么**：Python 3.6+ 引入的格式化字符串，`f"{变量}"` 直接嵌入表达式，是现在最推荐、最易读的写法。

```python
name = "小明"
age = 18
print(f"{name} 今年 {age} 岁")    # 小明 今年 18 岁
print(f"{age + 1 = }")           # age + 1 = 19   # 3.8+ 自解释
print(f"{3.14159:.2f}")          # 3.14   保留两位小数
print(f"{1000:,}")               # 1,000  千分位
print(f"{0.25:.1%}")             # 25.0%  百分比
```

**CPython 实现细节③：字符串驻留（intern）**。对于短小的、形似标识符的字符串（纯字母/数字/下划线），CPython 会把相同内容**驻留**成同一个对象来省内存。所以下面这个 `is` 判断恰好是 `True`——但它和小整数缓存一样，是**实现细节**，别依赖它。

```python
a = "hello"
b = "hello"
print(a is b)   # True  # 被驻留，同一对象
```

**注意点**：判断字符串相等请用 `==`，不要用 `is`。驻留只对部分字符串生效，长字符串、带空格或运行时拼接的结果通常不驻留。

### bytes 与 str：文本与字节的分界线

**是什么**：这是 Python 3 里最重要的一对区别。

- `str`：**文本**，一串 Unicode 码点，表示「人类读的字符」。
- `bytes`：**字节**，一串 0~255 的整数，表示「机器存的二进制」。

两者**不能直接混用**，必须通过 `encode` / `decode` 显式转换。

```python
s = "hello"
b = b"hello"
print(type(s), type(b))      # <class 'str'> <class 'bytes'>

print(s.encode())            # b'hello'  默认 utf-8
print(b.decode())            # hello

# bytes 不可变；bytearray 是可变版
ba = bytearray(b"hello")
ba[0] = 72
print(ba)                    # bytearray(b'Hello')
```

**注意点**：

- 读文件、收网络数据拿到的通常是 `bytes`，要先 `decode` 成 `str` 才能当文本处理；写文件、发网络数据前要把 `str` `encode` 成 `bytes`。
- `str + bytes` 会直接报 `TypeError`，这是 Python 3 刻意设计来逼你明确处理编码，避免 Python 2 时代常见的乱码问题。
## 布尔、None 与类型转换

### 布尔与 None 的真值规则

**是什么**：`bool` 只有 `True` / `False` 两个值，且 `bool` 是 `int` 的**子类**。`None` 是一个单独的类型 `NoneType`，表示「没有值」。

```python
print(issubclass(bool, int))   # True
print(True + 1)                # 2  # True 本质是 1

# 真值规则：以下都是 Falsy（条件判断里视作 False）
falsy = [None, False, 0, 0.0, "", [], {}, set(), ()]
print([bool(x) for x in falsy])
# [False, False, False, False, False, False, False, False, False]

# None 判断用 is
x = None
print(x is None)   # True
```

**注意点**：

- 记住 Falsy 清单：`None`、`False`、`0` / `0.0`、空字符串、空容器。**其余全是 Truthy**，包括 `" "`（含空格）、`[0]`、`0.1`。
- 判断 `None` 用 `is None`，不用 `== None`（更清晰、也更快）。

### 类型转换规则

**是什么**：用内置构造器在类型之间显式转换，规则要记牢，尤其 `int` 的截断行为。

```python
print(int("42"))       # 42
print(int(3.9))        # 3   # 截断，不是四舍五入
print(float("3.14"))   # 3.14
print(str(100))        # '100'
print(bool(""))        # False
print(bool("x"))       # True
print(list("abc"))     # ['a', 'b', 'c']
print(tuple([1, 2]))   # (1, 2)
print(set([1, 1, 2]))  # {1, 2}
print(dict([("a", 1)])) # {'a': 1}
```

**注意点**：

- `int(3.9)` 是**直接截断**成 `3`，要四舍五入用 `round(3.9)`。
- 不能转换会抛 `ValueError`（如 `int("abc")`）或 `TypeError`，别硬转，必要时先判断或用 `try`。

## 可变与不可变

### 可变 vs 不可变的根本区别

**是什么**：这是理解 Python 一切「玄学行为」的地基。

- **不可变**：`int`、`float`、`str`、`tuple`、`bool`、`None`、`frozenset`。值一旦创建就不能改，「修改」其实是返回新对象。
- **可变**：`list`、`dict`、`set`、`bytearray`。值可以原地改，多个引用会互相影响。

**代码（用 `id` 看对象身份）**：

```python
# 不可变：改了之后是不同对象
x = 100
print(id(x))
x = x + 1
print(id(x))   # 地址变了，是新对象

# 可变：原地改，地址不变
lst = [1, 2]
print(id(lst))
lst.append(3)
print(id(lst))   # 地址不变，还是同一个对象
```

### 误区二：可变默认参数（可运行反例）

```python
def add_item(item, lst=[]):
    lst.append(item)
    return lst

print(add_item(1))   # [1]
print(add_item(2))   # [1, 2]  # 不是 [2]！默认空列表被共享了
```

**原因**：默认参数 `lst=[]` 在**函数定义时只创建一次**，之后每次调用都复用同一个列表。**正确写法**是用 `None` 作默认值：

```python
def add_item(item, lst=None):
    if lst is None:
        lst = []
    lst.append(item)
    return lst

print(add_item(1))   # [1]
print(add_item(2))   # [2]  这次对了
```

### 误区三：`is` 与 `==`、赋值与拷贝（可运行反例）

```python
a = [1, 2, 3]
b = [1, 2, 3]
print(a == b)   # True  值相等
print(a is b)   # False 不是同一对象

# 赋值是共享引用，不是拷贝
c = a
c.append(4)
print(a)   # [1, 2, 3, 4]  # a 也被改了！

# 浅拷贝：复制一层
d = a.copy()
d.append(5)
print(a)   # [1, 2, 3, 4]
print(d)   # [1, 2, 3, 4, 5]
```

**注意点**：

- `is` 判断「是不是同一个对象」，`==` 判断「值相不相等」。判断相等请用 `==`。
- `=` 赋值只是把多个名字绑到同一个对象上；想真正复制一份，用 `.copy()` 或 `copy` 模块。浅拷贝只复制第一层，嵌套可变对象仍需小心。

## 容器类型的选择与类型注解

### 容器：list / tuple / dict / set

**是什么**：四种最常用的容器，各有定位，选对能少写很多代码。

```python
lst = [1, 2, 3]         # 列表：有序、可变、可重复
tup = (1, 2, 3)         # 元组：有序、不可变
d = {"a": 1, "b": 2}    # 字典：键值对，键唯一
s = {1, 2, 3}           # 集合：无序、自动去重

# list 常用
lst.append(4)
lst.insert(0, 0)
lst.pop()
print(lst[1:3])         # [1, 2]  切片

# dict 常用
d["c"] = 3
print(d.get("x", 0))    # 0  取不到给默认值，不报错

# set 常用
s.add(4)
print(1 in s)           # True  集合判断成员是 O(1)
```

**对比表**：

| 特性 | list | tuple | dict | set |
|------|------|-------|------|-----|
| 是否有序 | ✅ | ✅ | ✅（3.7+） | ❌ |
| 是否可变 | ✅ | ❌ | ✅ | ✅ |
| 元素可重复 | ✅ | ✅ | 键不可重复 | ❌ 自动去重 |
| 索引 / 切片 | ✅ | ✅ | ❌ | ❌ |
| 成员查找复杂度 | O(n) | O(n) | O(1) | O(1) |
| 典型场景 | 有序可变集合 | 不变数据、多返回值 | 键值映射 | 去重、集合运算 |

**注意点**：

- **什么时候选 tuple 而不是 list**：数据不会改、想表示「结构」（如坐标 `(x, y)`）、函数返回多个值、或用它做 dict 的键（list 不可哈希，不能做键，tuple 可以）。
- **为什么 dict 和 set 查找是 O(1)**：CPython 底层用**哈希表**实现，通过哈希值直接定位桶位置；list 则是**动态数组**，查找要逐个比，是 O(n)。

```python
# tuple 能做 dict 的键，list 不行
d2 = {(1, 2): "point"}
print(d2[(1, 2)])   # point
```

### 类型注解基础

**是什么**：Python 3.5+ 支持给变量、函数参数、返回值写**类型提示**。它只是「提示」，运行时**不做强制校验**，主要靠 `mypy` / `pydantic` 等工具做静态检查。

```python
def greet(name: str, age: int = 0) -> str:
    return f"{name} {age}"

x: int = 10
names: list[str] = ["a", "b"]   # 3.9+ 内置泛型写法

from typing import Optional, Union

def find(s: str) -> Optional[int]:   # 可能返回 int 或 None
    return len(s) if s else None

def to_str(v: Union[int, float]) -> str:  # 3.10+ 可写成 int | float
    return str(v)

print(greet("小明", 18))   # 小明 18
print(find(""))           # None
```

**注意点**：

- 注解不改变运行时行为：`greet(123, "x")` 依然能跑，不会报类型错误。
- 想真正利用注解，就配上 `mypy` 检查或 `pydantic` 做数据校验。Python 3.10+ 可以用 `int | float` 代替 `Union[int, float]`，更简洁。

## 小结

这篇文章串起了一条主线：**数字 → 字符串/字节 → 布尔 → 容器 → 可变性 → 注解**。核心结论其实就几条：

1. **判断相等用 `==`，判断「同一个对象」才用 `is`**——小整数缓存和字符串驻留是 CPython 的实现细节，别当语言特性用。
2. **浮点数是近似值**，别用 `==` 比较，需要精确用 `Decimal` / `Fraction`。
3. **可变 vs 不可变**是理解默认参数陷阱、赋值与拷贝、`id()` 变化的钥匙。

### 几个常见问题

**Q1：`0.1 + 0.2` 为什么不是 `0.3`？**
因为 `float` 是二进制浮点，`0.1` 和 `0.2` 在二进制里都是无限循环小数，存储时有截断误差。用 `math.isclose` 比较，或改用 `Decimal`。

**Q2：什么时候用 `is`，什么时候用 `==`？**
`is` 只在判断「是否是同一个对象」时用（最典型是 `x is None`）。判断值相等一律 `==`。

**Q3：默认参数 `lst=[]` 为什么有坑？**
默认值在函数**定义时**就创建并绑定，之后每次调用复用同一对象。要写成 `lst=None`，函数体内再新建。

**Q4：list 和 tuple 到底怎么选？**
数据会变、需要增删改 → `list`；数据是固定的结构、想当 dict 键、或表示不可变记录 → `tuple`。

### 本篇知识地图

| 知识点 | 一句话要点 | 关键结论 |
|--------|-----------|---------|
| 数字类型 | int / float / complex | `/` 返回 float，`//` 向下取整 |
| int 任意精度 | 不溢出，底层变长存储 | 大整数慢但安全 |
| 小整数缓存 | `[-5, 256]` 复用同一对象 | 别用 `is` 判断数值 |
| float 陷阱 | IEEE 754 有精度误差 | 用 `isclose` 比较 |
| Decimal / Fraction | 精确十进制 / 分数 | 金融用 Decimal，构造用字符串 |
| 字符串 | 不可变、Unicode、f-string | 拼接用 join，比较用 `==` |
| bytes vs str | 字节 vs 文本 | 必须 encode / decode |
| 布尔与 None | bool 是 int 子类 | 记住 Falsy 清单，`is None` 判断 |
| 类型转换 | 构造器显式转换 | `int(3.9)` 是截断 |
| 可变 vs 不可变 | 对象能否原地改 | 默认参数、赋值拷贝都源于此 |
| 容器选择 | list / tuple / dict / set | 查重用 set，映射用 dict |
| 类型注解 | 提示而非强制 | 配 mypy / pydantic 才生效 |
