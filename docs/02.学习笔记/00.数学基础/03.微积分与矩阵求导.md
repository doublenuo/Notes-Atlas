> **本章定位**：反向传播、策略梯度、雅可比矩阵、线性化、牛顿法，本质上都是**求导**。本章的目标不是做题，而是让你能**独立推导一层神经网络的梯度、读懂机器人雅可比、看懂策略梯度里每一项从哪来**，并能用数值方法验证自己的推导。

## 1. 单变量微积分回顾

### 1.1 导数与局部线性近似

函数 $f$ 在 $x$ 处的导数：

$$
f'(x)=\lim_{h\to0}\frac{f(x+h)-f(x)}{h}
$$

**核心思想**：在 $x$ 附近，函数可以用一条直线近似

$$
f(x+h)\approx f(x)+f'(x)\,h
$$

后面所有"线性化""梯度""雅可比"都是这个想法的多维推广。

### 1.2 常用导数

| 函数 | 导数 | 备注 |
|---|---|---|
| $x^n$ | $nx^{n-1}$ | |
| $e^x$ | $e^x$ | |
| $\ln x$ | $1/x$ | 对数概率的导数 |
| $\sin x,\ \cos x$ | $\cos x,\ -\sin x$ | 旋转矩阵、雅可比 |
| $\sigma(x)=\dfrac{1}{1+e^{-x}}$ | $\sigma(x)\big(1-\sigma(x)\big)$ | Sigmoid |
| $\tanh x$ | $1-\tanh^2x$ | 策略网络常用激活 |
| $\text{ReLU}(x)=\max(0,x)$ | $\mathbb{1}[x>0]$ | 在 0 处取次梯度 |
| $\text{ELU},\ \text{GELU}$ | 查表或自动求导 | |

### 1.3 求导法则

- 乘法：$(uv)'=u'v+uv'$
- 商：$(u/v)'=(u'v-uv')/v^2$
- **链式法则**：$\dfrac{d}{dx}f(g(x))=f'(g(x))\,g'(x)$

> 深度网络是 $f_L(\cdots f_2(f_1(x)))$ 的复合，反向传播就是**把链式法则从输出端向输入端逐层连乘**。

### 1.4 泰勒展开

$$
f(x+h)=f(x)+f'(x)h+\frac12f''(x)h^2+\cdots
$$

| 展开阶数 | 用途 |
|---|---|
| 一阶 | 线性化（LQR、EKF）、梯度下降的理论基础 |
| 二阶 | 牛顿法、判断极值、PPO 代理目标的 KL 二阶近似 |

常用近似：$\sin\theta\approx\theta$，$\cos\theta\approx1-\theta^2/2$（小角度），$\ln(1+x)\approx x$。

> **小角度近似**是倒立摆线性化的基础：$\sin\theta\approx\theta$ 使非线性动力学变成线性系统，才能套用 LQR。

### 1.5 积分的两点提醒

本课程用到的积分极少，记住两点即可：

- **期望就是积分**：$\mathbb{E}[f(x)]=\int f(x)p(x)\,dx$，实际中用采样近似
- **动力学积分**：状态 $x_{t+1}=x_t+\int_t^{t+\Delta t}\dot{x}\,d\tau$，仿真器用数值积分（显式欧拉、半隐式欧拉、RK4）实现。步长太大会不稳定，这也是仿真频率与控制频率要分开设置的原因之一

## 2. 多元微积分

### 2.1 偏导数与梯度

对标量函数 $f:\mathbb{R}^n\to\mathbb{R}$，**梯度**是所有偏导数组成的列向量：

$$
\nabla f(\mathbf{x})=\begin{bmatrix}\dfrac{\partial f}{\partial x_1}\\\vdots\\\dfrac{\partial f}{\partial x_n}\end{bmatrix}
$$

**几何意义**：

- 梯度指向函数**上升最快**的方向，负梯度是下降最快的方向
- 梯度与等值线（等高线）垂直
- 梯度的模是最陡的变化率

**方向导数**：沿单位向量 $\mathbf{u}$ 的变化率为 $\nabla f^\top\mathbf{u}$。

**一阶近似**：

$$
f(\mathbf{x}+\boldsymbol\delta)\approx f(\mathbf{x})+\nabla f(\mathbf{x})^\top\boldsymbol\delta
$$

**梯度下降**由此而来：取 $\boldsymbol\delta=-\eta\nabla f$，则 $f$ 的变化约为 $-\eta\|\nabla f\|^2\le0$。

### 2.2 雅可比矩阵

对向量函数 $\mathbf{f}:\mathbb{R}^n\to\mathbb{R}^m$，**雅可比矩阵**是 $m\times n$ 矩阵：

$$
J=\frac{\partial\mathbf{f}}{\partial\mathbf{x}}=\begin{bmatrix}\dfrac{\partial f_1}{\partial x_1}&\cdots&\dfrac{\partial f_1}{\partial x_n}\\\vdots&\ddots&\vdots\\\dfrac{\partial f_m}{\partial x_1}&\cdots&\dfrac{\partial f_m}{\partial x_n}\end{bmatrix},\qquad J_{ij}=\frac{\partial f_i}{\partial x_j}
$$

- 第 $i$ 行是 $f_i$ 的梯度的转置
- 一阶近似：$\mathbf{f}(\mathbf{x}+\boldsymbol\delta)\approx\mathbf{f}(\mathbf{x})+J\boldsymbol\delta$
- **雅可比是"局部最佳线性近似"**：它把输入的微小变化映射为输出的微小变化

> **三个最重要的雅可比**：
> 1. **机器人运动学**：$\mathbf{x}_{\text{ee}}=\text{FK}(\mathbf{q})$，则 $\dot{\mathbf{x}}_{\text{ee}}=J(\mathbf{q})\dot{\mathbf{q}}$，把关节速度映射为末端速度
> 2. **动力学线性化**：$\dot{\mathbf{x}}=f(\mathbf{x},\mathbf{u})$，$A=\partial f/\partial\mathbf{x}$，$B=\partial f/\partial\mathbf{u}$
> 3. **神经网络层**：每一层的雅可比参与反向传播

### 2.3 Hessian 矩阵

标量函数的二阶偏导数矩阵：

$$
H=\nabla^2f,\qquad H_{ij}=\frac{\partial^2f}{\partial x_i\partial x_j}
$$

- 当二阶偏导连续时 $H$ **对称**
- 二阶泰勒展开：

$$
f(\mathbf{x}+\boldsymbol\delta)\approx f(\mathbf{x})+\nabla f^\top\boldsymbol\delta+\frac12\boldsymbol\delta^\top H\boldsymbol\delta
$$

**极值的二阶条件**（在 $\nabla f=0$ 处）：

| Hessian | 结论 |
|---|---|
| 正定 | 局部极小点 |
| 负定 | 局部极大点 |
| 不定 | 鞍点 |

> 高维神经网络损失面上**鞍点远多于局部极小点**。$H$ 的特征值分布描述了曲面的弯曲程度，最大特征值与最小特征值之比（条件数）越大，梯度下降越慢、越容易震荡，这就是自适应优化器（Adam）与归一化（BatchNorm、观测归一化）有用的原因。

> 与上一章呼应：二次函数 $f=\tfrac12\mathbf{x}^\top A\mathbf{x}$ 的 Hessian 就是 $A$。

### 2.4 多元链式法则

设 $\mathbf{y}=\mathbf{g}(\mathbf{x})$，$\mathbf{z}=\mathbf{f}(\mathbf{y})$，则雅可比**相乘**：

$$
\frac{\partial\mathbf{z}}{\partial\mathbf{x}}=\frac{\partial\mathbf{z}}{\partial\mathbf{y}}\cdot\frac{\partial\mathbf{y}}{\partial\mathbf{x}}
$$

当最终输出是**标量损失** $L$ 时，梯度（列向量）为

$$
\nabla_{\mathbf{x}}L=\left(\frac{\partial\mathbf{y}}{\partial\mathbf{x}}\right)^\top\nabla_{\mathbf{y}}L
$$

> **这一个公式就是反向传播**：每一层只需要知道"上游传来的梯度 $\nabla_{\mathbf{y}}L$"和"本层的雅可比转置"，就能算出传给下一层的梯度。

### 2.5 约束优化的预告

在约束 $g(\mathbf{x})=0$ 下最小化 $f$，引入拉格朗日函数 $\mathcal{L}=f+\lambda g$，最优点满足 $\nabla f=-\lambda\nabla g$（目标梯度与约束梯度平行）。MPC、WBC 中的 QP 都建立在此基础上，详见下一章《最优化基础》。

## 3. 矩阵求导基础

### 3.1 为什么需要专门学

神经网络的参数是矩阵 $W$，损失是标量 $L$，需要 $\partial L/\partial W$。逐元素求导太繁琐，需要一套**整体运算**的规则。

### 3.2 布局约定（务必先统一）

矩阵求导有两种布局，不同教材不同，**这是最常见的混乱来源**。本课程采用：

| 对象 | 约定 | 形状 |
|---|---|---|
| 标量 $f$ 对向量 $\mathbf{x}\in\mathbb{R}^n$ | **梯度**，与 $\mathbf{x}$ 同形 | $n\times1$ 列向量 |
| 标量 $f$ 对矩阵 $X\in\mathbb{R}^{m\times n}$ | 与 $X$ **同形** | $m\times n$ |
| 向量 $\mathbf{f}\in\mathbb{R}^m$ 对向量 $\mathbf{x}\in\mathbb{R}^n$ | **雅可比** | $m\times n$ |

> **记忆法则**：标量对谁求导，结果就和谁形状相同。这条规则能用来检查所有结果的形状是否正确，也和 PyTorch 中 `x.grad` 与 `x` 形状一致相符。

### 3.3 基本公式表

设 $\mathbf{a},\mathbf{b}$ 为常向量，$A$ 为常矩阵，$\mathbf{x}$ 为变量向量：

| 函数 | 梯度 $\nabla_{\mathbf{x}}$ |
|---|---|
| $\mathbf{a}^\top\mathbf{x}$ | $\mathbf{a}$ |
| $\mathbf{x}^\top\mathbf{x}=\|\mathbf{x}\|^2$ | $2\mathbf{x}$ |
| $\mathbf{x}^\top A\mathbf{x}$ | $(A+A^\top)\mathbf{x}$；若 $A$ 对称则为 $2A\mathbf{x}$ |
| $\|A\mathbf{x}-\mathbf{b}\|^2$ | $2A^\top(A\mathbf{x}-\mathbf{b})$ |
| $\|\mathbf{x}\|_2$ | $\mathbf{x}/\|\mathbf{x}\|$（$\mathbf{x}\neq0$） |

对矩阵变量 $X$：

| 函数 | 梯度 $\partial/\partial X$ |
|---|---|
| $\text{tr}(AX)$ | $A^\top$ |
| $\text{tr}(X^\top AX)$ | $(A+A^\top)X$ |
| $\mathbf{a}^\top X\mathbf{b}$ | $\mathbf{a}\mathbf{b}^\top$ |
| $\ln\det X$ | $X^{-\top}$ |
| $\|X\|_F^2$ | $2X$ |

对向量函数（雅可比）：

| 函数 | 雅可比 $\partial\mathbf{f}/\partial\mathbf{x}$ |
|---|---|
| $A\mathbf{x}$ | $A$ |
| $\mathbf{x}$ | $I$ |
| $\sigma(\mathbf{x})$（逐元素） | $\text{diag}\big(\sigma'(\mathbf{x})\big)$ |

### 3.6 微分法（推荐的推导方法）

**不需要死记公式，学会"微分法"就能推出几乎所有结果。**

步骤：

1. 对表达式求**微分** $dL$（把 $d$ 当作线性算子，用乘积法则）
2. 利用迹技巧，把 $dL$ 整理成 $\text{tr}(G^\top dX)$ 的形式
3. 则 $\partial L/\partial X=G$

**迹的常用性质**：

- $\text{tr}(A)=\text{tr}(A^\top)$，标量等于它自己的迹
- $\text{tr}(AB)=\text{tr}(BA)$（循环移动）
- $\text{tr}(A+B)=\text{tr}(A)+\text{tr}(B)$

**常用微分**：

- $d(XY)=dX\,Y+X\,dY$
- $d(X^\top)=(dX)^\top$
- $d(X^{-1})=-X^{-1}(dX)X^{-1}$
- $d(\ln\det X)=\text{tr}(X^{-1}dX)$

**例 1**：$L=\|A\mathbf{x}-\mathbf{b}\|^2$，求 $\nabla_{\mathbf{x}}L$。

$$
\begin{aligned}
dL&=2(A\mathbf{x}-\mathbf{b})^\top A\,d\mathbf{x}\\
\Rightarrow\ \nabla_{\mathbf{x}}L&=2A^\top(A\mathbf{x}-\mathbf{b})
\end{aligned}
$$

令其为零即得上一章的**正规方程** $A^\top A\mathbf{x}=A^\top\mathbf{b}$。

**例 2**：$L=\mathbf{a}^\top X\mathbf{b}$，求 $\partial L/\partial X$。

$$
dL=\mathbf{a}^\top(dX)\mathbf{b}=\text{tr}(\mathbf{a}^\top dX\,\mathbf{b})=\text{tr}(\mathbf{b}\mathbf{a}^\top dX)
$$

对照 $\text{tr}(G^\top dX)$，得 $G^\top=\mathbf{b}\mathbf{a}^\top$，即 $G=\mathbf{a}\mathbf{b}^\top$。

**例 3**：线性层 $\mathbf{y}=W\mathbf{x}$，上游梯度 $\boldsymbol\delta=\nabla_{\mathbf{y}}L$，求 $\partial L/\partial W$。

$$
dL=\boldsymbol\delta^\top d\mathbf{y}=\boldsymbol\delta^\top(dW)\mathbf{x}=\text{tr}(\mathbf{x}\boldsymbol\delta^\top dW)
\ \Rightarrow\ \frac{\partial L}{\partial W}=\boldsymbol\delta\,\mathbf{x}^\top
$$

形状检查：$\boldsymbol\delta\in\mathbb{R}^{d_{out}}$，$\mathbf{x}\in\mathbb{R}^{d_{in}}$，外积形状为 $d_{out}\times d_{in}$，与 $W$ 一致。

### 3.7 NumPy 实践：用数值梯度验证公式

```python
import numpy as np

rng = np.random.default_rng(0)

def numerical_grad(f, x, eps=1e-6):
    """中心差分计算 f 在 x 处的梯度，x 为 float 数组，f 返回标量"""
    g = np.zeros_like(x, dtype=float)
    for i in range(x.size):
        xp, xm = x.copy(), x.copy()
        xp.flat[i] += eps
        xm.flat[i] -= eps
        g.flat[i] = (f(xp) - f(xm)) / (2 * eps)
    return g

# 1) f = x^T A x，梯度应为 (A + A^T) x
A = rng.standard_normal((4, 4))
x = rng.standard_normal(4)
f = lambda v: v @ A @ v
print(np.allclose(numerical_grad(f, x), (A + A.T) @ x, atol=1e-5))

# 2) f = ||A x - b||^2，梯度应为 2 A^T (A x - b)
A2 = rng.standard_normal((6, 4))
b = rng.standard_normal(6)
f2 = lambda v: np.sum((A2 @ v - b) ** 2)
print(np.allclose(numerical_grad(f2, x), 2 * A2.T @ (A2 @ x - b), atol=1e-5))

# 3) f = a^T X b，对矩阵 X 的梯度应为 a b^T
a, bb = rng.standard_normal(3), rng.standard_normal(5)
X = rng.standard_normal((3, 5))
f3 = lambda M: a @ M @ bb
print(np.allclose(numerical_grad(f3, X), np.outer(a, bb), atol=1e-5))
```

> 习惯：**推导完一个梯度，立刻用数值梯度验证一次**，这是自己实现 PPO、动力学与雅可比时最有效的调试手段。

## 4. 反向传播的推导

### 4.1 计算图与前向、反向

把计算拆成基本运算组成的**有向无环图**：

- **前向传播**：从输入到输出，计算并**缓存中间量**
- **反向传播**：从输出的标量损失出发，沿图反向，用链式法则逐节点计算梯度
- 同一个变量被多处使用时，其梯度要**累加**

### 4.2 全连接层

单样本 $\mathbf{y}=W\mathbf{x}+\mathbf{b}$，设上游梯度 $\boldsymbol\delta=\partial L/\partial\mathbf{y}$：

$$
\frac{\partial L}{\partial W}=\boldsymbol\delta\mathbf{x}^\top,\qquad\frac{\partial L}{\partial\mathbf{b}}=\boldsymbol\delta,\qquad\frac{\partial L}{\partial\mathbf{x}}=W^\top\boldsymbol\delta
$$

**批量形式**（工程中实际使用）：设 $X\in\mathbb{R}^{N\times d_{in}}$，$Y=XW^\top+\mathbf{1}\mathbf{b}^\top$，$\Delta=\partial L/\partial Y\in\mathbb{R}^{N\times d_{out}}$：

$$
\frac{\partial L}{\partial W}=\Delta^\top X,\qquad\frac{\partial L}{\partial\mathbf{b}}=\Delta^\top\mathbf{1}\ (\text{对批次求和}),\qquad\frac{\partial L}{\partial X}=\Delta W
$$

> 注意：批次维度的梯度是**求和**还是**平均**，取决于损失是求和还是平均。常见的 bug 就是忘记除以 $N$ 导致学习率"莫名变大"。

### 4.3 逐元素激活函数

$\mathbf{h}=\phi(\mathbf{z})$，雅可比是对角矩阵，因此上游梯度**逐元素相乘**：

$$
\frac{\partial L}{\partial\mathbf{z}}=\frac{\partial L}{\partial\mathbf{h}}\odot\phi'(\mathbf{z})
$$

**梯度消失与爆炸的数学原因**：反向传播是多个雅可比的连乘。若每层雅可比的范数小于 1，连乘趋于 0（消失）；大于 1 则趋于无穷（爆炸）。

- Sigmoid 导数最大值只有 0.25，深层时极易消失
- ReLU 在正区间导数为 1，缓解了消失
- ResNet 的残差连接 $\mathbf{y}=\mathbf{x}+F(\mathbf{x})$ 使雅可比为 $I+\partial F/\partial\mathbf{x}$，梯度有一条"直通路径"
- 初始化（Xavier、He）与归一化的目的，就是让每层雅可比的尺度接近 1

### 4.4 损失函数的梯度

| 损失 | 公式 | 对输出的梯度 |
|---|---|---|
| MSE | $L=\tfrac12\|\hat{\mathbf{y}}-\mathbf{y}\|^2$ | $\hat{\mathbf{y}}-\mathbf{y}$ |
| Softmax + 交叉熵 | $L=-\sum_ky_k\log p_k$，$\mathbf{p}=\text{softmax}(\mathbf{z})$ | $\mathbf{p}-\mathbf{y}$ |

**Softmax + 交叉熵的推导**（单样本，$\mathbf{y}$ 为 one-hot）：

$$
\text{softmax}:\ p_k=\frac{e^{z_k}}{\sum_je^{z_j}},\qquad
L=-\sum_ky_k\Big(z_k-\log\sum_je^{z_j}\Big)=-\mathbf{y}^\top\mathbf{z}+\log\sum_je^{z_j}
$$

$$
\frac{\partial L}{\partial z_i}=-y_i+\frac{e^{z_i}}{\sum_je^{z_j}}=p_i-y_i
$$

结果极其简洁，所以工程实现中把 Softmax 与交叉熵**合并**为一个算子（`F.cross_entropy` 接受 logits 而不是概率），既简化梯度，又保证数值稳定（见第 9 节）。

### 4.5 完整例子：两层网络的反向传播

网络：$\mathbf{z}_1=W_1\mathbf{x}+\mathbf{b}_1$，$\mathbf{h}=\tanh(\mathbf{z}_1)$，$\hat{\mathbf{y}}=W_2\mathbf{h}$，损失 $L=\tfrac12\|\hat{\mathbf{y}}-\mathbf{y}\|^2$。

**前向**：依次计算并缓存 $\mathbf{z}_1,\mathbf{h},\hat{\mathbf{y}}$。

**反向**：

$$
\begin{aligned}
\boldsymbol\delta_2&=\hat{\mathbf{y}}-\mathbf{y}\\
\frac{\partial L}{\partial W_2}&=\boldsymbol\delta_2\mathbf{h}^\top\\
\boldsymbol\delta_1&=\big(W_2^\top\boldsymbol\delta_2\big)\odot\big(1-\mathbf{h}^2\big)\\
\frac{\partial L}{\partial W_1}&=\boldsymbol\delta_1\mathbf{x}^\top,\qquad\frac{\partial L}{\partial\mathbf{b}_1}=\boldsymbol\delta_1
\end{aligned}
$$

```python
def forward(W1, b1, W2, x, y):
    z1 = W1 @ x + b1
    h = np.tanh(z1)
    yhat = W2 @ h
    loss = 0.5 * np.sum((yhat - y) ** 2)
    return loss, (z1, h, yhat)

def backward(W1, b1, W2, x, y, cache):
    z1, h, yhat = cache
    d2 = yhat - y
    dW2 = np.outer(d2, h)
    d1 = (W2.T @ d2) * (1 - h ** 2)
    dW1 = np.outer(d1, x)
    db1 = d1
    return dW1, db1, dW2

# 随机初始化
din, dh, dout = 3, 5, 2
W1 = rng.standard_normal((dh, din))
b1 = rng.standard_normal(dh)
W2 = rng.standard_normal((dout, dh))
x = rng.standard_normal(din)
y = rng.standard_normal(dout)

loss, cache = forward(W1, b1, W2, x, y)
dW1, db1, dW2 = backward(W1, b1, W2, x, y, cache)

# 梯度检查：分别对 W1、b1、W2 做数值梯度
g_W1 = numerical_grad(lambda M: forward(M, b1, W2, x, y)[0], W1)
g_b1 = numerical_grad(lambda v: forward(W1, v, W2, x, y)[0], b1)
g_W2 = numerical_grad(lambda M: forward(W1, b1, M, x, y)[0], W2)

print(np.allclose(dW1, g_W1, atol=1e-6),
      np.allclose(db1, g_b1, atol=1e-6),
      np.allclose(dW2, g_W2, atol=1e-6))      # 期望全部 True
```

> 这段代码就是后续《深度学习》第 3 周"手写反向传播"的核心。

## 5. 自动微分

### 5.1 三种求导方式的比较

| 方式 | 原理 | 优点 | 缺点 |
|---|---|---|---|
| 手工推导 | 推出解析式 | 最快、最清晰 | 易错、复杂模型不可行 |
| 数值微分 | 有限差分 | 实现简单，用于检验 | 慢（每个参数一次前向）、有舍入与截断误差 |
| **自动微分（AD）** | 对基本运算做链式法则 | 精确（到机器精度）、通用 | 需要存中间量，占显存 |

自动微分**不是**符号求导，也不是数值求导。它把程序分解成基本运算，对每个基本运算应用已知的导数规则并按链式法则组合。

### 5.2 前向模式与反向模式

对 $\mathbf{f}:\mathbb{R}^n\to\mathbb{R}^m$ 的雅可比 $J\in\mathbb{R}^{m\times n}$：

| 模式 | 计算内容 | 一次传播得到 | 适合 |
|---|---|---|---|
| 前向模式 | **JVP**：$J\mathbf{v}$ | 雅可比的一**列**（方向导数） | 输入少、输出多（$n\ll m$） |
| 反向模式 | **VJP**：$\mathbf{u}^\top J$ | 雅可比的一**行** | 输入多、输出少（$n\gg m$） |

**深度学习的损失是标量**（$m=1$），参数有百万到数十亿个（$n$ 很大），所以使用**反向模式**，一次反向传播就得到所有参数的梯度，这也是"反向传播"被普遍采用的原因。

**机器人场景**：计算完整雅可比 $J\in\mathbb{R}^{6\times n}$ 时，$n$ 与 $m$ 相当，使用解析的几何雅可比（Pinocchio 提供）效率最高；可微仿真（MJX、Brax、Warp）中可以对整个仿真流程做自动微分，用于轨迹优化与系统辨识。

### 5.3 PyTorch 的 autograd

```python
import torch

x = torch.tensor([1.0, 2.0], requires_grad=True)
A = torch.tensor([[2.0, 1.0], [1.0, 3.0]])

f = x @ A @ x                    # 标量
f.backward()                     # 反向传播
print(x.grad)                    # 应等于 (A + A^T) x = [8., 14.]

# 雅可比：向量函数
def g(v):
    return torch.stack([v[0] ** 2 + v[1], torch.sin(v[0]) * v[1]])

J = torch.autograd.functional.jacobian(g, torch.tensor([1.0, 2.0]))
print(J)

# 常见用法：每次迭代前清零梯度
# optimizer.zero_grad(); loss.backward(); optimizer.step()
```

**使用中的几个要点**：

- `x.grad` 默认是**累加**的，每次迭代必须清零（`optimizer.zero_grad()`）
- 推理与评估时用 `torch.no_grad()`，节省显存并加速
- `detach()` 把张量从计算图中分离，**阻断梯度**；Critic 的目标值、Actor 更新时的优势估计都需要 `detach`
- 就地操作（`x.add_()`）可能破坏反向传播所需的中间量
- 梯度裁剪 `clip_grad_norm_` 应在 `backward()` 之后、`step()` 之前调用

> **PPO 实现中的 `detach`**：计算新旧策略概率比时，旧策略的 `log_prob` 来自采样阶段，**不应该带梯度**；优势函数 $A_t$ 也要当作常数。若漏掉 `detach`，梯度会流到不该更新的分支，是常见的隐蔽 bug。

## 6. 优化中的微积分

### 6.1 梯度下降

$$
\mathbf{x}_{k+1}=\mathbf{x}_k-\eta\nabla f(\mathbf{x}_k)
$$

对二次函数 $f=\tfrac12\mathbf{x}^\top A\mathbf{x}$（$A\succ0$），收敛速度由条件数 $\kappa(A)=\lambda_{\max}/\lambda_{\min}$ 决定：学习率需要小于 $2/\lambda_{\max}$，而收敛速度受 $\lambda_{\min}$ 限制，**条件数越大越慢**。

### 6.2 牛顿法

使用二阶泰勒展开，令近似函数的梯度为零：

$$
\mathbf{x}_{k+1}=\mathbf{x}_k-H^{-1}\nabla f(\mathbf{x}_k)
$$

- 对二次函数**一步收敛**；在最优点附近二次收敛
- 每步要计算并求解 Hessian（$O(n^3)$），大规模问题代价过高
- $H$ 不正定时需要修正（如加阻尼项）
- 深度学习中使用近似二阶方法（Adam 可看作对角近似、K-FAC、自然梯度）

### 6.3 高斯-牛顿与 Levenberg-Marquardt

对非线性最小二乘 $\min\ \tfrac12\|\mathbf{r}(\mathbf{x})\|^2$，残差雅可比为 $J$：

- **高斯-牛顿**：忽略 Hessian 中的二阶残差项，$H\approx J^\top J$

$$
\Delta\mathbf{x}=-(J^\top J)^{-1}J^\top\mathbf{r}
$$

- **Levenberg-Marquardt**：$\Delta\mathbf{x}=-(J^\top J+\lambda I)^{-1}J^\top\mathbf{r}$，加阻尼保证稳定

> 与上一章呼应：**阻尼最小二乘逆运动学就是 LM 方法**。系统辨识、标定、SLAM 的后端优化也都是它。

### 6.4 一阶与二阶最优性条件

- 无约束：$\nabla f(\mathbf{x}^*)=0$ 且 $H\succeq0$
- 凸函数：任何满足 $\nabla f=0$ 的点都是全局最小点，凸函数的 Hessian 处处半正定
- 凸性是 QP、MPC 能被**可靠且快速**求解的根本原因，详见下一章

## 7. 机器人中的微积分

### 7.1 速度运动学：雅可比

平面 2 连杆机械臂（连杆长 $l_1,l_2$）的正运动学：

$$
\begin{aligned}
x&=l_1\cos q_1+l_2\cos(q_1+q_2)\\
y&=l_1\sin q_1+l_2\sin(q_1+q_2)
\end{aligned}
$$

对 $\mathbf{q}$ 求导，得雅可比：

$$
J=\begin{bmatrix}-l_1\sin q_1-l_2\sin(q_1+q_2)&-l_2\sin(q_1+q_2)\\l_1\cos q_1+l_2\cos(q_1+q_2)&l_2\cos(q_1+q_2)\end{bmatrix}
$$

**力与速度的对偶**：末端力 $\mathbf{F}$ 对应的关节力矩为

$$
\boldsymbol\tau=J^\top\mathbf{F}
$$

这由虚功原理得到，是力控与阻抗控制的基础。

**加速度**：对 $\dot{\mathbf{x}}=J\dot{\mathbf{q}}$ 再求导，得 $\ddot{\mathbf{x}}=J\ddot{\mathbf{q}}+\dot{J}\dot{\mathbf{q}}$，WBC 中的任务空间加速度正是这个形式。

### 7.2 牛顿迭代求数值逆运动学

给定目标位置 $\mathbf{p}^*$，反复迭代：

$$
\mathbf{e}=\mathbf{p}^*-\text{FK}(\mathbf{q}),\qquad\Delta\mathbf{q}=J^+\mathbf{e}\ \ (\text{或阻尼形式}),\qquad\mathbf{q}\leftarrow\mathbf{q}+\Delta\mathbf{q}
$$

```python
def fk(q, l1=1.0, l2=1.0):
    return np.array([l1 * np.cos(q[0]) + l2 * np.cos(q[0] + q[1]),
                     l1 * np.sin(q[0]) + l2 * np.sin(q[0] + q[1])])

def jac(q, l1=1.0, l2=1.0):
    s1, c1 = np.sin(q[0]), np.cos(q[0])
    s12, c12 = np.sin(q[0] + q[1]), np.cos(q[0] + q[1])
    return np.array([[-l1 * s1 - l2 * s12, -l2 * s12],
                     [ l1 * c1 + l2 * c12,  l2 * c12]])

def numerical_jacobian(f, q, eps=1e-6):
    m = f(q).size
    J = np.zeros((m, q.size))
    for j in range(q.size):
        qp, qm = q.copy(), q.copy()
        qp[j] += eps
        qm[j] -= eps
        J[:, j] = (f(qp) - f(qm)) / (2 * eps)
    return J

q = np.array([0.4, 0.9])
print(np.allclose(jac(q), numerical_jacobian(fk, q), atol=1e-6))   # 雅可比检查

# 牛顿迭代 IK（带阻尼）
target = np.array([1.2, 0.8])
q = np.array([0.3, 0.3])
lam = 0.01
for it in range(50):
    e = target - fk(q)
    if np.linalg.norm(e) < 1e-8:
        break
    J = jac(q)
    dq = J.T @ np.linalg.solve(J @ J.T + lam**2 * np.eye(2), e)
    q = q + dq
print(it, q, fk(q))
```

### 7.3 动力学的线性化

非线性系统 $\dot{\mathbf{x}}=f(\mathbf{x},\mathbf{u})$ 在工作点 $(\mathbf{x}_0,\mathbf{u}_0)$ 附近做一阶泰勒展开：

$$
\dot{\mathbf{x}}\approx f(\mathbf{x}_0,\mathbf{u}_0)+A(\mathbf{x}-\mathbf{x}_0)+B(\mathbf{u}-\mathbf{u}_0),\quad A=\frac{\partial f}{\partial\mathbf{x}}\Big|_0,\ B=\frac{\partial f}{\partial\mathbf{u}}\Big|_0
$$

在平衡点（$f(\mathbf{x}_0,\mathbf{u}_0)=0$）处，令 $\delta\mathbf{x}=\mathbf{x}-\mathbf{x}_0$，得线性系统

$$
\delta\dot{\mathbf{x}}=A\,\delta\mathbf{x}+B\,\delta\mathbf{u}
$$

**应用**：

- **LQR**：在线性化后的系统上设计最优反馈
- **iLQR / DDP / MPC**：每次迭代沿当前轨迹重新线性化
- **EKF**：用 $\partial f/\partial\mathbf{x}$ 与 $\partial h/\partial\mathbf{x}$ 传递协方差，再用上一章的 $A\Sigma A^\top$ 公式
- **稳定性分析**：线性化系统的矩阵 $A$ 的特征值决定平衡点的局部稳定性

**倒立摆示例**：$\ddot\theta=\dfrac{g}{l}\sin\theta+\dfrac{u}{ml^2}$，状态 $\mathbf{x}=[\theta,\dot\theta]^\top$，在 $\theta=0$ 处：

$$
A=\begin{bmatrix}0&1\\g/l&0\end{bmatrix},\qquad B=\begin{bmatrix}0\\1/(ml^2)\end{bmatrix}
$$

$A$ 的特征值为 $\pm\sqrt{g/l}$，有一个正实根，说明直立位置不稳定，需要反馈控制。

### 7.4 旋转的导数

旋转矩阵 $R(t)$ 随时间变化，满足

$$
\dot{R}=[\boldsymbol\omega]_\times R
$$

其中 $\boldsymbol\omega$ 是（世界系下的）角速度，$[\boldsymbol\omega]_\times$ 是反对称矩阵：

$$
[\boldsymbol\omega]_\times=\begin{bmatrix}0&-\omega_z&\omega_y\\\omega_z&0&-\omega_x\\-\omega_y&\omega_x&0\end{bmatrix}
$$

由此可见，**角速度不是欧拉角的时间导数**，两者之间还差一个与姿态相关的矩阵。这是后续《刚体运动与旋转表示》的重点，也是 RL 观测使用"机体系角速度 + 投影重力"而不是欧拉角及其导数的原因之一。

### 7.5 数值微分与离散化

仿真与控制中经常需要用数值方法估计导数，例如由编码器位置估计关节速度：

| 方法 | 公式 | 误差 |
|---|---|---|
| 前向差分 | $\dfrac{f(x+h)-f(x)}{h}$ | $O(h)$ |
| 后向差分 | $\dfrac{f(x)-f(x-h)}{h}$ | $O(h)$，**实时控制只能用这个**（不能用未来的值） |
| 中心差分 | $\dfrac{f(x+h)-f(x-h)}{2h}$ | $O(h^2)$，更精确，适合离线检验 |

**步长权衡**：$h$ 太大，截断误差大；$h$ 太小，舍入误差放大（浮点相减抵消）。双精度下中心差分 $h\sim10^{-5}\sim10^{-6}$ 较为合适。

> 对实测位置做差分求速度会**放大噪声**（噪声被除以很小的 $\Delta t$），因此实物上通常对速度做低通滤波，或直接使用电机驱动器给出的速度。训练时给关节速度观测加噪声，对应的就是这个问题。

## 8. 策略梯度中的求导

### 8.1 高斯策略的对数概率梯度

对一维高斯 $\pi(a\mid s)=\mathcal{N}(\mu,\sigma^2)$：

$$
\log\pi(a)=-\frac{(a-\mu)^2}{2\sigma^2}-\log\sigma-\frac12\log2\pi
$$

$$
\frac{\partial\log\pi}{\partial\mu}=\frac{a-\mu}{\sigma^2},\qquad\frac{\partial\log\pi}{\partial\sigma}=\frac{(a-\mu)^2}{\sigma^3}-\frac1\sigma,\qquad\frac{\partial\log\pi}{\partial\log\sigma}=\frac{(a-\mu)^2}{\sigma^2}-1
$$

**直观含义**：

- 对 $\mu$ 的梯度指向"动作所在的方向"，乘上正的优势就把均值推向该动作，负的优势则推离
- 当所采样的动作偏离均值超过一个标准差（$|a-\mu|>\sigma$）时，$\partial\log\pi/\partial\log\sigma>0$，若优势为正，则增大 $\sigma$，扩大探索；反之缩小

对数标准差 $\log\sigma$ 作为可学习参数，可以保证 $\sigma>0$，且梯度形式更简洁，这就是 rsl_rl、CleanRL 中常见的 `log_std` 参数化。

### 8.2 Softmax 策略的梯度

$\pi(a\mid s)=\text{softmax}(\mathbf{z})_a$，由第 4.4 节的结果：

$$
\nabla_{\mathbf{z}}\log\pi(a)=\mathbf{e}_a-\boldsymbol\pi
$$

其中 $\mathbf{e}_a$ 是第 $a$ 个位置为 1 的 one-hot 向量。选中的动作 logit 被推高，其余按当前概率被压低。

### 8.3 策略梯度定理的求导链条

把前面几章的内容串起来：

1. $J(\theta)=\mathbb{E}_{\tau\sim p_\theta}[G(\tau)]$（概率统计：期望）
2. $\nabla_\theta J=\mathbb{E}\big[G(\tau)\nabla_\theta\log p_\theta(\tau)\big]$（概率统计：对数导数技巧）
3. $\nabla_\theta\log p_\theta(\tau)=\sum_t\nabla_\theta\log\pi_\theta(a_t\mid s_t)$（动力学项与 $\theta$ 无关，求导为零）
4. 对每个 $\nabla_\theta\log\pi_\theta$ 用本章的链式法则反向传播到网络参数

于是策略梯度的实现就是：**构造损失 $L=-\frac1N\sum_t\log\pi_\theta(a_t|s_t)\,A_t$，调用 `loss.backward()`**，其中 $A_t$ 是被 `detach` 的常数。

### 8.4 PPO 截断目标的梯度

令 $r_t(\theta)=\dfrac{\pi_\theta(a_t|s_t)}{\pi_{\theta_{\text{old}}}(a_t|s_t)}$，目标为

$$
L^{\text{CLIP}}=\mathbb{E}\Big[\min\big(r_tA_t,\ \text{clip}(r_t,1-\epsilon,1+\epsilon)A_t\big)\Big]
$$

因为 $\nabla_\theta r_t=r_t\nabla_\theta\log\pi_\theta(a_t|s_t)$，所以：

- 当截断**未起作用**时，梯度为 $r_tA_t\nabla_\theta\log\pi_\theta$，与策略梯度一致（只是多了概率比）
- 当 $A_t>0$ 且 $r_t>1+\epsilon$（已经提升得足够多），或 $A_t<0$ 且 $r_t<1-\epsilon$，被截断的项**梯度为零**，样本不再推动策略继续变化

> 这就是 PPO "限制更新幅度"在**梯度层面**的含义：不是显式约束，而是让越界样本的梯度消失。

```python
# 验证高斯 log_prob 对 mu、log_sigma 的梯度
def logp(a, mu, log_sigma):
    sigma = np.exp(log_sigma)
    return -0.5 * ((a - mu) / sigma) ** 2 - log_sigma - 0.5 * np.log(2 * np.pi)

a, mu, ls = 0.7, 0.1, -0.3
sigma = np.exp(ls)

g_mu = (a - mu) / sigma**2
g_ls = (a - mu) ** 2 / sigma**2 - 1

eps = 1e-6
num_mu = (logp(a, mu + eps, ls) - logp(a, mu - eps, ls)) / (2 * eps)
num_ls = (logp(a, mu, ls + eps) - logp(a, mu, ls - eps)) / (2 * eps)
print(np.isclose(g_mu, num_mu), np.isclose(g_ls, num_ls))
```

## 9. 数值稳定性

| 问题 | 原因 | 做法 |
|---|---|---|
| Softmax 溢出 | $e^{z}$ 对大 $z$ 溢出 | 减去最大值：$\text{softmax}(\mathbf{z})=\text{softmax}(\mathbf{z}-\max z)$ |
| $\log(0)$ | 概率下溢 | 使用 `log_softmax`、`logsumexp`，或加小量 |
| 交叉熵不稳定 | 先算概率再取对数 | 直接用 logits（`F.cross_entropy`） |
| Sigmoid + BCE | 同上 | 使用 `BCEWithLogitsLoss` |
| 概率比溢出 | $\exp(\log\pi_{\text{new}}-\log\pi_{\text{old}})$ 差值过大 | 在对数域相减，并限制范围或裁剪 |
| $\sigma\to0$ | 高斯策略标准差塌缩，$1/\sigma^2$ 爆炸 | 参数化为 $\log\sigma$，设下限，保持熵正则 |
| 梯度爆炸 | 连乘雅可比范数过大 | 梯度裁剪、合理初始化、归一化 |
| 舍入误差 | 数值微分步长不合适 | 用中心差分，$h\approx10^{-5}\sim10^{-6}$ |

**logsumexp 技巧**：

$$
\log\sum_ie^{z_i}=m+\log\sum_ie^{z_i-m},\quad m=\max_iz_i
$$

```python
def logsumexp(z):
    m = np.max(z)
    return m + np.log(np.sum(np.exp(z - m)))

z = np.array([1000.0, 1001.0, 1002.0])
# np.log(np.sum(np.exp(z)))  会溢出为 inf
print(logsumexp(z))        # 稳定
```

**一句话记忆**：*反向传播 = 雅可比转置 × 上游梯度；线性化 = 雅可比 × 小变化；推导完一定用数值梯度验证。*
