## 1. 向量

### 1.1 向量与几何意义

向量 $\mathbf{x}\in\mathbb{R}^n$ 是 $n$ 个实数的有序排列，默认写成**列向量**：

$$
\mathbf{x}=\begin{bmatrix}x_1\\x_2\\\vdots\\x_n\end{bmatrix}
$$

两种理解方式，需要随时切换：

- **几何视角**：空间中的一个点或一个带方向的箭头（位置、速度、力）
- **数据视角**：一组特征（机器人的观测向量：关节角、关节速度、基座角速度、指令……）

> 在 RL 中，一个人形机器人的观测可能是 $\mathbb{R}^{70}$ 以上的向量，它就是"一个点"，策略网络是把这个点映射成动作向量的函数。

### 1.2 基本运算

| 运算 | 定义 | 说明 |
|---|---|---|
| 加法 | $\mathbf{a}+\mathbf{b}$ | 逐元素相加 |
| 数乘 | $c\mathbf{a}$ | 缩放 |
| 内积 | $\mathbf{a}^\top\mathbf{b}=\sum_i a_ib_i$ | 结果是标量 |
| 外积 | $\mathbf{a}\mathbf{b}^\top$ | 结果是 $m\times n$ 矩阵，秩为 1 |
| 逐元素乘 | $\mathbf{a}\odot\mathbf{b}$ | 不是内积，神经网络里常见 |

### 1.3 内积、夹角与正交

内积与夹角的关系：

$$
\mathbf{a}^\top\mathbf{b}=\|\mathbf{a}\|\,\|\mathbf{b}\|\cos\theta
$$

- $\mathbf{a}^\top\mathbf{b}=0$ 时两向量**正交**（垂直）
- 内积衡量"方向有多一致"，也是余弦相似度、注意力机制 $QK^\top$ 的基础
- **投影**：$\mathbf{a}$ 在 $\mathbf{b}$ 方向上的投影为

$$
\text{proj}_{\mathbf{b}}\mathbf{a}=\frac{\mathbf{b}^\top\mathbf{a}}{\mathbf{b}^\top\mathbf{b}}\mathbf{b}
$$

> 机器人中的"投影重力"观测，就是把世界系重力向量 $[0,0,-1]^\top$ 通过旋转矩阵转到机体系，它反映机身姿态。

### 1.4 范数

范数衡量向量的"大小"：

| 范数 | 定义 | 用途 |
|---|---|---|
| $L_1$ | $\|\mathbf{x}\|_1=\sum_i\lvert x_i\rvert$ | 稀疏性、动作惩罚（鲁棒） |
| $L_2$ | $\|\mathbf{x}\|_2=\sqrt{\sum_i x_i^2}$ | 最常用，误差、能耗 |
| $L_\infty$ | $\|\mathbf{x}\|_\infty=\max_i\lvert x_i\rvert$ | 限幅、最大误差 |

**在 RL 奖励中的例子**：

- 速度跟踪：$r=\exp\left(-\|\mathbf{v}_{\text{cmd}}-\mathbf{v}\|_2^2/\sigma^2\right)$
- 动作平滑：$r=-\|\mathbf{a}_t-\mathbf{a}_{t-1}\|_2^2$
- 能耗：$r=-\|\boldsymbol{\tau}\odot\dot{\mathbf{q}}\|_1$

### 1.5 线性相关、基与维数

- 向量组 $\{\mathbf{v}_1,\dots,\mathbf{v}_k\}$ **线性无关**：只有全零系数才能使 $\sum c_i\mathbf{v}_i=\mathbf{0}$
- **基**：一组线性无关且能张成整个空间的向量；**维数**是基中向量个数
- 张成（span）：所有线性组合构成的集合

> 机器人的**自由度**本质就是构型空间的维数；**冗余**意味着可用的独立运动方向多于任务需要。

### 1.6 NumPy 实践

```python
import numpy as np

a = np.array([1.0, 2.0, 3.0])
b = np.array([4.0, 5.0, 6.0])

print(a @ b)                       # 内积 32.0
print(np.outer(a, b))              # 外积，3x3 矩阵
print(np.linalg.norm(a))           # L2 范数
print(np.linalg.norm(a, 1))        # L1 范数
print(np.linalg.norm(a, np.inf))   # L∞ 范数

# 夹角
cos_theta = a @ b / (np.linalg.norm(a) * np.linalg.norm(b))
theta = np.arccos(np.clip(cos_theta, -1.0, 1.0))  # clip 避免数值误差导致越界
print(np.degrees(theta))
```

> ⚠️ **常见错误**：把一维数组当作列向量。`a.shape == (3,)` 既不是行向量也不是列向量。做矩阵运算时，建议显式使用 `a.reshape(-1, 1)` 或确认 `@` 的行为。

## 2. 矩阵

### 2.1 矩阵是什么

矩阵 $A\in\mathbb{R}^{m\times n}$ 有两种本质理解：

1. **数据表**：$m$ 行 $n$ 列的数字
2. **线性映射**：把 $\mathbb{R}^n$ 中的向量变成 $\mathbb{R}^m$ 中的向量，$\mathbf{y}=A\mathbf{x}$

**线性**的含义：$A(\alpha\mathbf{x}+\beta\mathbf{z})=\alpha A\mathbf{x}+\beta A\mathbf{z}$。

> 线性映射的特点：原点不动、直线映射成直线、网格保持平行等距。所有"线性"的结论（叠加原理、LQR）都建立在这一点上。

### 2.2 矩阵乘法的三种理解

对 $C=AB$，同一个运算有三种视角，都需要熟悉：

1. **逐元素**：$C_{ij}=\sum_k A_{ik}B_{kj}$（行乘列）
2. **列视角**：$A\mathbf{x}$ 是 $A$ 的各列按 $\mathbf{x}$ 的元素加权求和
3. **复合映射**：$AB$ 表示先做 $B$ 再做 $A$

**重要性质**：

- 一般 $AB\neq BA$（不可交换），这正是旋转顺序重要的原因
- $(AB)^\top=B^\top A^\top$
- $(AB)^{-1}=B^{-1}A^{-1}$（逆的顺序反转）
- 结合律成立：$(AB)C=A(BC)$

> **神经网络前向传播** $\mathbf{h}=\sigma(W\mathbf{x}+\mathbf{b})$ 就是一层线性映射加非线性。
> **坐标变换链**：${}^{0}T_{3}={}^{0}T_{1}\,{}^{1}T_{2}\,{}^{2}T_{3}$ 是矩阵的连乘。

### 2.3 特殊矩阵

| 类型 | 定义 | 例子与用途 |
|---|---|---|
| 单位矩阵 $I$ | 对角为 1 | $AI=IA=A$ |
| 对角矩阵 | 仅对角非零 | 缩放、PD 增益矩阵 $K_p=\text{diag}(\dots)$ |
| 对称矩阵 | $A=A^\top$ | 协方差、质量矩阵 $M(q)$、Hessian |
| 正交矩阵 | $Q^\top Q=I$ | 旋转、反射 |
| 正定矩阵 | $\mathbf{x}^\top A\mathbf{x}>0$ | 协方差、LQR 代价、QP |
| 稀疏矩阵 | 大部分元素为 0 | MPC 中的约束矩阵 |

### 2.4 迹与行列式

**迹**（对角线元素之和）：

$$
\text{tr}(A)=\sum_i A_{ii},\qquad \text{tr}(AB)=\text{tr}(BA)
$$

- 迹等于所有特征值之和
- 常用于把标量写成矩阵形式，如 $\mathbf{x}^\top A\mathbf{x}=\text{tr}(A\mathbf{x}\mathbf{x}^\top)$

**行列式** $\det(A)$（方阵）：

- 几何意义：线性映射对**体积**的缩放倍数，符号表示是否翻转方向
- $\det(A)=0\iff A$ 奇异（不可逆）
- $\det(AB)=\det(A)\det(B)$，$\det(A)=\prod_i\lambda_i$
- 旋转矩阵 $\det(R)=+1$，反射矩阵 $\det=-1$

> 实际数值计算中**几乎不会用行列式判断可逆性**，因为数值上不稳定，应使用条件数或奇异值。

### 2.5 逆矩阵

方阵 $A$ 可逆当且仅当 $\det(A)\neq0$，此时 $A^{-1}A=AA^{-1}=I$。

> ⚠️ **工程准则**：求解 $A\mathbf{x}=\mathbf{b}$ 时，**不要计算 `inv(A) @ b`**，而应使用 `np.linalg.solve(A, b)`，更快、更稳定。

```python
A = np.array([[4.0, 1.0], [2.0, 3.0]])
b = np.array([1.0, 2.0])

x_bad  = np.linalg.inv(A) @ b      # 不推荐
x_good = np.linalg.solve(A, b)     # 推荐
print(np.allclose(x_bad, x_good))
```

## 3. 线性方程组与四个基本子空间

### 3.1 方程组的三种情形

$A\mathbf{x}=\mathbf{b}$，$A\in\mathbb{R}^{m\times n}$：

| 情形 | 条件 | 解的情况 |
|---|---|---|
| 适定 | $m=n$ 且 $A$ 可逆 | 唯一解 |
| 超定 | $m>n$（方程多于未知数） | 通常无精确解，求最小二乘解 |
| 欠定 | $m<n$（未知数多于方程） | 通常有无穷多解，取最小范数解 |

> **机器人对应**：
> - 逆运动学：$J\dot{\mathbf{q}}=\mathbf{v}$，$J\in\mathbb{R}^{6\times n}$。人形手臂 $n=7$ 为**欠定**（冗余），腿的奇异位形附近则出现**秩亏**。
> - 系统辨识、线性回归：数据点远多于参数，是**超定**。

### 3.2 秩

**秩** $\text{rank}(A)$：$A$ 的线性无关列（或行）的最大个数。

- $\text{rank}(A)\le\min(m,n)$
- 满秩：$\text{rank}(A)=\min(m,n)$
- $\text{rank}(A)=$ 非零奇异值的个数
- **秩亏**意味着丢失了某些方向上的信息或运动能力

> 机械臂**奇异位形**，就是雅可比矩阵 $J$ 秩下降的位形：末端在某个方向上无法产生速度。

### 3.3 四个基本子空间

对 $A\in\mathbb{R}^{m\times n}$，秩为 $r$：

| 子空间 | 符号 | 所在空间 | 维数 |
|---|---|---|---|
| 列空间（值域） | $\mathcal{C}(A)$ | $\mathbb{R}^m$ | $r$ |
| 零空间（核） | $\mathcal{N}(A)$ | $\mathbb{R}^n$ | $n-r$ |
| 行空间 | $\mathcal{C}(A^\top)$ | $\mathbb{R}^n$ | $r$ |
| 左零空间 | $\mathcal{N}(A^\top)$ | $\mathbb{R}^m$ | $m-r$ |

关键关系（**秩-零度定理**）：$\text{rank}(A)+\dim\mathcal{N}(A)=n$。

正交关系：$\mathcal{N}(A)\perp\mathcal{C}(A^\top)$，$\mathcal{N}(A^\top)\perp\mathcal{C}(A)$。

**含义**：

- $A\mathbf{x}=\mathbf{b}$ 有解 $\iff\mathbf{b}\in\mathcal{C}(A)$
- 解不唯一的"自由度"由零空间描述：若 $\mathbf{x}_p$ 是特解，则所有解为 $\mathbf{x}_p+\mathbf{n}$，$\mathbf{n}\in\mathcal{N}(A)$

> **零空间在机器人中的核心应用**：冗余机械臂中，$\dot{\mathbf{q}}=J^+\mathbf{v}+(I-J^+J)\dot{\mathbf{q}}_0$。第二项在 $J$ 的零空间内运动，**不影响末端**，可用来避障、避关节限位、保持姿态，这是**任务优先级**与**全身控制（WBC）**的数学基础。

```python
J = np.array([[1.0, 0.0, 1.0],
              [0.0, 1.0, 1.0]])   # 2x3，欠定

print("rank:", np.linalg.matrix_rank(J))

# 零空间基：用 SVD 的右奇异向量（见第 5 节）
U, S, Vt = np.linalg.svd(J)
null_basis = Vt[np.sum(S > 1e-10):].T      # 3x1
print("零空间基:", null_basis.ravel())
print("J @ null =", J @ null_basis)        # ≈ 0
```

## 4. 特征值与特征向量

### 4.1 定义与几何意义

对方阵 $A\in\mathbb{R}^{n\times n}$，若存在非零向量 $\mathbf{v}$ 与标量 $\lambda$ 使

$$
A\mathbf{v}=\lambda\mathbf{v}
$$

则 $\lambda$ 为**特征值**，$\mathbf{v}$ 为**特征向量**。

**几何意义**：$A$ 作用在 $\mathbf{v}$ 上，只改变长度（缩放 $\lambda$ 倍），不改变方向。特征向量是线性映射的"不变方向"。

### 4.2 求法与性质

- 特征方程：$\det(A-\lambda I)=0$
- $\sum_i\lambda_i=\text{tr}(A)$，$\prod_i\lambda_i=\det(A)$
- $A$ 可逆 $\iff$ 所有 $\lambda_i\neq0$
- 特征值可能是复数（如旋转矩阵），复特征值总是成共轭对出现

### 4.3 特征分解

若 $A$ 有 $n$ 个线性无关的特征向量，则

$$
A=V\Lambda V^{-1}
$$

**对称矩阵**的特征分解最重要（**谱定理**）：

$$
A=Q\Lambda Q^\top,\qquad Q^\top Q=I
$$

- 特征值全为实数
- 特征向量彼此**正交**，可取成标准正交基
- 几何解释：先旋转到特征向量方向（$Q^\top$），再沿各轴独立缩放（$\Lambda$），再旋转回来（$Q$）

> **协方差矩阵**是对称半正定矩阵，其特征向量是数据的**主方向**，特征值是该方向的方差，这就是 PCA。

### 4.4 应用：稳定性判断

线性离散系统 $\mathbf{x}_{t+1}=A\mathbf{x}_t$：

- 稳定 $\iff$ 所有特征值的模 $|\lambda_i|<1$

线性连续系统 $\dot{\mathbf{x}}=A\mathbf{x}$：

- 稳定 $\iff$ 所有特征值的**实部**$<0$

> 这是后续《机器人学与经典控制》第 9 周（状态空间与稳定性）、LQR、极点配置的基础：**稳定性 = 看特征值**。

### 4.5 NumPy 实践

```python
# 对称矩阵：使用 eigh（更快、更稳定，返回升序实特征值）
A = np.array([[2.0, 1.0], [1.0, 2.0]])
w, Q = np.linalg.eigh(A)
print("特征值:", w)                       # [1. 3.]
print("重构:", np.allclose(Q @ np.diag(w) @ Q.T, A))

# 一般矩阵：使用 eig（可能返回复数）
B = np.array([[0.0, -1.0], [1.0, 0.0]])  # 旋转 90°
w, V = np.linalg.eig(B)
print(w)                                  # [0+1j, 0-1j]

# 稳定性判断（连续系统）
A_sys = np.array([[0.0, 1.0], [-2.0, -3.0]])
print("稳定:", np.all(np.linalg.eigvals(A_sys).real < 0))
```

> ⚠️ 对称矩阵一律用 `eigh`，不要用 `eig`。


## 5. 奇异值分解（SVD）

SVD 是线性代数里**最有用**的分解，适用于**任意形状**的矩阵。

### 5.1 定义

对任意 $A\in\mathbb{R}^{m\times n}$：

$$
A=U\Sigma V^\top
$$

- $U\in\mathbb{R}^{m\times m}$：正交矩阵，列为**左奇异向量**
- $V\in\mathbb{R}^{n\times n}$：正交矩阵，列为**右奇异向量**
- $\Sigma\in\mathbb{R}^{m\times n}$：对角矩阵，对角元 $\sigma_1\ge\sigma_2\ge\dots\ge0$ 为**奇异值**

### 5.2 几何意义

任意线性映射都可以分解为三步：

1. $V^\top$：旋转（在输入空间选好方向）
2. $\Sigma$：沿坐标轴缩放（$\sigma_i$ 倍）
3. $U$：旋转（在输出空间摆好方向）

即：**单位球经过 $A$ 变成椭球**，椭球的半轴长度是奇异值 $\sigma_i$，方向是 $U$ 的列。

### 5.3 与其他概念的联系

| 概念 | 由 SVD 得到 |
|---|---|
| 秩 | 非零奇异值的个数 |
| 零空间 | $V$ 中对应零奇异值的列 |
| 列空间 | $U$ 中对应非零奇异值的列 |
| $L_2$ 范数 | $\|A\|_2=\sigma_1$ |
| Frobenius 范数 | $\|A\|_F=\sqrt{\sum\sigma_i^2}$ |
| 条件数 | $\kappa(A)=\sigma_1/\sigma_r$ |
| 与特征值的关系 | $\sigma_i^2$ 是 $A^\top A$ 的特征值 |

### 5.4 条件数

$$
\kappa(A)=\frac{\sigma_{\max}}{\sigma_{\min}}
$$

- 越大，矩阵越"病态"，求解越不稳定，对输入噪声越敏感
- $\kappa\approx1$：良态；$\kappa\to\infty$：接近奇异

### 5.5 机器人中的雅可比分析

对雅可比矩阵 $J$ 做 SVD：

- **可操作度**：$w=\sqrt{\det(JJ^\top)}=\prod\sigma_i$，衡量末端运动能力
- **奇异位形**：$\sigma_{\min}\to0$，某方向上运动能力丧失，关节速度会爆炸
- **速度椭球**：长轴方向容易运动，短轴方向难以运动

### 5.6 低秩近似

取前 $k$ 个奇异值：

$$
A_k=\sum_{i=1}^{k}\sigma_i\mathbf{u}_i\mathbf{v}_i^\top
$$

这是在 Frobenius 范数意义下对 $A$ 的**最优秩 $k$ 近似**（Eckart-Young 定理）。应用：图像压缩、PCA 降维、LoRA（大模型低秩适配，$\Delta W=BA$）。

### 5.7 NumPy 实践

```python
A = np.random.randn(6, 4)

U, S, Vt = np.linalg.svd(A, full_matrices=False)   # 经济型 SVD
print(U.shape, S.shape, Vt.shape)                  # (6,4) (4,) (4,4)

# 重构
print(np.allclose(U @ np.diag(S) @ Vt, A))

# 条件数
print("cond:", S[0] / S[-1], np.linalg.cond(A))

# 低秩近似
k = 2
A_k = U[:, :k] @ np.diag(S[:k]) @ Vt[:k]
print("相对误差:", np.linalg.norm(A - A_k) / np.linalg.norm(A))

# 机器人例子：2 连杆平面臂的雅可比与可操作度
def jacobian_2link(q1, q2, l1=1.0, l2=1.0):
    s1, c1 = np.sin(q1), np.cos(q1)
    s12, c12 = np.sin(q1 + q2), np.cos(q1 + q2)
    return np.array([[-l1*s1 - l2*s12, -l2*s12],
                     [ l1*c1 + l2*c12,  l2*c12]])

for q2 in [1.0, 0.3, 0.01]:          # q2 -> 0 即手臂伸直，接近奇异
    J = jacobian_2link(0.5, q2)
    s = np.linalg.svd(J, compute_uv=False)
    print(f"q2={q2:5.2f}  σ={s}  cond={s[0]/s[1]:.1f}")
```

运行后你会看到：`q2` 趋近 0（手臂伸直）时 $\sigma_{\min}$ 趋于 0，条件数急剧上升，这就是奇异位形。


## 6. 伪逆与最小二乘

### 6.1 最小二乘问题

超定方程 $A\mathbf{x}\approx\mathbf{b}$（$m>n$）无精确解，转而最小化残差：

$$
\min_{\mathbf{x}}\ \|A\mathbf{x}-\mathbf{b}\|_2^2
$$

对 $\mathbf{x}$ 求导并令其为零，得到**正规方程**：

$$
A^\top A\,\mathbf{x}=A^\top\mathbf{b}\ \Longrightarrow\ \mathbf{x}^*=(A^\top A)^{-1}A^\top\mathbf{b}
$$

**几何意义**：$A\mathbf{x}^*$ 是 $\mathbf{b}$ 在 $A$ 的列空间上的**正交投影**，残差 $\mathbf{b}-A\mathbf{x}^*$ 与列空间正交。

> 线性回归、最小二乘拟合、系统辨识（如执行器模型参数拟合），都是这个问题。

### 6.2 Moore-Penrose 伪逆

对任意矩阵 $A$，通过 SVD 定义伪逆：

$$
A^+=V\Sigma^+U^\top
$$

其中 $\Sigma^+$ 是把 $\Sigma$ 中非零奇异值取倒数、再转置得到的矩阵。

| 情形 | 伪逆公式 | 得到的解 |
|---|---|---|
| 列满秩（超定） | $A^+=(A^\top A)^{-1}A^\top$ | 最小二乘解 |
| 行满秩（欠定） | $A^+=A^\top(AA^\top)^{-1}$ | 所有解中**范数最小**的解 |
| 一般情形 | $A^+=V\Sigma^+U^\top$ | 最小二乘解中范数最小的 |

> 因此 $\mathbf{x}=A^+\mathbf{b}$ 在一般情形下统一给出"误差最小、且范数最小"的解。

### 6.3 机器人应用：数值逆运动学

微分运动学 $\mathbf{v}=J\dot{\mathbf{q}}$，求关节速度：

$$
\dot{\mathbf{q}}=J^+\mathbf{v}
$$

**问题**：靠近奇异位形时，$J^+$ 中含有 $1/\sigma_{\min}$，关节速度会变得极大。

**解决：阻尼最小二乘（DLS，Levenberg-Marquardt）**

$$
\dot{\mathbf{q}}=J^\top(JJ^\top+\lambda^2I)^{-1}\mathbf{v}
$$

用 SVD 看：每个奇异值的倒数由 $1/\sigma_i$ 变为 $\sigma_i/(\sigma_i^2+\lambda^2)$，当 $\sigma_i\to0$ 时趋于 0 而不是无穷大，代价是引入少许跟踪误差。

**零空间任务（二级任务）**

$$
\dot{\mathbf{q}}=J_1^+\mathbf{v}_1+(I-J_1^+J_1)\,\dot{\mathbf{q}}_{0}
$$

其中 $(I-J_1^+J_1)$ 是向零空间的投影矩阵。

### 6.4 正则化

当 $A^\top A$ 病态或接近奇异时，使用**岭回归（Tikhonov 正则化）**：

$$
\min_{\mathbf{x}}\ \|A\mathbf{x}-\mathbf{b}\|^2+\lambda\|\mathbf{x}\|^2\ \Longrightarrow\ \mathbf{x}=(A^\top A+\lambda I)^{-1}A^\top\mathbf{b}
$$

这与深度学习里的**权重衰减（L2 正则）**是同一件事。

### 6.5 NumPy 实践

```python
# 1) 线性回归（超定）
np.random.seed(0)
x = np.linspace(0, 1, 50)
y = 2.0 * x + 1.0 + 0.1 * np.random.randn(50)
A = np.stack([x, np.ones_like(x)], axis=1)         # 50x2

w1 = np.linalg.lstsq(A, y, rcond=None)[0]          # 推荐
w2 = np.linalg.pinv(A) @ y
w3 = np.linalg.solve(A.T @ A, A.T @ y)             # 正规方程
print(w1, w2, w3)                                  # 都约为 [2, 1]

# 2) 欠定：最小范数解
J = np.array([[1.0, 0.0, 1.0],
              [0.0, 1.0, 1.0]])
v = np.array([1.0, 2.0])
dq = np.linalg.pinv(J) @ v
print("dq =", dq, " J@dq =", J @ dq)

# 3) 零空间投影
N = np.eye(3) - np.linalg.pinv(J) @ J
dq0 = np.array([1.0, 1.0, 1.0])                    # 次级任务：想让所有关节都转动
dq_total = np.linalg.pinv(J) @ v + N @ dq0
print("末端速度是否不受影响:", np.allclose(J @ dq_total, v))

# 4) 阻尼最小二乘
def dls(J, v, lam=0.05):
    m = J.shape[0]
    return J.T @ np.linalg.solve(J @ J.T + lam**2 * np.eye(m), v)

print(dls(J, v))
```

> ⚠️ 实际工程中，求最小二乘用 `np.linalg.lstsq`（内部基于 SVD，数值稳定），避免直接计算 $(A^\top A)^{-1}$：这会把条件数**平方**，丢失精度。

## 7. 正交矩阵与旋转

### 7.1 正交矩阵

$Q^\top Q=QQ^\top=I$，即 $Q^{-1}=Q^\top$。

**性质**：

- 保持内积与长度：$(Q\mathbf{x})^\top(Q\mathbf{y})=\mathbf{x}^\top\mathbf{y}$，$\|Q\mathbf{x}\|=\|\mathbf{x}\|$
- 列向量（也包括行向量）构成**标准正交基**
- $\det(Q)=\pm1$：$+1$ 为旋转，$-1$ 含反射
- 条件数为 1，数值计算最稳定

### 7.2 旋转矩阵 $SO(3)$

三维旋转矩阵构成特殊正交群：

$$
SO(3)=\{R\in\mathbb{R}^{3\times3}\mid R^\top R=I,\ \det R=1\}
$$

绕 $z$ 轴旋转 $\theta$：

$$
R_z(\theta)=\begin{bmatrix}\cos\theta&-\sin\theta&0\\\sin\theta&\cos\theta&0\\0&0&1\end{bmatrix}
$$

**应用**：

- 逆旋转直接转置：$R^{-1}=R^\top$（不需要求逆）
- 把世界系向量转到机体系：$\mathbf{v}_{\text{body}}=R^\top\mathbf{v}_{\text{world}}$
- 旋转的复合：$R=R_3R_2R_1$（**顺序很重要**，因为矩阵乘法不可交换）

> 这是后续《机器人学》第 2 周"刚体运动与旋转表示"的起点。RL 观测里的"投影重力"和"基座角速度"都涉及这一变换。

### 7.3 QR 分解与正交化

任意列满秩矩阵 $A=QR$，$Q$ 的列为标准正交，$R$ 为上三角。

- **Gram-Schmidt**：把一组线性无关向量逐个减去已有方向上的投影，得到标准正交基
- 用途：数值求解最小二乘、数值稳定的正交化

### 7.4 NumPy 实践

```python
def Rz(theta):
    c, s = np.cos(theta), np.sin(theta)
    return np.array([[c, -s, 0], [s, c, 0], [0, 0, 1]])

R = Rz(0.5)
print(np.allclose(R.T @ R, np.eye(3)))       # True：正交
print(np.isclose(np.linalg.det(R), 1.0))     # True：旋转

# 世界系重力 -> 机体系（投影重力）
g_world = np.array([0.0, 0.0, -1.0])
g_body = R.T @ g_world
print(g_body)

# 顺序不可交换
Rx = lambda t: np.array([[1,0,0],[0,np.cos(t),-np.sin(t)],[0,np.sin(t),np.cos(t)]])
print(np.allclose(Rz(0.5) @ Rx(0.3), Rx(0.3) @ Rz(0.5)))   # False

# QR 分解
A = np.random.randn(5, 3)
Q, R_ = np.linalg.qr(A)
print(np.allclose(Q.T @ Q, np.eye(3)), np.allclose(Q @ R_, A))
```

## 8. 二次型与正定矩阵

### 8.1 二次型

对对称矩阵 $A$，二次型为标量函数：

$$
f(\mathbf{x})=\mathbf{x}^\top A\mathbf{x}
$$

它描述"碗状"或"鞍状"曲面。很多代价函数都是二次型：

- LQR 代价：$\mathbf{x}^\top Q\mathbf{x}+\mathbf{u}^\top R\mathbf{u}$
- 机器人动能：$\tfrac12\dot{\mathbf{q}}^\top M(\mathbf{q})\dot{\mathbf{q}}$
- 高斯分布指数项：$(\mathbf{x}-\boldsymbol{\mu})^\top\Sigma^{-1}(\mathbf{x}-\boldsymbol{\mu})$

### 8.2 正定性

| 类型 | 定义 | 特征值 |
|---|---|---|
| 正定（$A\succ0$） | $\mathbf{x}^\top A\mathbf{x}>0,\ \forall\mathbf{x}\ne0$ | 全部 $>0$ |
| 半正定（$A\succeq0$） | $\mathbf{x}^\top A\mathbf{x}\ge0$ | 全部 $\ge0$ |
| 负定 | $<0$ | 全部 $<0$ |
| 不定 | 有正有负 | 有正有负 |

**判断方法**：计算特征值、做 Cholesky 分解（能成功说明正定）、检查各阶顺序主子式。

### 8.3 为什么重要

- **优化**：Hessian 正定 $\Rightarrow$ 局部极小点；凸二次规划（QP）要求 $P\succeq0$，是 MPC 的核心
- **LQR**：要求 $Q\succeq0$，$R\succ0$
- **动力学**：质量矩阵 $M(\mathbf{q})$ 对称正定（动能总是正的），因此一定可逆，才有 $\ddot{\mathbf{q}}=M^{-1}(\boldsymbol{\tau}-\dots)$
- **概率**：协方差矩阵 $\Sigma$ 对称半正定
- **RL**：高斯策略 $\pi(a|s)=\mathcal{N}(\mu,\Sigma)$ 中，$\Sigma$ 需保持正定，常用对角形式并参数化为 $\log\sigma$，保证 $\sigma>0$

### 8.4 Cholesky 分解

对称正定矩阵可分解为 $A=LL^\top$（$L$ 为下三角）。

用途：

- 高效求解线性方程组（比通用求解快约一倍）
- 采样多元高斯：$\mathbf{x}=\boldsymbol{\mu}+L\boldsymbol{\epsilon}$，$\boldsymbol{\epsilon}\sim\mathcal{N}(0,I)$
- 判断正定性

### 8.5 NumPy 实践

```python
# 构造对称正定矩阵
B = np.random.randn(4, 4)
A = B.T @ B + 1e-3 * np.eye(4)        # B^T B 半正定，加小量保证正定

print("特征值:", np.linalg.eigvalsh(A))            # 全部 > 0
L = np.linalg.cholesky(A)                          # 若不正定会抛出 LinAlgError
print(np.allclose(L @ L.T, A))

# 多元高斯采样
mu = np.zeros(4)
eps = np.random.randn(4, 10000)
samples = mu[:, None] + L @ eps
print(np.allclose(np.cov(samples), A, atol=0.5))   # 样本协方差约等于 A
```
