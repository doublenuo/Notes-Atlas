# 推理与规划

传统的大语言模型（LLM）通常采用输入 → 输出的工作方式，模型接收到用户的问题后直接生成答案。而 Agent 不同，它不仅需要理解用户意图，还需要分析问题、制定执行策略、调用工具，并根据执行结果不断调整下一步行动。

因此，一个能够自主完成复杂任务的 Agent，通常离不开两个核心能力：

- **Reasoning（推理）**：思考当前应该做什么。
- **Planning（规划）**：思考整个任务应该如何完成。

两者共同决定了 Agent 的智能水平，也是 Agent 与传统 ChatBot 最大的区别之一。

## 为什么 Agent 需要推理与规划

对于简单问题，例如：

> 北京是中国的首都吗？

LLM 可以直接回答。

但是对于复杂任务，例如：

> 帮我规划一趟东京三日游，并根据天气推荐每天的路线，最后生成 PDF。

Agent 无法一次生成最终答案，而需要经历多个步骤：

```mermaid
flowchart LR

A[用户任务]
--> B[理解任务]
--> C[制定执行计划]
--> D[调用工具]
--> E[分析结果]
--> F[调整计划]
--> G[生成最终答案]
```

整个过程中：

- 推理负责分析当前应该执行什么操作；
- 规划负责组织整个任务的执行流程；
- 工具负责获取外部信息；
- Observation（观察）则不断反馈执行结果，使 Agent 能够动态调整后续策略。

因此，Agent 更像一个能够思考 + 执行 + 修正的智能体，而不是简单的文本生成器。
