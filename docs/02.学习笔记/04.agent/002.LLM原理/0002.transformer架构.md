# transformer架构

2017 年，Google 在论文[《Attention Is All You Need》](https://arxiv.org/pdf/1706.03762)中首次提出了 Transformer 架构，并将其应用于机器翻译等序列建模任务。该模型完全摒弃了循环神经网络的结构，仅依靠注意力机制便在翻译任务上超越了当时最先进的循环神经网络模型，开启了自然语言处理的新范式。几乎与此同时，Fast.ai 在论文[《Universal Language Model Fine-tuning for Text Classification》](https://arxiv.org/pdf/1801.06146)中提出了 ULMFiT（Universal Language Model Fine-tuning）。该方法通过在大规模语料上预训练 LSTM 语言模型，再迁移到下游文本分类任务，仅需少量标注数据便取得了当时最优的性能，验证了**预训练 + 微调**这一范式的巨大潜力。这两项具有里程碑意义的工作分别推动了两条技术路线的发展：Transformer 架构和预训练语言模型。随后，这两条路线相结合，催生了两个影响深远的 Transformer 预训练模型：
- [GPT](https://openai.com/index/language-unsupervised/): 采用 Decoder-only 架构，以自回归方式进行预训练，擅长文本生成任务。
- [BERT](https://arxiv.org/abs/1810.04805): 采用 Encoder-only 架构，通过掩码语言模型（Masked Language Model, MLM）进行双向预训练，在文本理解任务上取得了突破性的性能。

## Transformer 模型的背景

Transformer 最初是为机器翻译任务设计的，整体采用 Encoder-Decoder 架构。在训练过程中，编码器（Encoder） 接收源语言句子作为输入，而解码器（Decoder）则根据已经生成的目标语言序列，逐步预测下一个单词。在编码器中，由于翻译一个单词往往需要结合整个句子的上下文信息，因此自注意力（Self-Attention）可以访问输入序列中的所有单词，从而学习全局语义表示。而解码器采用自回归（Autoregressive）的生成方式，即按照从左到右的顺序逐词生成目标序列。在预测当前单词时，解码器只能利用已经生成的目标单词，而不能看到未来的信息。例如，假设模型已经生成了前三个单词，那么这三个单词将作为解码器的输入，结合编码器输出的源语言表示，共同预测第四个单词。

> 实际训练时，为了充分利用 GPU 的并行计算能力，并不会像推理阶段那样逐词生成，而是将整个目标序列一次性输入解码器。为了保证训练方式与推理方式一致，Transformer 在解码器的自注意力层中引入了Mask机制。该 Mask 会屏蔽当前位置之后的所有单词，使模型在预测第 t 个单词时，只能访问前 t−1 个单词，而无法看到当前词及未来词，从而避免信息泄露。这样既实现了高效的并行训练，又保证了模型满足自回归生成的约束。

## Transformer组成

标准 Transformer 模型主要由编码器（Encoder）和解码器（Decoder）两部分组成。编码器负责对输入序列进行特征提取和语义建模，将原始输入映射为包含丰富上下文信息的高维语义表示；解码器则基于编码器生成的语义表示，并结合已生成的历史输出，逐步预测并生成目标序列。


![Transformer组成](https://picupload-1330431167.cos.ap-guangzhou.myqcloud.com/images/20260708141029279.png)

> 虽然标准 Transformer 同时包含编码器和解码器，但在实际应用中，两者通常会根据任务特点独立使用。编码器负责建模输入序列的上下文语义，因此形成了以 BERT 为代表的 Encoder-only 架构，主要用于文本理解任务，如文本分类、命名实体识别和语义匹配等；解码器负责根据历史信息自回归地预测下一个 Token，因此形成了以 GPT 为代表的 Decoder-only 架构，广泛应用于文本生成、代码生成和智能对话等生成式任务；而保留完整编码器—解码器结构的模型，如 T5 和 BART，则能够先理解输入，再生成输出，更适用于机器翻译、文本摘要以及其他 Seq2Seq 生成任务。

### 编码器模型

纯编码器模型（Encoder-only）仅保留 Transformer 架构中的编码器部分。在编码过程中，每个 Token 都可以通过自注意力机制访问输入序列中的所有 Token，因此具有双向上下文建模能力。这类模型通常采用自编码方式进行预训练，即通过随机遮盖输入序列中的部分 Token，并训练模型根据上下文恢复被遮盖的内容，从而学习丰富的语义表示。由于能够充分理解整个输入序列的上下文信息，纯编码器模型尤其适用于文本理解类任务，如文本分类、命名实体识别、语义匹配以及抽取式问答等。采用纯编码器架构的一些代表性模型包括：
- [BERT](https://arxiv.org/pdf/1810.04805) 是纯编码器架构最具代表性的预训练语言模型，由Google于2018年提出。BERT首次采用双向自注意力机制结合掩码语言模型进行预训练，使模型能够充分利用上下文信息学习词语表示，从而显著提升了文本理解能力。同时，BERT还引入了下一句预测任务，以增强模型对句间关系的建模能力。凭借优异的性能，BERT成为现代自然语言理解模型的重要基础，并广泛应用于文本分类、命名实体识别、情感分析、问答系统等任务；
- [RoBERTa](https://arxiv.org/pdf/1907.11692) 是由Meta于2019年提出的BERT改进模型。RoBERTa并未对模型结构进行修改，而是重点优化了预训练策略，包括移除下一句预测任务、采用动态掩码、扩大训练数据规模、延长训练时间以及增大批量大小等。这些改进充分释放了BERT架构的潜力，使RoBERTa在多数自然语言理解基准测试中取得了优于原始BERT的性能，也证明了预训练策略对于模型效果的重要性;
- [ALBERT](https://arxiv.org/pdf/1909.11942) 同样由Google于2019年提出，其核心目标是在尽可能保持模型性能的同时大幅减少模型参数。ALBERT采用了词嵌入矩阵分解和跨层参数共享两项关键技术，有效降低了模型规模和显存占用，同时减少了训练成本。此外，ALBERT将原有的下一句预测任务替换为句子顺序预测，进一步提升了模型对篇章语义关系的建模能力，因此在参数量远小于BERT的情况下仍取得了具有竞争力的性能;
- [DistilBERT](https://arxiv.org/abs/1910.01108) 通过知识蒸馏进行预训练，创建了一个更小的模型，该模型推理速度更快，训练所需的计算量也更少。在预训练过程中，DistilBERT 采用三重损失目标：语言建模损失、知识蒸馏损失和余弦距离损失。结果表明，DistilBERT 在内存占用减少 40%、计算速度提高 60% 的情况下，依然可以保持 97% 的性能；

### 解码器模型

纯解码器模型（Decoder-only）仅保留 Transformer 架构中的解码器部分，采用**自回归**方式进行预训练。在生成过程中，模型利用掩码多头注意力机制保证当前位置只能访问自身及之前已经生成的 Token，并根据历史上下文逐步预测下一个 Token，从而学习序列的概率分布。由于能够按照从左到右的方式连续生成文本，纯解码器模型尤其适用于开放式文本生成任务，如文本续写、对话生成、代码生成、机器翻译以及内容创作等。近年来，大语言模型（Large Language Models，LLMs）几乎均采用纯解码器架构，并通过大规模语料预训练获得了优异的语言理解与生成能力。采用纯解码器架构的一些代表性模型包括：
- GPT 由 OpenAI 于 2018 年提出，是最早将 Transformer 解码器成功应用于大规模预训练语言模型的工作之一。GPT 采用单向自回归语言建模目标，通过预测序列中的下一个 Token 学习语言知识，并利用预训练加微调的范式完成文本分类、自然语言推理和问答等多种下游任务，为后续 GPT 系列模型的发展奠定了基础；
- Meta 的 [LLaMA](https://arxiv.org/abs/2302.13971) 由 Meta 于 2023 年提出，是一系列高性能、开放权重的大语言模型。LLaMA 在模型结构上仍采用 Transformer 解码器架构，并通过大量公开语料进行训练，在相对较小的参数规模下取得了与更大模型相当的性能，为学术界和工业界的大语言模型研究提供了重要基础；
- [DeepSeek-R1](https://arxiv.org/abs/2501.12948) 是 DeepSeek 于 2025 年发布的大语言模型，在 Transformer 解码器架构基础上，引入大规模强化学习训练，使模型在数学推理、代码生成和复杂逻辑推理等任务上表现出较强能力。DeepSeek-R1 进一步验证了预训练 + 推理优化的发展路线，为提升大语言模型推理能力提供了新的思路。

## Transformer架构详解

原始 Transformer 采用经典的 Encoder–Decoder 架构，整体结构如下图所示。整个模型由左侧的编码器和右侧的解码器组成：编码器负责理解输入信息，解码器则利用编码结果生成最终输出。

![Transformer架构](https://picupload-1330431167.cos.ap-guangzhou.myqcloud.com/images/20260708143505054.png)

从模型结构可以发现，解码器包含两个注意力层。其中，第一个注意力层为掩码自注意力，**只能关注当前 Token 之前已经生成的内容，以保证生成过程满足自回归特性**；第二个注意力层则为编码器—解码器注意力，**利用编码器输出的上下文表示，使解码器在生成当前 Token 时能够访问整个输入序列的信息**。因此，解码器不仅能够结合历史生成结果，还能够充分利用源序列的全局语义信息，从而生成更加准确的目标序列。这一机制对于机器翻译等序列到序列任务尤为重要，因为不同语言之间往往存在词序差异，目标语言中的某个词可能需要依赖源语言后半部分甚至整个句子的语义信息，而不是简单地按照词语顺序进行逐词翻译。

### 输入

Transformer 本身并不能直接处理自然语言，它接收的输入必须是数值化的向量。因此，在文本进入 Transformer 之前，需要经过三个步骤：
- **分词**： 将连续的文本切分为一个个 Token，并转换为对应的 Token ID，使文本能够表示为一串整数序列；
- **词嵌入**：将离散的 Token ID 映射为高维连续向量，使每个 Token 都拥有能够表示语义信息的向量表示；
- **位置编码**：由于 Transformer 的自注意力机制本身不具备感知序列顺序的能力，因此需要为每个 Token 注入位置信息，使模型能够区分我爱你与你爱我这类仅顺序不同但语义完全不同的句子。

#### 分词

对于计算机而言，自然语言本质上是一串**字符序列**。一种最直观的想法是既然计算机能够处理字符，为什么不直接把每个字符编码后输入 Transformer，而要先进行分词呢？原因在于，**字符并不是语言中最合适的语义单位**。
- **单个字符通常无法表达完整的语义**：例如，智和能分别只是两个汉字，而智能组合在一起才表示一个完整的概念，如果完全按照字符进行处理，模型需要自己学习如何从字符组合中理解整个单词的含义，这会显著增加学习难度；
- **直接使用字符作为输入会导致序列长度大幅增加**：序列过长不仅会增加计算开销，还会占用更多显存，降低模型训练和推理效率。

因此，现代 Transformer 模型通常不会采用简单的字符分词或整词分词，而是使用**子词（Subword）分词**。子词分词位于字符和完整单词之间，它既能够保留较完整的语义信息，又能够有效控制词表规模，并且能够处理大量未见过的新词。此外，仅按照完整单词建立词表也存在问题。如果词表中没有某个新词，模型将无法识别它，这就是**未登录词（Out-of-Vocabulary，OOV）**问题。例如，当词表中没有 DeepSeek 时，传统按词切分的方法只能将其视为未知词。

完成分词之后，每个 Token 都会根据词表映射为唯一的整数编号（Token ID）。例如：

| Token       | Token ID |
| ----------- | -------: |
| 今天           |      125 |
| 天气        |      863 |
| 很          |     2147 |
| 好 |     9856 |

需要注意的是，Token 并不等同于单词。一个 Token 可以是一个汉字、一个词语、一个词根、一个标点符号，甚至只是单词的一部分。Transformer 真正处理的并不是原始文本，而是由这些 Token 组成的序列。

#### 词嵌入

经过分词之后，文本已经被转换成了一串 Token ID，模型的输入变成了这样的整数编码序列`[125, 863, 2147, 9856]`，但是这些Token ID 本质上只是词表中的索引，并不表示任何语义信息，Transformer 并不会直接使用 Token ID，而是首先通过**词嵌入**将每一个 Token 映射到一个高维连续向量。

假设词表大小为$V$，模型隐藏维度为$d$，则嵌入矩阵可以表示为

$$
E\in \mathbb{R}^{V\times d_{\mathrm{model}}}
$$

矩阵中的每一行都对应一个 Token 的向量表示，当输入 Token ID 为 125 时，本质上就是取出矩阵中的第 125 行作为该 Token 的表示， 因此，词嵌入本质上就是一个**可学习的查找表**。

需要注意的是，这些向量并不是人工设计的，在模型训练开始时，嵌入矩阵通常采用随机初始化，每个 Token 对应的向量都是一组随机数，不包含任何语义信息。随着模型不断训练，预测误差会通过反向传播更新整个嵌入矩阵。那些经常出现在相似上下文中的 Token，会逐渐学习到相似的向量表示。由此，**词嵌入将原本没有任何语义的离散编号，映射到了一个具有语义结构的连续向量空间**。在这个空间中，语义相近的 Token 往往拥有更接近的向量表示，Transformer 后续的注意力计算和神经网络运算也都是在这些向量上进行的，而不是直接处理 Token ID。

![词嵌入的原理](https://picupload-1330431167.cos.ap-guangzhou.myqcloud.com/images/20260708152126493.png)

#### 位置编码

Transformer 的自注意力机制（Self-Attention）在计算时会同时处理整个输入序列，其本质上是一种置换不变（Permutation Invariant）的运算。换言之，**如果仅使用词嵌入作为输入，自注意力机制无法感知 Token 之间的先后顺序**。例如，“我爱你”和“你爱我”包含完全相同的 Token 集合，但由于语序不同，其语义存在显著差异。为了使模型能够理解序列中的位置信息，Transformer 在输入表示中引入了位置编码（Position Encoding, PE）。

对于序列中的第 $i$ 个 Token，其最终输入表示为:

$$
\mathbf{x}_i=\mathbf{e}_i+\mathbf{p}_i
$$

其中$\mathbf{e}_i$表示第$i$个Token的词嵌入向量，$\mathbf{p}_i$表示对应的位置编码。

位置编码的方式有很多种，包括
- **绝对位置编码**：直接为序列中的每一个位置分配唯一的位置表示，并与词嵌入相加后输入模型。Transformer 原论文采用的是基于正弦函数和余弦函数构造的固定位置编码，其无需额外学习参数，并具有一定的长度外推能力。
- **相对位置编码**：绝对位置编码关注 Token 在序列中的具体位置，而相对位置编码更加关注 Token 之间的距离关系。例如，在自然语言中，当前位置附近的 Token 往往比远距离 Token 更重要。为此，相对位置编码直接在注意力计算过程中引入位置偏置，使模型学习 Token 间的相对距离信息，而非绝对位置。Transformer-XL、T5、DeBERTa 等模型均采用了不同形式的相对位置编码机制。
- **旋转位置编码**：RoPE 将位置信息编码为一组与位置相关的旋转变换，并作用于查询向量和键向量。通过旋转操作，模型能够在计算注意力分数时自然地获得相对位置信息，而无需显式构造位置偏置。由于 RoPE 具有良好的长度外推能力、较低的计算开销以及优异的长文本建模性能，目前已成为大语言模型中最主流的位置编码方案，被 LLaMA、Qwen、DeepSeek 等模型广泛采用。
- **可学习的位置编码**：将位置编码视为可训练参数，为每个位置维护一个独立的位置向量，并通过模型训练自动学习最优的位置表示。相比固定位置编码，该方法具有更强的表达能力，但通常难以泛化到超出训练长度的序列。BERT、ViT 等模型均采用了该方案。

Transformer 原论文采用了基于正弦函数和余弦函数构造的绝对位置编码，它不需要训练，而是利用正弦和余弦函数直接计算位置编码向量。

$$
PE(\mathrm{pos},2i) = \sin\left(\dfrac{\mathrm{pos}}{10000^{2i / d_{\mathrm{model}}}}\right) \\[10pt]
PE(\mathrm{pos},2i + 1) = \cos\left(\dfrac{\mathrm{pos}}{10000^{ 2i / d_{\mathrm{model}}}}\right)
$$

其中$\mathrm{pos}$代表Token所在的位置，$i$表示向量维度的索引，$d_{\mathrm{model}}$表示模型隐藏维度。也就是偶数位置使用$\sin$进行编码，奇数位置使用$\cos$进行编码。

下图展示了位置编码采用$\sin$和$\cos$函数的原理，横轴表示表示位置编码向量的各个维度，纵轴表示 Token 在序列中的位置，颜色表示该位置、该维度上的数值，整张图可以理解为一个位置编码矩阵。

### 注意力机制

文本经过输入层已经转换为一个由词嵌入组成的矩阵

$$
\mathbf{X}=(\mathbf{x_1},\mathbf{x_2},\mathbf{x_3}\cdots，\mathbf{x_n})
$$

其中$\mathbf{x_i}$表示第$i$个Token的输入表示（包括词嵌入与位置编码），维度为$d_{\mathrm{model}}$，然而，此时每个 Token 的表示仍然是独立的，尚未融合上下文信息。例如，句子中的"苹果"究竟表示水果还是苹果公司，仅凭其自身的词向量无法判断，还需要结合周围词语进行理解。因此，模型的核心任务是根据上下文对输入序列进行编码，使每个 Token 的表示能够融合整个句子的语义信息。在 Transformer 模型提出之前，对序列$\mathbf{X}$的编码是通过循环神经网络或卷积神经网络来进行。
- **循环神经网络**的方案很简单，采用递归的方式逐个处理序列中的 Token，每个位置的隐藏状态不仅依赖当前输入，还依赖前一时刻的隐藏状态。因此，第 $i$ 个 Token 的表示可以看作是前面所有 Token 信息的累积，从而实现对序列上下文的建模。然而，由于信息必须沿着序列逐步传递，RNN 难以充分利用并行计算，同时在长序列上容易出现梯度消失或长期依赖问题；
- **卷积神经网络**则采用滑动卷积核对局部上下文进行建模。例如，当卷积核大小为 3 时，每个 Token 的表示由其自身以及相邻两个 Token 共同计算得到，从而能够提取局部语义特征。相比 RNN，CNN 具有更高的并行计算效率，但其感受野受卷积核大小限制，若希望捕获更远距离的依赖关系，则需要堆叠更多卷积层或采用空洞卷积等结构。

正是由于 RNN 难以并行计算、CNN 难以高效建模长距离依赖，Transformer 提出了注意力机制，**序列中的每一个 Token 都主动关注整个输入序列，并根据其他 Token 与自身的相关程度，有选择地聚合信息，从而生成新的上下文表示**，在充分利用 GPU 并行计算能力的同时，有效捕获全局上下文信息。

#### 缩放点积注意力

基于注意力思路编码文本并非由 Google 首创，在早期的神经网络工作中许多研究者就已经提出了各种版本的注意力机制。直到 2017 年 Transformer 模型横空出世，才确定了注意力机制的形式，并被后续的工作所沿用，这种注意力机制的全称为缩放点积注意力。

![](https://picupload-1330431167.cos.ap-guangzhou.myqcloud.com/images/20260710122730059.png)

对于输入的任意一个 Token，每个 Token 都需要根据上下文动态决定关注哪些 Token，以及关注多少？最直接的方法就是计算它与其他所有 Token 的相似程度。因此，注意力机制的第一步就是建立一个**相关性矩阵**。

为了计算 Token 之间的相关性，Transformer 并没有直接使用输入向量，而是首先对输入矩阵进行三次线性变换，得到三个新的表示：

$$
\mathbf{Q}=\mathbf{X}\mathbf{W}_Q \\
\mathbf{K}=\mathbf{X}\mathbf{W}_K \\
\mathbf{V}=\mathbf{X}\mathbf{W}_V
$$

三个权重矩阵$\mathbf{W}_Q,\mathbf{W}_K,\mathbf{W}_V$都是**模型训练过程中学习得到的参数**，假设$\mathbf{X}\in\mathbb{R}^{n\times d_{\mathrm{model}}}$，则通常会有$\mathbf{Q},\mathbf{K}\in\mathbb{R}^{n\times d_k},\mathbf{V}\in\mathbb{R}^{n\times d_v}.$ 

注意力机制的核心思想是：根据查询与所有键之间的相关性，为不同位置的信息分配不同的关注权重，并利用这些权重对值进行加权聚合，从而生成融合全局上下文信息的新表示。整个计算过程主要包括两个步骤：
1. **计算注意力权重**：首先利用查询向量与所有键向量计算两者之间的相似度，得到注意力分数；随后通过 Softmax 函数将注意力分数归一化，使其转换为和为 1 的概率分布，即注意力权重，用于表示当前查询对各个键的关注程度；
2. **加权聚合值向量**：将得到的注意力权重与对应的值向量进行加权求和，生成当前查询对应的新语义表示。由于每个值对输出的贡献由注意力权重决定，因此输出不仅保留了当前 Token 的信息，还能够动态融合与其最相关 Token 的上下文语义信息。

形式化表示为：

$$
\mathrm{Attention}(\mathbf{Q,K,V})=\mathrm{softmax}\left(\frac{\mathrm{Q}\mathrm{K^T}}{\sqrt{d_k}}\right)\mathrm{V}
$$

- $\mathrm{Q}$表示查询矩阵，用于描述当前 Token 希望获取的信息;
- $\mathrm{K}$表示键矩阵，用于描述每个 Token 可供匹配的特征;
- $\mathrm{V}$表示值矩阵，包含最终需要传递和聚合的语义信息。

![](https://picupload-1330431167.cos.ap-guangzhou.myqcloud.com/images/20260713140743529.png)

#### 多头注意力机制

多头注意力（Multi-Head Attention）机制是在缩放点积注意力的基础上提出的一种并行注意力计算方法。其核心思想是：将输入的查询、键和值分别通过多组独立的线性变换映射到不同的特征子空间，在每个子空间中独立执行一次缩放点积注意力计算，最后将所有注意力头（Head）的输出进行拼接，并经过一次线性映射得到最终结果。 其整体结构如图所示。

![](https://picupload-1330431167.cos.ap-guangzhou.myqcloud.com/images/20260713141436548.png)

对于第$i$个注意力头，首先利用三组独立的权重矩阵将输入映射到对应的查询、键和值空间：

$$
\mathbf{Q}_i=\mathbf{Q}W_i^Q,\quad\mathbf{K}_i=\mathbf{K}W_i^K,\quad\mathbf{V}_i=\mathbf{V}W_i^V
$$

随后，在每个子空间内独立计算缩放点积注意力：

$$
\mathrm{head}_i=\mathrm{Attention}(\mathbf{Q}_i,\mathbf{K}_i,\mathbf{V}_i)=\mathrm{softmax}\left(\frac{\mathbf{Q}_i\mathbf{K}_i^T}{\sqrt{d_k}}\right)\mathbf{V}_i
$$

所有注意力头计算完成后，将各个 Head 的输出沿特征维度进行拼接，并通过输出投影矩阵 $W^O$ 融合来自不同子空间的信息，得到多头注意力机制的最终输出：

$$
\mathrm{MultiHead}(\mathbf{Q},\mathbf{K},\mathbf{V})=\mathrm{Concat}(\mathrm{head}_1,\mathrm{head}_2,\cdots,\mathrm{head}_h)W^O
$$

相比于单头注意力，多头注意力能够在**不同的表示子空间**中并行学习多种关联关系。不同的注意力头可以分别关注不同层面的信息，例如语法依赖、语义关联、位置关系以及长距离依赖等，从而使模型能够从多个角度理解输入序列，获得更加丰富且具有判别性的上下文表示。

![](https://picupload-1330431167.cos.ap-guangzhou.myqcloud.com/images/20260713143145922.png)

### 编码器

#### 残差连接

残差连接最早由何恺明等人在 [ResNet](https://arxiv.org/pdf/1512.03385) 中提出，其核心思想并不是简单地把输入加回来，而是**让神经网络学习输入与目标输出之间的变化量**，而不是直接学习完整的映射关系。

假设一个网络的输入为$X$, 希望学习得到输出$H(X)$, 传统神经网络直接学习从输入到输出的映射$H(X)=F(X).$ 也就是说，网络需要通过大量参数去拟合完整的目标函数。然而，当网络层数不断增加时，人们发现了一个非常奇怪的现象：理论上，网络越深，其表达能力应该越强，因为深层网络至少可以模拟浅层网络的功能；但实际上，当网络加深到几十层甚至上百层以后，训练误差反而开始增大，这种现象被称为 Degradation Problem。这里需要特别注意，它不是过拟合，而是训练误差本身变大了，说明模型虽然具有足够的表达能力，却越来越难以优化。

造成这一问题的重要原因在于，深层网络中很多层实际上并不需要学习新的特征，而只需要保持已有的信息。例如，某一层输入已经是一个非常好的语义表示，那么下一层最理想的情况可能就是什么都不要改变，即输出仍然等于输入，也就是$H(X)=X$，这就是所谓的**恒等映射**。然而，对于一个由线性变换、激活函数等组成的神经网络来说，要学习一个完全等于输入的映射实际上并不容易。网络需要不断调整参数，使所有层共同逼近这个恒等函数，这不仅增加了优化难度，也导致深层网络训练越来越困难。

因此定义了一个新的目标函数$H(X)=F(X)+X$, 这里的$F(X)$就称为残差，那么网络就只学习$F(X)=0$就可以实现恒等映射。从结构上来看，残差连接就是在神经网络旁边增加了一条恒等映射通路，使输入能够直接绕过当前网络，与网络输出相加。例如，对于某一个网络模块，其输入为$X$, 经过神经网络得到$F(X)$, 最终输出不是单独的$F(X)$, 而是$X+F(X).$

![](https://picupload-1330431167.cos.ap-guangzhou.myqcloud.com/images/20260713143412925.png)

可以看到，输入信息始终保留了一条不经过任何参数计算的捷径，即使神经网络这一层学习得不好，原始信息仍然能够直接传递到下一层，因此不会因为某一层性能较差而导致信息完全丢失。残差连接另一个更加重要的作用体现在反向传播过程中。假设网络输出为$H(X)=X+F(X)$, 根据求导法则，其关于输入的梯度为$1+\frac{\partial F(x)}{\partial x}$，梯度仍然至少保留了一条大小为 1 的传播路径，因此**梯度可以沿着恒等映射直接传递到前面的网络层，大大缓解了深层网络中的梯度消失问题**。

Transformer在每一个 Encoder Layer 包含两个子层：Multi-Head Attention 和 Feed-Forward Network。每经过一个子层，Transformer 都不会直接将新的特征替换掉原来的表示，而是先将输入与子层输出相加，再进行 Layer Normalization，即

$$
\mathrm{Output}=\mathrm{LayerNorm}\left(x+\mathrm{Sublayer}(x)\right)
$$

因此，每一层 Transformer 都是在已有语义表示的基础上进行增量式更新，而不是重新构建整个表示。假设某个 Token 已经拥有较好的上下文语义，那么当前层只需要学习哪些信息需要补充、哪些信息需要修正即可，而无需重新学习整个表示。这种保留已有信息，同时学习新的增量信息的方式，使得随着 Encoder 和 Decoder 层数不断增加，模型的表示能力能够逐步增强，同时又不会因为网络过深而导致优化困难。

#### 层归一化

随着网络不断加深，数据会不断经过线性变换、注意力计算、前馈网络以及残差相加。经过这些运算之后，每一层输出的数据分布都会发生变化。例如，对于一个 Token 的表示向量$x=[2.1，5.3，-1.2，8.4]$,经过多头注意力机制后可能变成$[15.8,23.6,-9.7，31.4]$，不同层输出向量的数值范围和分布都在不断变化，如果这种变化越来越剧烈，那么后续网络就必须不断适应新的输入分布，从而增加训练难度，使模型收敛速度变慢，甚至导致训练不稳定。因此，需要一种方法，使**每一层输出都保持相似的数据分布**，这就是归一化的目的。

Transformer采用LayerNorm进行归一化操作，LayerNorm 并不会计算整个 Batch 的统计信息，而是只针对当前这个 Token 的特征计算均值和方差，其计算步骤如下：
1. 以矩阵的行为单位求一个均值$u_j=\frac{1}{m}\sum_{i=1}^{m}x_{ij}$;
2. 以矩阵的行为单位求一个方差$\sigma_j^2=\frac{1}{m}\sum_{i=1}^m(x_{ij}-\mu_j)^2$；
3. 用每一行的元素减去这一列的均值再除以这一列的标准差从而得到归一化的数值

$$
\mathrm{LayerNorm}(x)=\frac{x_{ij}-\mu_j}{\sqrt{\sigma_j^2+\epsilon}}\gamma+\beta
$$

其中$\gamma$为可学习的缩放参数，初始值为1，维度与$X$相同;$\beta$为可学习的偏移参数，初始值为0, 维度与$X$相同.

#### 前馈网络层

在 Transformer 的 Encoder 和 Decoder 中，**前馈网络层（Feed-Forward Network，FFN）** 是每个编码器层和解码器层中的第二个核心子层，其主要作用是**对每一个 Token 的表示进行进一步的非线性特征变换**。与多头注意力机制负责建立不同 Token 之间的信息交互不同，前馈网络层不会计算 Token 之间的相关性，而是**独立地对每一个 Token 的上下文表示进行相同的非线性映射，从而进一步提取高层语义特征，增强模型的表达能力**。

对于输入矩阵 $\mathbf{X}$，前馈网络层由两个全连接层和一个激活函数组成，其数学表达式为：

$$
\mathrm{FFN}(\mathbf{X}) = \sigma(\mathbf{X}\mathbf{W}^{U}+\mathbf{b}_1)\mathbf{W}^{D}+\mathbf{b}_2
$$

其中，$\mathbf{W}^{U}$ 和 $\mathbf{W}^{D}$ 分别表示第一层和第二层线性变换的权重矩阵，$\mathbf{b}_1$ 和 $\mathbf{b}_2$ 为对应的偏置项，$\sigma(\cdot)$ 为非线性激活函数。在原始 Transformer 中采用 **ReLU** 作为激活函数，它能够为网络引入非线性，使模型能够学习更加复杂的特征表示。

从网络结构来看，前馈网络首先利用第一层全连接将输入特征映射到更高维的特征空间，在更大的表示空间中学习更加丰富的语义特征；随后通过 ReLU 激活函数增强模型的非线性表达能力；最后利用第二层全连接将特征重新映射回原始维度，以保证整个 Transformer 各层之间输入和输出的维度保持一致，从而便于后续进行残差连接。需要注意的是，前馈网络层中的 **Position-wise** 表示**逐位置计算**。也就是说，虽然输入是一个由多个 Token 组成的序列，但 FFN 并不会像多头注意力机制那样建立不同 Token 之间的信息交互，而是**对序列中的每一个 Token 独立执行完全相同的前馈网络计算，并共享同一组网络参数**。因此，FFN 的作用并不是学习 Token 之间的依赖关系，而是在多头注意力已经完成上下文信息融合的基础上，对每个 Token 的语义表示进行进一步的非线性加工和特征提炼。


### 解码器

Transformer 模型中的**解码器负责根据编码器最后一层的输出以及已生成的目标词元序列**，逐步预测下一个词元，从而实现自回归文本生成。与编码器仅包含一种注意力子层不同，解码器为了同时建模目标序列内部的依赖关系以及源序列与目标序列之间的对应关系，在每个 Decoder Layer 中设计了两种不同的注意力机制：掩码多头注意力和交叉注意力。
- **掩码多头注意力层**：该层与编码器中的多头自注意力机制计算方式基本相同，但在注意力计算过程中引入了**掩码（Mask）机制，将当前位置之后的所有词元进行屏蔽，使当前位置只能关注已经生成的词元，而无法访问未来的信息。这样可以保证模型满足自回归**生成的要求，即每一步只能依据历史信息预测下一个词元。如果不采用掩码机制，模型在训练过程中便能够直接看到后续真实词元，从而造成信息泄露，使预测任务失去意义；
- **交叉注意力层**：交叉注意力层负责建立源序列与目标序列之间的信息交互。其中，**查询向量来自掩码多头注意力层的输出，而键向量和值向量均来自编码器最后一层的输出**。通过这种设计，解码器能够在生成每一个目标词元时，根据当前已经生成的内容，有选择地关注源序列中最相关的信息，从而学习输入序列与输出序列之间的语义对应关系。例如，在机器翻译任务中，当解码器生成当前词元时，交叉注意力能够自动定位源语言中与其对应的词或短语，实现不同语言之间的语义对齐。由于编码器已经完成了整个输入序列的上下文建模，因此**解码器在每一层的交叉注意力中都可以访问编码器最后一层输出的全部键和值表示**，从而充分利用源序列的全局语义信息。

#### 掩码注意力机制

编码器中的自注意力机制允许每个 Token 与输入序列中的所有 Token 建立联系，因此每个位置都能够获取完整的上下文信息。而在解码器中，模型需要按照自回归的方式逐步生成目标序列，即当前位置只能依据已经生成的内容预测下一个 Token，而不能提前获取未来词元的信息。因此，Transformer 在解码器中引入了掩码注意力机制，通过人为限制注意力的计算范围，确保当前位置只能关注自身及其之前已经生成的 Token，而无法访问未来位置的信息，从而避免训练阶段的信息泄露，并保证训练过程与推理过程保持一致。

例如，对于输入序列今天天气很好，普通自注意力机制得到的注意力权重矩阵可能如下所示：

| Query/Key |       今天 |       天气 |        很 |        好 |
| --------- | -------: | -------: | -------: | -------: |
| **今天**        | **0.19** | **0.64** | **0.06** | **0.11** |
| **天气**        | **0.04** | **0.55** | **0.17** | **0.24** |
| **很**         | **0.03** | **0.18** | **0.12** | **0.67** |
| **好**         | **0.02** | **0.07** | **0.17** | **0.74** |

可以看到，在普通自注意力机制中，每一个 Token 都可以关注整个输入序列，这种机制非常适合编码器，因为编码器需要充分利用整个输入序列的信息来学习全局语义表示。然而，在解码器中，如果当前位置仍然能够关注未来 Token，就意味着模型在预测当前词时已经提前获得了正确答案，这将导致训练过程出现信息泄露。因此，解码器需要在注意力计算过程中加入掩码，将当前位置之后的所有位置全部屏蔽，使当前位置只能关注历史信息。

加入掩码后的注意力权重矩阵如下所示：

| Query/Key |    今天    |    天气    |     很    |     好    |
| --------- | :------: | :------: | :------: | :------: |
| **今天**    | **1.00** | **0.00** | **0.00** | **0.00** |
| **天气**    | **0.07** | **0.93** | **0.00** | **0.00** |
| **很**     | **0.09** | **0.33** | **0.58** | **0.00** |
| **好**     | **0.02** | **0.07** | **0.17** | **0.74** |

可以发现，加入 Mask 后，注意力权重矩阵变成了一个下三角矩阵，由此保证了每一个位置只能利用历史信息进行预测，满足自回归生成的要求。Mask 并不是简单地删除未来位置，而是在计算注意力分数时，将未来位置对应的元素加上一个极小值（通常为$-\infty.$)，对应的数学表达为：

$$
\mathrm{Attention}(Q,K,V)=\mathrm{softmax}\left(\frac{QK^T}{\sqrt{d_k}}+M\right)V
$$

#### 交叉注意力机制

交叉注意力机制是解码器区别于编码器的关键组成部分，其主要作用是**建立源序列与目标序列之间的语义联系**，使解码器在生成每一个 Token 时，都能够动态地从输入序列中获取最相关的信息。掩码多头注意力负责学习目标序列内部的依赖关系，交叉注意力则负责融合编码器提取的上下文信息，实现输入序列与输出序列之间的信息交互。

交叉注意力与自注意力具有相同的计算过程，不同之处在于三组输入向量的来源不同。在交叉注意力中，**查询向量来自解码器掩码多头注意力层的输出，而键向量和值向量均来自编码器最后一层的输出**，即

$$Q=W_QH_{decoder},\quad K=W_KH_{encoder},\quad V=W_VH_{encoder}$$

随后按照缩放点积注意力的方式计算注意力权重：

$$\text{CrossAttention}(Q,K,V)=\mathrm{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$
