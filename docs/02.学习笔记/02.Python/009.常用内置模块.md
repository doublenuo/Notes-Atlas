# Python 常用内置模块到底该怎么用？从 collections 到 itertools 一次讲清楚

标准库是 Python 最被低估的资产——很多人遇到「计数、组合、队列、日期」就吭哧吭哧手写循环，殊不知 `collections`、`itertools` 这些内置模块里早有现成的、还是 C 写的、比手写快得多的实现。这篇文章把最常用的几个模块一次讲清。

适合写过 Python、但一直「手撸」这些基础功能，或者想从「能用」进阶到「写得像 Python 老手」的人。读完你能想明白三件事：**这些模块分别解决什么问题、什么时候该用它而不是手写、以及那些容易踩的坑**。

## 一、collections：更聪明的容器

### Counter：计数器

`Counter` 本质是「键 → 出现次数」的字典，但把计数这件事做到了极致——统计字符、词频、投票，一行搞定。

```python
from collections import Counter

c = Counter("abracadabra")
print(c)                  # Counter({'a': 5, 'b': 2, 'r': 2, 'c': 1, 'd': 1})
print(c.most_common(2))   # [('a', 5), ('b', 2)]  出现最多的前 2 个

c2 = Counter("abc")
print(c + c2)             # Counter 支持加减运算，直接合并计数
# Counter({'a': 6, 'b': 3, 'r': 2, 'c': 2, 'd': 1})
```

**注意点**：`Counter` 还能直接吃列表、可迭代对象，`c["某个键"]` 取不到时返回 `0`（而不是报 KeyError），比普通 dict 做计数省心太多。

### defaultdict：带默认值的字典

普通 dict 访问不存在的键会抛 `KeyError`，于是你要写一堆 `if key not in d`。`defaultdict` 让你指定一个「默认值工厂」，键不存在时自动用它生成默认值。

```python
from collections import defaultdict

d = defaultdict(int)   # 默认值工厂 int() → 0
d["a"] += 1
d["b"] += 1
d["b"] += 1
print(dict(d))         # {'a': 1, 'b': 2}

dd = defaultdict(list)  # 默认值是空 list，直接 append
dd["k"].append(1)
dd["k"].append(2)
print(dict(dd))         # {'k': [1, 2]}
```

**误区一：`defaultdict` 访问不存在的键会「静默创建」它**。普通 dict 的 `d["x"]` 是「只读、取不到报错」，而 `defaultdict` 的 `d["x"]` 会**顺手把 `x` 这个键插进去**。

```python
d = defaultdict(int)
print(d["x"])      # 0   以为只是「读」，结果键被创建了
print(dict(d))     # {'x': 0}  多了一个键！
```

**注意点**：别在「只是想看看有没有这个键」的地方用 `defaultdict`，它会污染你的字典。真正的「读」，用 `d.get(key)` 或 `key in d`。

### deque：双端队列

**CPython 细节①：`deque` 底层是双向链表，两端操作 O(1)**。而 `list` 的 `insert(0, x)` 和 `pop(0)` 是 O(n)——因为要把后面所有元素整体挪一位。

**误区二：用 `list` 当队列，`insert(0)`/`pop(0)` 是 O(n)**。

```python
from collections import deque

dq = deque([1, 2, 3])
dq.append(4)        # 右边加
dq.appendleft(0)    # 左边加，O(1)
print(dq)           # deque([0, 1, 2, 3, 4])

print(dq.pop())     # 4   右边弹出
print(dq.popleft()) # 0   左边弹出，O(1)
print(dq)           # deque([1, 2, 3])
```

**注意点**：做「先进先出」队列、或需要频繁在两端增删的场景，一律用 `deque`。`list` 只有在「只在末尾操作」时才是 O(1)（当栈用）。

### namedtuple 与 OrderedDict（简要）

- `namedtuple`：给元组的每个位置起名字，既轻量又自解释。
- `OrderedDict`：记住插入顺序的字典。**但 Python 3.7+ 的普通 `dict` 已经天然有序**，所以它现在主要用在一个场景——判断两个 dict 是否「按顺序相等」。

```python
from collections import namedtuple

Point = namedtuple("Point", ["x", "y"])
p = Point(1, 2)
print(p.x, p.y)   # 1 2
print(p[0])       # 1  还能按下标取
```

## 二、itertools：迭代器的瑞士军刀

### 无限迭代器

`count`、`cycle`、`repeat` 是「无限长」的迭代器，配合 `islice` 或 `break` 使用。

```python
import itertools

# count(10)：从 10 开始无限数下去
print(list(itertools.islice(itertools.count(10), 3)))  # [10, 11, 12]

# repeat("x", 3)：重复 3 次
print(list(itertools.repeat("x", 3)))   # ['x', 'x', 'x']
```

**CPython 细节②：`itertools` 是惰性的、C 实现的**。`count()` 这种「无限序列」之所以不爆内存，是因为它**用到哪算到哪**，从不在内存里展开整个序列。这也意味着——**误区三：`itertools` 的迭代器只能遍历一次**，和生成器一样，走完就空。

```python
it = itertools.count(1)
print(next(it), next(it))   # 1 2
# 迭代器是「一次性」的，别指望能重复从头遍历同一个迭代器
```

### 组合迭代器

`product`（笛卡尔积）、`permutations`（排列）、`combinations`（组合）——凡是「枚举所有可能」的需求，别再手写嵌套循环。

```python
print(list(itertools.product("AB", [1, 2])))
# [('A', 1), ('A', 2), ('B', 1), ('B', 2)]  笛卡尔积

print(list(itertools.permutations("ABC", 2)))
# [('A','B'),('A','C'),('B','A'),('B','C'),('C','A'),('C','B')]  排列（有序）

print(list(itertools.combinations("ABC", 2)))
# [('A','B'),('A','C'),('B','C')]  组合（无序）
```

**注意点**：排列和组合的区别是「顺序算不算数」——`AB` 和 `BA` 在排列里是两个，在组合里是一个。

### chain / zip_longest / groupby

```python
print(list(itertools.chain([1, 2], [3, 4])))   # [1, 2, 3, 4]  多个可迭代对象接成一条

# zip_longest：两个不等长时，短的补 fillvalue（默认 None）
print(list(itertools.zip_longest("AB", [1], fillvalue=None)))
# [('A', 1), ('B', None)]

# groupby：按 key 把相邻元素分组（注意：要先排序，只合并「相邻」的）
data = [("a", 1), ("a", 2), ("b", 3)]
for key, group in itertools.groupby(data, key=lambda x: x[0]):
    print(key, list(group))
# a [('a', 1), ('a', 2)]
# b [('b', 3)]
```

**注意点**：`groupby` 只合并**相邻**的相同 key，所以数据得先按 key 排好序，否则同一 key 会被拆成好几组。这是 `groupby` 最容易用错的地方。


## 三、datetime 与 time：日期时间处理

### datetime 与 timedelta

`datetime` 表示一个具体的日期时间，`timedelta` 表示一段时间差，两者可以直接做加减。

```python
from datetime import datetime, timedelta

now = datetime(2024, 8, 8, 12, 30, 0)
print(now)                                  # 2024-08-08 12:30:00
print(now + timedelta(days=1, hours=2))     # 2024-08-09 14:30:00

delta = now - datetime(2024, 8, 1)
print(delta.days)                           # 7
```

### strftime / strptime 与时间戳

`strftime` 把 datetime **格式化**成字符串，`strptime` 把字符串**解析**成 datetime。两者格式串共用一套指令（`%Y` 年、`%m` 月、`%d` 日、`%H` 时、`%M` 分、`%S` 秒）。

```python
print(now.strftime("%Y-%m-%d %H:%M:%S"))          # 2024-08-08 12:30:00
print(datetime.strptime("2024-08-08", "%Y-%m-%d"))  # 2024-08-08 00:00:00

print(now.timestamp())   # 1723091400.0  （Unix 时间戳，依赖本地时区）
```

**注意点**：`strftime` 是「字符串格式化」的 format，`strptime` 是「字符串解析」的 parse，方向相反，别记混。另外 naive datetime（不带时区）做 `timestamp()` 会用**本地时区**换算，跨时区程序要小心。

**常用方法速查**：

| 方法 | 作用 |
|------|------|
| `datetime.now()` | 当前日期时间 |
| `datetime.today()` | 同上（naive） |
| `dt.strftime(fmt)` | 格式化输出 |
| `datetime.strptime(s, fmt)` | 解析字符串 |
| `dt.timestamp()` | 转 Unix 时间戳 |
| `dt.date()` / `dt.time()` | 拆出日期/时间 |

## 四、os 与 sys：和系统打交道

`os` 管「操作系统层面」的事（路径、环境变量、进程），`sys` 管「Python 解释器本身」的事（命令行参数、模块路径、退出）。

```python
import os, sys

print(os.getcwd())                # 当前工作目录
print(os.environ.get("HOME"))     # 读环境变量
print(os.path.join("a", "b"))     # 拼路径（跨平台）

print(sys.argv)                   # 命令行参数列表，argv[0] 是脚本名
print(sys.version.split()[0])     # Python 版本
sys.exit(0)                       # 退出程序（0 表示正常）
```

**注意点**：路径操作用上一篇文章的 `pathlib.Path` 更现代（`Path("a") / "b"` 更清晰），`os.path` 是老写法但依然到处都是；`sys.argv` 是做 CLI 工具拿参数的第一站（更复杂的用 `argparse`）。

## 五、random 与 math：随机数与数学

### random

`random` 生成随机数。**`seed` 固定种子后，随机序列完全可复现**——这是写测试、复现 bug、做实验的必备技能。

```python
import random

random.seed(42)
a = random.random()     # [0, 1) 的随机浮点
random.seed(42)         # 同样的种子
b = random.random()
print(a == b)           # True  种子相同，序列可复现

print(random.randint(1, 6))              # 1~6 的随机整数
print(random.choice(["a", "b", "c"]))    # 随机挑一个

lst = [1, 2, 3]
random.shuffle(lst)      # 原地洗牌
print(lst)               # 乱序
```

**注意点**：`random` 是**伪随机**（梅森旋转算法），可预测、可复现，不适合加密。要加密级随机数，用 `secrets` 模块（生成 token、验证码）。

### math

`math` 是数学函数的大本营，还顺带解决了浮点比较的世纪难题：

```python
import math

print(math.sqrt(16))       # 4.0
print(math.ceil(3.2))      # 4   向上取整
print(math.floor(3.8))     # 3   向下取整
print(math.pi)             # 3.141592653589793
print(math.isclose(0.1 + 0.2, 0.3))   # True  浮点近似比较
```

**注意点**：`math.isclose` 是之前那篇「float 陷阱」里的正确比较姿势；`ceil`/`floor` 注意和 `round` 的区别（`round` 是四舍五入、且 banker's rounding 遇 5 取偶）。


## 小结

回头看这条主线：**collections（更聪明的容器）→ itertools（迭代器工具）→ datetime（日期时间）→ os/sys（系统交互）→ random/math（随机与数学）**。三句话收尾：

1. **计数用 `Counter`、分组默认值用 `defaultdict`、队列用 `deque`**——别再用普通 dict 和 list 手撸，前者是 C 写的还更少 bug。
2. **枚举组合用 `itertools`，但要记住它是惰性的、只能遍历一次**，`groupby` 要先排序。
3. **`defaultdict` 读键会偷偷创建键**，想要「只读不创建」就回到 `dict.get()`。

### 几个常见问题

**Q1：`Counter` 和普通 dict 计数有什么区别？**
`Counter` 专门为计数优化：`most_common` 排序、取不到键返回 0、支持加减合并。手写 dict 计数要自己处理这些。

**Q2：`deque` 和 `list` 做队列哪个快？**
`deque` 两端操作 O(1)，`list` 的 `insert(0)`/`pop(0)` 是 O(n)。做队列用 `deque`。

**Q3：`defaultdict` 访问不存在的键会怎样？**
会**静默创建**这个键（用默认值工厂生成的值）。只想判断键在不在，用 `key in d` 或 `d.get(key)`。

**Q4：`itertools` 的迭代器能重复遍历吗？**
不能，它是惰性迭代器，只能遍历一次。需要重复用就 `list()` 转成列表。

**Q5：随机数怎么才能复现？**
固定种子 `random.seed(42)`，之后的随机序列就完全可复现。加密场景别用 `random`，用 `secrets`。
