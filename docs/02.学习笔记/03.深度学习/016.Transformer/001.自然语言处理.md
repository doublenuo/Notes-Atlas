# 自然语言处理

自然语言处理（Natural Language Processing，NLP）是人工智能的重要分支，旨在让计算机能够理解、生成和处理人类语言。

本文将按照统计语言模型、神经网络模型、预训练模型和大语言模型四个阶段，对自然语言处理的发展进行梳理。

## 统计语言模型

随着互联网的发展和计算能力的提升，研究人员开始尝试利用大量文本数据自动学习语言规律，而不再依赖人工编写复杂的语言规则。这一阶段的核心思想是**一个词出现的概率可以通过它前面若干个词来预测**。

例如对于一个三元模型在预测当前词时，模型仅考虑前面两个词的信息，而忽略更远位置的上下文信息，这种做法实际上基于一个重要假设，马尔可夫假设，即未来状态只与最近的有限个历史状态有关。然而，人类语言中往往存在大量跨越较长距离的语义和语法依赖关系。

为了捕获更远的上下文，可以增大 N 的取值，例如使用 5-Gram 或 10-Gram，然而这样又会引发严重的数据稀疏问题，因此统计模型只能统计词频和共现概率，而无法真正理解词语的语义信息。
