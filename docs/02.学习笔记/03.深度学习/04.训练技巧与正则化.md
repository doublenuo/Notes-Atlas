# 训练技巧与正则化

前面三章把骨架搭完了：网络结构、反向传播、优化器。但真开始训练就会发现，同样的骨架，有人一次跑通、有人 loss 不降、有人训练集 99% 测试集 70%——差距全在"骨架之外"的细节里。这一章讲的正是这些细节：参数怎么初始化、梯度怎么在深层里活下来、过拟合怎么压、训练过程怎么监控。它们不改变模型的表达能力，但决定模型能不能被训出来、训出来能不能用。

## 参数初始化

### 为什么要随机初始化

权重如果全初始化成同一个值（比如全 0），同一隐藏层的所有神经元在前向时算出完全相同的输出，反向时收到完全相同的梯度——更新之后还是相同。这叫**对称性**，加多少个神经元都等于只有一个。所以初始权重必须打破对称：随机、且不能太小也不能太大。

太小的问题：信号经过多层连乘后衰减到零附近，梯度跟着消失。太大的问题：信号被激活函数挤进饱和区，或者直接溢出。初始化的目标就是把方差控制在一个"刚好合适"的范围里，让每层的激活值和梯度在统计上保持稳定。

### Xavier 初始化

Xavier/Glorot 初始化（Glorot & Bengio, 2010）的推导出发点是：**前向传播时各层激活值的方差保持不变，反向传播时各层梯度的方差也保持不变**。对线性层 $z = Wx + b$，假设 $x$ 的各分量独立同分布、均值为零、方差为 $\sigma_x^2$，$W$ 同理，要让 $\mathrm{Var}(z)$ 与层宽无关，需要：

$$
\mathrm{Var}(W) = \frac{2}{n_{\text{in}} + n_{\text{out}}}
$$

$n_{\text{in}}, n_{\text{out}}$ 是该层的输入和输出维度。均匀分布采样 $U(-a, a)$ 时 $a = \sqrt{6/(n_{\text{in}}+n_{\text{out}})}$；正态分布采样 $\mathcal{N}(0, 2/(n_{\text{in}}+n_{\text{out}}))$。

Xavier 是为 **Sigmoid/Tanh** 设计的——这两者在原点附近导数接近 1（Tanh）或 0.25（Sigmoid），推导里用到了"激活函数在原点线性"的近似。配 ReLU 用就不太对：ReLU 会把一半的激活砍成零，方差实际上减半，信号仍然会逐层衰减。

### He 初始化

He/Kaiming 初始化（He et al., 2015，就是 ResNet 那篇）针对 ReLU 修正了这个方差。ReLU 之后正值一半被保留，要把方差补回来，就需要：

$$
\mathrm{Var}(W) = \frac{2}{n_{\text{in}}}
$$

注意只依赖输入维度 $n_{\text{in}}$，不看输出。直觉：ReLU 是半激活，$n_{\text{in}}$ 个输入里平均只有 $n_{\text{in}}/2$ 个活着，每个的方差要加倍才能撑住下一层的输入。均匀分布时 $a = \sqrt{6/n_{\text{in}}}$（PyTorch 里 `nn.init.kaiming_uniform_` 有个 $\sqrt{3}$ 系数的细微差别，以文档为准）。

### 实际怎么用

PyTorch 里全连接层默认就是 Kaiming 均匀初始化，卷积层也是，所以现代框架下其实"不写也对"。但换激活函数、自己写层、或者遇到初始化不收敛时，显式初始化是第一个要检查的旋钮：

```python
import torch.nn as nn

# 全连接 + ReLU
nn.init.kaiming_normal_(layer.weight, nonlinearity='relu')
nn.init.zeros_(layer.bias)

# 全连接 + Tanh（Xavier）
nn.init.xavier_normal_(layer.weight)
nn.init.zeros_(layer.bias)

# Transformer 常见：Xavier + 特定增益，或直接 normal_(std=0.02)
nn.init.normal_(layer.weight, std=0.02)
```

偏置通常初始化为零，没什么争议。实操口诀：**ReLU 系用 He，Sigmoid/Tanh 用 Xavier，Transformer 里小 std 正态也够用**。初始化引发的训练失败有个典型症状：loss 从第一步就是 NaN，或者几千步都不动——先查初始化，再查学习率。

## 归一化

深层网络里每一层的输入分布会随着前面层的参数更新而不断漂移，后面层就得不停重新适应——这曾经被解释为"内部协变量偏移"（internal covariate shift）。归一化（normalization）就是把每层的输入（或激活）拉回一个稳定的分布，让训练更稳、学习率可以开更大。这个动机的现代解释其实有争议（有人认为归一化真正的作用是平滑损失地形），但工程效果是公认的：没有归一化，深层网络基本训不动。

### 批归一化

批归一化（BatchNorm, Ioffe & Szegedy, 2015）作用在每个特征维度上，用**当前 mini-batch** 的统计量做标准化：

训练时：

$$
\mu_{\mathcal{B}} = \frac{1}{B}\sum_{i=1}^{B} z_i, \qquad
\sigma^2_{\mathcal{B}} = \frac{1}{B}\sum_{i=1}^{B}(z_i - \mu_{\mathcal{B}})^2
$$

$$
\hat{z}_i = \frac{z_i - \mu_{\mathcal{B}}}{\sqrt{\sigma^2_{\mathcal{B}} + \epsilon}}, \qquad
y_i = \gamma\,\hat{z}_i + \beta
$$

$\gamma, \beta$ 是可学习的缩放和偏移——标准化把分布强制拉成零均值单位方差，万一这个变换对任务有害，网络可以通过 $\gamma, \beta$ 把它变回来。没有这两个参数的话，BatchNorm 会硬性破坏层的表达能力。

测试时问题来了：单个样本没有"batch 统计量"可用。解决方案是训练过程中维护 $\gamma, \beta$ 之外的**移动平均**（running mean/var，动量约 0.1），推理时用它们代替 batch 统计量：

```python
# 训练循环里 model.train() 用 batch 统计量并更新 running stats
# 推理前 model.eval() 切换到 running stats
model.train()
...
model.eval()
with torch.no_grad():
    ...
```

`train()` / `eval()` 忘了切换是 BatchNorm 最经典的事故：用 eval 模式训练，running stats 永远不更新，推理时用的是一堆过时的随机值。

放置位置有两种流派：BN-ReLU（先归一化再激活，原论文）和 ReLU-BN（先激活再归一化，ResNet 实践）。实测差别不大，跟团队约定走即可。

BatchNorm 的软肋也明确：**batch 太小时统计量噪声大**（batch=1 或 2 时直接崩），而且它天然把同一个 batch 的样本耦合了——对 batch size 敏感、对 RNN 这种变长序列不友好、推理和训练行为不一致。这些软肋催生了下面的 LayerNorm。

### 层归一化

层归一化（LayerNorm, Ba et al., 2016）不跨样本统计，而是**对单个样本的所有特征**做标准化：

$$
\mu_i = \frac{1}{H}\sum_{h=1}^{H} z_{ih}, \qquad
\sigma^2_i = \frac{1}{H}\sum_{h=1}^{H}(z_{ih} - \mu_i)^2, \qquad
\hat{z}_{ih} = \frac{z_{ih}-\mu_i}{\sqrt{\sigma^2_i+\epsilon}}
$$

同样的 $\gamma, \beta$ 可学习变换。因为统计量只依赖单个样本，训练和推理行为完全一致，也不需要 running stats——BatchNorm 那套 train/eval 切换的坑全没了。batch 内样本互相独立，batch size = 1 也能用。

Transformer 从原始论文开始就用 LayerNorm，而且是放在注意力/FFN **子层内部**（pre-LN）而不是外面（post-LN）——pre-LN 训练更稳、对学习率不那么敏感，如今已经是大模型标配。GPT、LLaMA 这一代模型还常把 LayerNorm 换成更简的 **RMSNorm**（只减均值不减、只做均方根缩放），少算一个均值，效果基本持平。

选型可以粗暴记：**CNN 用 BatchNorm，Transformer/序列模型用 LayerNorm（pre-LN + RMSNorm）**。其他变体混个脸熟：GroupNorm（把通道分组做 norm，小 batch 视觉任务替代 BN）、InstanceNorm（每样本每通道单独 norm，风格迁移常用）。

## 正则化手段

模型容量大于数据复杂度时就会过拟合，上一章讲过偏差-方差权衡。这一节的四个手段——Dropout、权重衰减、数据增强、早停——从不同角度压同一个问题。

### Dropout

Dropout（Srivastava et al., 2014）训练时以概率 $p$ 随机把一部分神经元输出置零：

$$
\tilde{h}_i = \frac{m_i \cdot h_i}{1-p}, \qquad m_i \sim \text{Bernoulli}(1-p)
$$

除以 $(1-p)$ 叫** inverted dropout**，目的是让训练时激活值的期望和推理时保持一致——这样推理就不用再缩放了。$p$ 常取 0.5（隐藏层大）或 0.1~0.3（靠近输出）。PyTorch 的 `nn.Dropout` 默认就是 inverted 版本。

为什么这能防过拟合？主流的解释是**隐式模型集成**：每次 dropout 都相当于在采样一个子网络，训练 $N$ 轮相当于同时训练了 $2^N$ 个共享权重的子网络，推理时它们的效果被平均起来。另一个角度是它强迫冗余——任何神经元都不能依赖某个特定搭档，特征必须更鲁棒。

```python
class MyNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear(784, 256)
        self.dropout = nn.Dropout(p=0.5)
        self.fc2 = nn.Linear(256, 10)

    def forward(self, x):
        x = F.relu(self.fc1(x))
        x = self.dropout(x)          # 训练时随机置零，eval 时恒等
        return self.fc2(x)
```

和 BatchNorm 一样，**必须记得 `model.train()` / `model.eval()` 切换**——eval 模式下 Dropout 自动变成恒等映射。

### 权重衰减

权重衰减上一章讲 AdamW 时已经展开过：给损失加 $\frac{\lambda}{2}\|\theta\|^2$ 惩罚（或等价地在更新时收缩参数），鼓励模型用小权重实现同样的拟合——小权重意味着函数更平滑、对输入扰动更不敏感，泛化更好。Adam 优化器记得用 AdamW 的解耦版本，别让自适应分母把正则化吃掉。

$\lambda$ 的量级参考：视觉任务 SGD 常用 1e-4~5e-4，Transformer 训练 AdamW 常用 0.01~0.1（配合 warmup）。太大直接欠拟合，loss 压不下去。

### 数据增强

数据增强（data augmentation）不改模型，直接改数据：对训练样本做保持标签不变的变换，等效于增大训练集、引入先验。视觉任务的经典招式：

- **几何类**：随机裁剪、水平翻转、旋转、仿射变换；
- **颜色类**：亮度/对比度/饱和度抖动、色彩通道丢弃；
- **遮挡类**：Cutout（随机抠方块）、CutMix（两图按区域混合）、Random Erasing；
- **混合类**：Mixup（两张图和两个标签按 $\lambda$ 凸组合）、CutMix 可以看作 Mixup 的区域版本；
- **高级类**：AutoAugment（用搜索学出来的增强策略）、RandAugment（简化版，均匀采样强度）。

NLP 那边思路不同但目的一致：回译、同义词替换、随机删词（注意别删掉改变标签的关键词）。强化学习、机器人仿真里也有对应物——域随机化（domain randomization）本质就是把物理参数当增强来采样。

增强的度要把握：变换必须真的保持标签（猫翻转还是猫，但上下翻转就未必了），强度过大等于给模型喂噪声。ImageNet 上验证过的组合基本可以照搬，领域数据自己肉眼检查几批再定。

### 早停

早停（early stopping）的想法很朴素：过拟合的表现是验证误差先降后升，那就在验证误差开始回升时停下来。

```python
best_val = float('inf')
patience, wait = 10, 0

for epoch in range(max_epochs):
    train_one_epoch(model)
    val_loss = evaluate(model, val_loader)
    if val_loss < best_val:
        best_val = val_loss
        torch.save(model.state_dict(), 'best.pt')   # 顺便存最好的那版
        wait = 0
    else:
        wait += 1
        if wait >= patience:
            print(f'早停于 epoch {epoch}')
            break

model.load_state_dict(torch.load('best.pt'))   # 恢复最佳权重
```

`patience` 就是"容忍多少个 epoch 不进步"，典型取 5~15。早停和权重衰减其实是一回事的两种表述——都是限制有效训练时长/有效容量，Pratt 1993 年就有论文指出两者在特定条件下等价。实践里通常一起用，早停负责兜底，权重衰减负责持续正则。

### 四个手段怎么搭配

没有统一配方，但有个常用的起手式：数据增强必上（免费的午餐）；权重衰减必上（AdamW 默认 0.01）；Dropout 在全连接层里好用、CNN 里可以先不上（BN 有一定正则效果，两个叠太多反而欠拟合）；早停看验证曲线再决定。真正要紧的是**盯着验证集做决策**，而不是闭眼堆技巧。

## 梯度消失与爆炸

### 为什么会发生

反向传播是链式法则连乘。对第 $l$ 层：

$$
\frac{\partial L}{\partial W^{(l)}} = \frac{\partial L}{\partial z^{(L)}} \prod_{k=l+1}^{L} \frac{\partial z^{(k)}}{\partial z^{(k-1)}}
$$

每个连乘项的 Jacobian 谱半径小于 1 时，层数越深梯度指数衰减——**梯度消失**，浅层参数几乎不动，深层先收敛浅层滞后，网络"学不动"。谱半径大于 1 则反过来指数放大——**梯度爆炸**，loss 直接变 NaN，或者 loss 上下剧烈震荡。

上一章激活函数的梯度表已经给了第一个诱因：Sigmoid 最大导数 0.25，连乘十层就是 $10^{-6}$；Tanh 两端也饱和。第二个诱因就是初始化：权重方差不对，信号和梯度的方差逐层指数变化。第三个诱因是深度本身——ResNet 之前的网络到 20 层就很难训，根本矛盾就在这。

现代深度学习里，梯度消失被三板斧基本治住了：**ReLU 系激活**（正半轴导数恒 1）、**He 初始化**（方差匹配）、**残差连接**（给梯度一条直达浅层的高速公路，第 2 章提过、第 5 章卷积网络会正式展开）。残差结构下哪怕中间 Jacobian 全是零，梯度也能从 skip connection 无损传回去，这是 ResNet 能堆到上百层的根本原因。

### 梯度裁剪

梯度爆炸的常用止血带是**梯度裁剪**（gradient clipping）。两种形式：

**按值裁剪**（clip by value）：每个分量硬截断到 $[-c, c]$——简单粗暴，但会破坏梯度方向。

**按范数裁剪**（clip by norm）：整个梯度向量的 $p$-范数超过阈值时，等比例缩放回阈值——保方向，更常用：

$$
g \leftarrow \begin{cases}
g & \text{if } \|g\| \leq c \\
c \cdot \dfrac{g}{\|g\|} & \text{if } \|g\| > c
\end{cases}
$$

```python
# PyTorch 一行
torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)

# 或按值
torch.nn.utils.clip_grad_value_(model.parameters(), clip_value=0.5)
```

放置位置在 `loss.backward()` 之后、`optimizer.step()` 之前——先拿到完整梯度，再决定削不削。阈值 $c$ 常取 0.5~5.0，RNN 和 Transformer 训练里几乎是必选项（序列长、连乘路径多，偶发的大梯度很常见）；CNN 训练梯度本来就稳定，用得少。注意裁剪治的是**爆炸的后果**，不治爆炸的**原因**——如果每一步都在疯狂裁剪，说明初始化、学习率或网络结构有问题，该回头查根源。

## 实验：Fashion-MNIST 分类与消融

概念都齐了，上真数据。这一节用 Fashion-MNIST（10 类服装图像，比 MNIST 稍难、又不至于像 ImageNet 那样要 GPU 跑一天）训练一个小 MLP，然后做一组消融实验（ablation study）：把每个技巧单独关掉，看它到底贡献了多少。

### 环境与数据

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
from torch.utils.data import DataLoader
from torchvision import datasets, transforms
import matplotlib.pyplot as plt
import numpy as np

device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
torch.manual_seed(42)

tfm = transforms.Compose([
    transforms.ToTensor(),
    transforms.Normalize((0.2860,), (0.3530,)),   # Fashion-MNIST 全局均值/标准差
])

train_ds = datasets.FashionMNIST('./data', train=True, download=True, transform=tfm)
test_ds  = datasets.FashionMNIST('./data', train=False, transform=tfm)
# 留 10% 训练集做验证
n_val = len(train_ds) // 10
train_sub, val_ds = torch.utils.data.random_split(train_ds, [len(train_ds) - n_val, n_val])

train_loader = DataLoader(train_sub, batch_size=128, shuffle=True)
val_loader   = DataLoader(val_ds,   batch_size=256)
test_loader  = DataLoader(test_ds,  batch_size=256)
print(f'train={len(train_sub)}  val={len(val_ds)}  test={len(test_ds)}')
```

### 可配置的 MLP

把归一化层、Dropout 做成开关，初始化方式做成参数，消融时只改配置、不改网络结构：

```python
class MLP(nn.Module):
    def __init__(self, use_bn=True, use_dropout=True, init='kaiming'):
        super().__init__()
        self.fc1 = nn.Linear(784, 256)
        self.bn1 = nn.BatchNorm1d(256) if use_bn else nn.Identity()
        self.fc2 = nn.Linear(256, 128)
        self.bn2 = nn.BatchNorm1d(128) if use_bn else nn.Identity()
        self.drop = nn.Dropout(0.3) if use_dropout else nn.Identity()
        self.fc3 = nn.Linear(128, 10)

        self._init_weights(init)

    def _init_weights(self, mode):
        for m in self.modules():
            if isinstance(m, nn.Linear):
                if mode == 'kaiming':
                    nn.init.kaiming_normal_(m.weight, nonlinearity='relu')
                elif mode == 'xavier':
                    nn.init.xavier_normal_(m.weight)
                elif mode == 'zeros':
                    nn.init.zeros_(m.weight)      # 故意错误的初始化，做对照
                nn.init.zeros_(m.bias)

    def forward(self, x):
        x = x.view(x.size(0), -1)
        x = self.drop(F.relu(self.bn1(self.fc1(x))))
        x = self.drop(F.relu(self.bn2(self.fc2(x))))
        return self.fc3(x)
```

### 训练与评估脚本

```python
def train_epoch(model, loader, optimizer, clip_norm=None):
    model.train()
    total, correct, loss_sum = 0, 0, 0.0
    for X, y in loader:
        X, y = X.to(device), y.to(device)
        logits = model(X)
        loss = F.cross_entropy(logits, y)
        optimizer.zero_grad()
        loss.backward()
        if clip_norm is not None:
            torch.nn.utils.clip_grad_norm_(model.parameters(), clip_norm)
        optimizer.step()
        loss_sum += loss.item() * len(y)
        correct += (logits.argmax(1) == y).sum().item()
        total += len(y)
    return loss_sum / total, correct / total

@torch.no_grad()
def evaluate(model, loader):
    model.eval()    # BN 用 running stats，Dropout 关闭
    total, correct, loss_sum = 0, 0, 0.0
    for X, y in loader:
        X, y = X.to(device), y.to(device)
        logits = model(X)
        loss = F.cross_entropy(logits, y)
        loss_sum += loss.item() * len(y)
        correct += (logits.argmax(1) == y).sum().item()
        total += len(y)
    return loss_sum / total, correct / total

def run_experiment(name, model, epochs=15, lr=1e-3, weight_decay=0.0, clip=None):
    model = model.to(device)
    opt = torch.optim.AdamW(model.parameters(), lr=lr, weight_decay=weight_decay)
    hist = {'train_acc': [], 'val_loss': [], 'val_acc': []}
    for ep in range(epochs):
        _, tr_acc = train_epoch(model, train_loader, opt, clip_norm=clip)
        vl, va = evaluate(model, val_loader)
        hist['train_acc'].append(tr_acc)
        hist['val_loss'].append(vl)
        hist['val_acc'].append(va)
        if (ep + 1) % 5 == 0:
            print(f'[{name}] ep{ep+1:2d}  val_loss={vl:.4f}  val_acc={va:.2%}')
    return hist
```

### 消融组

同一份数据、同一个训练循环，每次只动一个变量：

```python
exps = {
    'baseline (BN+Dropout+He)':       MLP(use_bn=True,  use_dropout=True,  init='kaiming'),
    'no BatchNorm':                   MLP(use_bn=False, use_dropout=True,  init='kaiming'),
    'no Dropout':                     MLP(use_bn=True,  use_dropout=False, init='kaiming'),
    'zeros init (bad)':               MLP(use_bn=True,  use_dropout=True,  init='zeros'),
    'xavier init':                    MLP(use_bn=True,  use_dropout=True,  init='xavier'),
}

results = {}
for name, model in exps.items():
    results[name] = run_experiment(name, model, epochs=15, lr=1e-3)
```

跑完把验证准确率画在一起：

```python
plt.figure(figsize=(8, 4.5))
for name, h in results.items():
    plt.plot(h['val_acc'], label=name, linewidth=1.8)
plt.xlabel('epoch'); plt.ylabel('val accuracy')
plt.title('Fashion-MNIST 消融实验')
plt.legend(loc='lower right')
plt.tight_layout()
plt.show()

print(f'{"配置":30s}  {"最终 val_acc":>10s}')
for name, h in results.items():
    print(f'{name:30s}  {h["val_acc"][-1]:>10.2%}')
```

典型的相对关系大致如下（绝对数字随随机种子浮动，相对排序很稳定）：

| 配置 | 验证准确率（约） | 解读 |
|------|------------------|------|
| baseline（BN+Dropout+He） | ~91% | 全家桶，参照系 |
| 关掉 BatchNorm | 掉 1~3 个点 | 归一化对 3 层 MLP 也有肉眼可见的贡献 |
| 关掉 Dropout | 基本持平或微降 | Fashion-MNIST 数据够、模型不大，过拟合本来就轻 |
| zeros 初始化 | ~10%（瞎猜水平） | 对称性没打破，所有神经元等价，等于白训 |
| Xavier 初始化 | ~90% | 和 He 差距不大，ReLU 网络里 He 略占优 |

两个实验细节值得亲手试一遍。第一，把 `zeros init` 那组的训练准确率打出来，会发现它停在 10% 一动不动——这就是对称性问题最直观的展示。第二，把 MLP 加深到 8 层（同样宽度），会看到不用 BN 时训练明显变慢、浅层权重几乎不动，这就是梯度消失在真实网络里的样子。

### 梯度裁剪演示

再补一个小实验：故意用大学习率（比如 lr=5e-2）训练，观察 loss spike，再开梯度裁剪看它是否被压住：

```python
hist_noclip = run_experiment('lr=5e-2 no clip',  MLP(), epochs=10, lr=5e-2, clip=None)
hist_clip   = run_experiment('lr=5e-2 clip=1.0', MLP(), epochs=10, lr=5e-2, clip=1.0)

plt.figure(figsize=(7, 4))
plt.plot(hist_noclip['val_loss'], label='no clip', linewidth=1.8)
plt.plot(hist_clip['val_loss'],   label='clip=1.0', linewidth=1.8)
plt.xlabel('epoch'); plt.ylabel('val loss')
plt.title('梯度裁剪对 loss spike 的抑制')
plt.legend(); plt.show()
```

不开裁剪时验证损失曲线偶尔会突然窜起一个尖峰（对应某一步梯度爆炸），开裁剪后曲线明显平滑。这个技巧在后面 Transformer、RNN 的实验里会持续出场。

## 小结

这一章的每个技巧都在回答一个具体的训练失败模式：初始化不对称 → 对称性无法打破 → He/Xavier；深层梯度衰减 → 梯度消失 → ReLU + 归一化 + 残差；损失偶发尖峰 → 梯度爆炸 → 梯度裁剪；验证误差回升 → 过拟合 → Dropout / 权重衰减 / 数据增强 / 早停；训练不稳 → 内部协变量漂移 → BatchNorm / LayerNorm。

消融实验的方法论也顺带立住了：**一次只改一个变量，其他全部固定**。这个习惯往后读论文、调自己的模型都用得上——没有消融的"涨点"都是不可信的。

到这里，通用训练方法论算是齐了。下一章进入专化结构：卷积神经网络——为什么图像任务不能用 MLP 硬堆，卷积和池化到底在归纳偏好里注入了什么先验。
