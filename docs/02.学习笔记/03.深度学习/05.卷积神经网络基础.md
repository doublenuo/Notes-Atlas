# 卷积神经网络基础

前面的网络都是全连接的：每个输出神经元看遍所有输入。处理 32×32 的小图还行，换成 224×224 的彩色图，第一层就要 $224\times224\times3 \approx 15$ 万个参数，纯属浪费——判断一个像素是边缘还是纹理，根本不需要知道图片另一头长什么样。卷积神经网络（CNN）的核心就是把这个先验写进结构里：**局部连接、参数共享**。这一章从卷积的定义讲起，把步幅、填充、池化、感受野这些构件拆开，然后过一遍 LeNet → AlexNet → VGG 这条经典演化线，实验部分在 CIFAR-10 上把 CNN 和 MLP 拉出来对比。

## 卷积层

### 从全连接到卷积

把图像看成二维（或多通道三维）的网格，全连接层相当于给每个输出神经元配一张和输入一样大的权重表——权重和位置绑定，换个位置就得重新学。图像的统计性质恰恰相反：边缘、角点这些特征在**任何位置**都长得一样，左上角有用的卷积核，右下角同样有用。

卷积层把这个直觉变成结构。一个卷积核（kernel/filter，也叫权重）尺寸通常很小（3×3、5×5），在输入上滑动，每个位置做元素相乘再求和：

$$
(\mathbf{x} * \mathbf{w})_{i,j} = \sum_{u}\sum_{v} x_{i+u,\, j+v}\, w_{u,v} + b
$$

同一个核从头滑到尾，**所有位置共享同一组权重**。3×3 的核只有 9 个参数（单通道时），却能检测整张图上任意位置的同类特征——这就是参数共享的红利。

```mermaid
flowchart LR
    subgraph 输入 5×5
        I["x"]
    end
    subgraph 卷积核 3×3
        K["w"]
    end
    I --> M["逐位置加权求和"]
    K --> M
    M --> O["输出 3×3 特征图"]
```

两个结构性质随之而来。**局部连接**：输出的每个值只依赖输入的一小块邻域（核覆盖的范围），梯度和计算都局限在局部。**平移等变性**（equivariance）：输入平移，输出特征图跟着平移同样的量——猫挪到图片右边，检测"猫耳朵"的响应也挪到右边，而且用的是同一套权重。严格说卷积本身是等变的，分类所需的**平移不变性**（equivariance→invariance）要靠后面的池化或全局平均池化来补，这个区别面试偶尔会追问。

### 多通道输入与输出

真实图像有通道（RGB 三通道），卷积核也不再是一个 2D 矩阵，而是一组和输入通道数相同的核——每个输入通道配一个核，各自卷积后把结果**加在一起**，再加偏置：

$$
y_{i,j}^{(k')} = \sum_{c=1}^{C_{\text{in}}} \sum_{u,v} x^{(c)}_{i+u,j+v}\, w^{(k',\,c)}_{u,v} + b^{(k')}
$$

一个完整的卷积核张量形状是 $(C_{\text{out}},\, C_{\text{in}},\, k, k)$：$C_{\text{out}}$ 个输出通道（每个输出通道 = 一种特征的响应图），每个覆盖全部输入通道。$3\times3$ 卷积、输入 64 通道、输出 128 通道，参数量是 $64\times128\times3\times3 \approx 74$K——和全连接比仍然很小，但表达力已经足够组装任意深度的网络。

PyTorch 对应接口：

```python
import torch.nn as nn

# in_ch, out_ch, kernel, stride, padding
conv = nn.Conv2d(3, 64, kernel_size=3, stride=1, padding=1)
y = conv(x)        # (N,3,32,32) → (N,64,32,32)
```

顺带一提 **1×1 卷积**：核尺寸 1×1，不看邻域，只在通道维做线性组合。作用是跨通道融合 + 升降维，Inception 和 ResNet 的 bottleneck 都靠它省算力，第 6 章会见到。

### 步幅与填充

卷积核默认一次挪一格（stride=1），输出尺寸和输入差不多。两个旋钮可以调：**步幅**（stride）每次滑动的格数，**填充**（padding）在输入四周补零的圈数。

输出尺寸的通式：

$$
H_{\text{out}} = \left\lfloor \frac{H_{\text{in}} + 2p - k}{s} \right\rfloor + 1
$$

$k$ 是核尺寸，$p$ 是填充，$s$ 是步幅。两个常用配置：

- **"same" 填充**：输出和输入同尺寸，取 $p = \lfloor k/2 \rfloor$（3×3 核填 1）。步幅 1 时保持分辨率，深度网络的默认选择；
- **"valid" 填配**：$p=0$，不填充。每过一层尺寸收缩，边缘像素参与计算的次数比中间少；
- **步幅 > 1**：直接下采样，$s=2$ 时输出边长减半——这是除池化之外另一种压缩空间分辨率的手段，现代网络（ResNet 下采样、ViT 的 patch embedding）越来越多用 stride-2 卷积代替池化。

```python
conv_s2 = nn.Conv2d(64, 128, kernel_size=3, stride=2, padding=1)
# (N,64,32,32) → (N,128,16,16)，步幅 2 直接折半

# 验证公式：H_out = floor((32 + 2*1 - 3)/2) + 1 = 16
```

填充还有个隐性作用：不填充的话，四角像素只被卷过一两次，边界信息利用不充分；补零让所有像素被"公平"访问。当然零本身没意义，填充太大（比如 5×5 核填 4 圈）会引入大量虚假边缘，一般 $p \le k/2$。

### 池化

池化（pooling）做的是下采样：把特征图划成小块，每块取一个代表值。最常用的是**最大池化**（取块内最大值），其次是平均池化：

```python
pool = nn.MaxPool2d(kernel_size=2, stride=2)   # 2×2 块、不重叠，边长减半
y = pool(x)        # (N,64,32,32) → (N,64,16,16)
```

池化没有可学习参数，它带来的好处有三层：

1. **降维**：特征图边长减半，后续计算量和参数量都降；
2. **扩大感受野**：下一层的核能"看到"原图更大的区域（和感受野一节呼应）；
3. **近似平移不变性**：特征在 2×2 邻域内挪动，最大池化的输出不变——分类头因此对小位移更鲁棒。

代价是空间精度的丢失：池化之后，"特征在哪"的信息变粗了。所以语义分割、目标检测这类需要精确定位的任务，往往少用池化、多用步幅卷积甚至完全不下采样（FCN 思路）。

另一个现代细节：AlexNet/VGG 时代"卷积×3 + 池化"是标准节奏，ResNet 之后**步幅卷积替代池化**成了主流，ViT 干脆用 patch embedding（一个 stride 等于核大小的大步幅卷积）一步到位。池化没有被抛弃，但不再是必选项。

### 感受野

**感受野**（receptive field）指输出特征图上一个像素"能看到"的输入区域大小。它决定了这一层能利用多大范围的上下文——判断"这是一只鸟"需要看到整个鸟，判断"这是羽毛"只需要一小块。

单层卷积的感受野就是核大小 $k$。往上堆叠时逐层扩大。纯卷积（步幅 1）每层加 $k-1$：

$$
r_{l} = r_{l-1} + (k-1)
$$

有步幅 $s$ 和池化时，用递推 $r_l = r_{l-1} + (k_l - 1)\,j_{l-1}$，其中 $j_l = j_{l-1}\cdot s_l$ 是累计跳步（jump，输出一格对应输入几格）。

手算一个 VGG 风格的例子：三个 3×3 池化层（stride 2），第三个池化层输出上的一个像素，感受野是 21×21（可以按公式自己推一遍）。直觉核：**分辨率每减半一次，感受野大致翻倍**。想让深层一个点"看到"整张 224×224 的图，靠 3×3 的核硬堆要很多层，这就是为什么网络必须"边变深、边下采样"——深度提供感受野增长的层数，下采样提供每层的增长步长。

有个常见的量级关系值得记：堆 $n$ 个 3×3 卷积（无池化）的感受野等效于一个 $(2n+1)\times(2n+1)$ 的大核，但参数量只有 $n\times3^2$ 对比 $(2n+1)^2$——两个 3×3 叠起来等效 5×5，参数 18 vs 25。VGG 满篇 3×3 的原因就在这：**更深、更小的核，感受野相同、参数更少、非线性更多**。

## 经典架构

### LeNet-5（1998）

LeCun 在邮政支票识别系统里部署的网络，卷积网络第一次真正落地。结构（数字识别，输入 32×32 灰度图）：

```
Conv(6,5×5) → Pool(2) → Conv(16,5×5) → Pool(2) → FC(120) → FC(84) → Softmax(10)
```

用今天的标准看它很小（总参数约 6 万），但现代 CNN 的全部零件已经齐了：卷积、池化、可学习层的交替、最后接全连接分类头。Sigmoid 激活 + 每层算出来的均值方差做归一化（当年的"手动 BN"）是时代印记。

### AlexNet（2012）

ImageNet 挑战赛的分水岭，top-5 错误率 15.3% 把第二名的传统方法甩开 10 个百分点，直接开启了深度学习时代（第 1 章讲过这段历史）。结构要点：

```
Conv(96,11×11,s4) → MaxPool → Conv(256,5×5) → MaxPool
→ Conv(384,3×3) → Conv(384,3×3) → Conv(256,3×3) → MaxPool
→ FC(4096) → FC(4096) → FC(1000)
```

历史贡献比结构本身更重要：

- **ReLU** 顶替 Sigmoid，训练速度质变；
- **Dropout（p=0.5）** 对抗 FC 层的过拟合；
- **LRN**（局部响应归一化）想模仿生物侧抑制——后来被证明不如 BN，淡出了历史；
- **双 GPU 训练**：网络切成两半在两块 GTX 580 上并行，数据并行的早期工程实践；
- **数据增强**：随机裁剪、水平翻转，ImageNet 上泛化的关键。

AlexNet 还是"卷积负责提特征、大 FC 负责分类"的旧范式，最后三个 4096 的全连接层占了全网络 90% 以上的参数——这个头重脚轻的毛病，VGG 之后开始被修正，到 ResNet 用全局平均池化彻底拔掉。

### VGG（2014）

VGG 的想法一句话：**全部用 3×3，靠深度取胜**。论文里从 11 层（VGG-11）试到 19 层（VGG-19），最常用的是 VGG-16（13 层卷积 + 3 层全连接）：

```
[64 conv×2] → pool → [128 conv×2] → pool
→ [256 conv×3] → pool → [512 conv×3] → pool
→ [512 conv×3] → pool → FC×3 → softmax
```

配置的几何规律很规整：每次池化分辨率减半，通道数翻倍——分辨率和通道数的这个 2:1 交换律，成了后来几乎所有 CNN 的默认节奏。

三个设计结论：

1. **堆小核**：三个 3×3 等效 7×7 感受野，参数 $3\times27=81$ vs 49（单通道口径），还多了两层非线性；
2. **深度即性能**：16 层明显好于 11 层，当时人们以为继续堆还能涨——直到发现 56 层反而更差，才引出第 6 章的主角 ResNet；
3. **依然头重脚轻**：VGG-16 的三个 FC 层参数约 1.3 亿，占全网络 80%+，卷积部分其实只有 1470 万参数。

VGG 的特征提取器（砍掉 FC、留下 conv 块）至今仍在无数检测、分割、风格迁移论文里当 backbone 用，代价是显存和参数——同样输入下它比 ResNet-50 贵得多，新项目直接训 VGG 的已经很少了。

### 三代对比

| | LeNet-5 (1998) | AlexNet (2012) | VGG-16 (2014) |
|---|---|---|---|
| 深度（卷积层） | 2 | 5 | 13 |
| 核尺寸 | 5×5 | 11×11 / 5×5 / 3×3 | 全部 3×3 |
| 激活 | Sigmoid | ReLU | ReLU |
| 归一化 | 手动均值方差 | LRN | 无（BN 是后话） |
| 正则 | — | Dropout | Dropout |
| 参数量 | ~6 万 | ~6000 万 | ~1.38 亿 |
| 输入 | 32×32 灰度 | 227×227 RGB | 224×224 RGB |

这条线的演化逻辑很清楚：先是"能不能训起来"（LeNet→AlexNet 靠 ReLU/Dropout/硬件），再是"怎么堆得更深"（VGG 靠小核堆深度）。堆到 56 层反而退化时，问题就变成了下一章的 ResNet。

## 实验：CIFAR-10 图像分类

CIFAR-10：10 类彩色小图（飞机/汽车/鸟/猫/鹿/狗/蛙/马/船/卡车），32×32×3，5 万训练 + 1 万测试。这一节先训一个 CNN，再和同参数量级的 MLP 对比，直观验证"卷积的归纳偏置"值多少分。

### 数据加载

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
from torch.utils.data import DataLoader
from torchvision import datasets, transforms
import matplotlib.pyplot as plt

device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
torch.manual_seed(42)

mean, std = (0.4914, 0.4822, 0.4465), (0.2470, 0.2435, 0.2616)
train_tf = transforms.Compose([
    transforms.RandomCrop(32, padding=4),      # 数据增强，上一章讲的
    transforms.RandomHorizontalFlip(),
    transforms.ToTensor(),
    transforms.Normalize(mean, std),
])
test_tf = transforms.Compose([
    transforms.ToTensor(),
    transforms.Normalize(mean, std),
])

train_ds = datasets.CIFAR10('./data', train=True, download=True, transform=train_tf)
test_ds  = datasets.CIFAR10('./data', train=False, transform=test_tf)
train_loader = DataLoader(train_ds, batch_size=128, shuffle=True,  num_workers=2)
test_loader  = DataLoader(test_ds,  batch_size=256, shuffle=False, num_workers=2)

classes = ('plane','car','bird','cat','deer','dog','frog','horse','ship','truck')
```

顺手看看数据长什么样：

### 模型定义

一个 VGG 风格的小 CNN（3 个 conv 块 + 全局平均池化 + 两层 FC），和一个参数量可比的 MLP：

```python
class SmallCNN(nn.Module):
    def __init__(self, num_classes=10):
        super().__init__()
        self.features = nn.Sequential(
            # block1: 32x32 → 16x16
            nn.Conv2d(3, 64, 3, padding=1), nn.BatchNorm2d(64), nn.ReLU(inplace=True),
            nn.Conv2d(64, 64, 3, padding=1), nn.BatchNorm2d(64), nn.ReLU(inplace=True),
            nn.MaxPool2d(2),
            # block2: 16x16 → 8x8
            nn.Conv2d(64, 128, 3, padding=1), nn.BatchNorm2d(128), nn.ReLU(inplace=True),
            nn.Conv2d(128, 128, 3, padding=1), nn.BatchNorm2d(128), nn.ReLU(inplace=True),
            nn.MaxPool2d(2),
            # block3: 8x8 → 4x4
            nn.Conv2d(128, 256, 3, padding=1), nn.BatchNorm2d(256), nn.ReLU(inplace=True),
            nn.Conv2d(256, 256, 3, padding=1), nn.BatchNorm2d(256), nn.ReLU(inplace=True),
            nn.MaxPool2d(2),
        )
        self.classifier = nn.Sequential(
            nn.Dropout(0.5),
            nn.Linear(256, 256), nn.ReLU(inplace=True),
            nn.Dropout(0.5),
            nn.Linear(256, num_classes),
        )

    def forward(self, x):
        f = self.features(x)
        f = f.mean(dim=(2, 3))          # 全局平均池化，替代 VGG 的大 FC
        return self.classifier(f)

class MLP(nn.Module):
    """对照组：同为约 170 万参数，但没有局部连接和参数共享"""
    def __init__(self, num_classes=10):
        super().__init__()
        self.net = nn.Sequential(
            nn.Flatten(),
            nn.Linear(3072, 2048), nn.ReLU(inplace=True), nn.Dropout(0.3),
            nn.Linear(2048, 1024), nn.ReLU(inplace=True), nn.Dropout(0.3),
            nn.Linear(1024, num_classes),
        )

    def forward(self, x):
        return self.net(x)

cnn = SmallCNN().to(device)
mlp = MLP().to(device)
print(f'CNN params: {sum(p.numel() for p in cnn.parameters()):,}')
print(f'MLP params: {sum(p.numel() for p in mlp.parameters()):,}')
```

参数量都在 170 万上下，公平对比。MLP 虽然层宽不小，但完全不利用空间结构——每个像素和分类的权重独立，这正是要验证的变量。

### 训练与评估

```python
def train_model(model, name, epochs=20, lr=1e-3, weight_decay=5e-4):
    opt = torch.optim.AdamW(model.parameters(), lr=lr, weight_decay=weight_decay)
    sched = torch.optim.lr_scheduler.CosineAnnealingLR(opt, T_max=epochs)  # 上一章的 cosine
    hist = {'train_acc': [], 'test_acc': []}

    for ep in range(epochs):
        model.train()
        correct, total = 0, 0
        for X, y in train_loader:
            X, y = X.to(device), y.to(device)
            loss = F.cross_entropy(model(X), y)
            opt.zero_grad(); loss.backward(); opt.step()
            correct += (model(X).argmax(1) == y).sum().item()
            total += len(y)
        sched.step()

        model.eval()
        t_correct, t_total = 0, 0
        with torch.no_grad():
            for X, y in test_loader:
                X, y = X.to(device), y.to(device)
                t_correct += (model(X).argmax(1) == y).sum().item()
                t_total += len(y)
        hist['train_acc'].append(correct / total)
        hist['test_acc'].append(t_correct / t_total)
        print(f'[{name}] ep{ep+1:2d}  train={correct/total:.2%}  test={t_correct/t_total:.2%}')
    return hist

hist_cnn = train_model(SmallCNN().to(device), 'CNN', epochs=20)
hist_mlp = train_model(MLP().to(device),      'MLP', epochs=20)
```

### 结果对比

20 个 epoch 之后典型的曲线关系（绝对值随种子、增略有波动）：

```python
plt.figure(figsize=(8, 4.5))
plt.plot(hist_cnn['test_acc'], label='CNN (VGG-style)', linewidth=2)
plt.plot(hist_mlp['test_acc'], label='MLP', linewidth=2, linestyle='--')
plt.xlabel('epoch'); plt.ylabel('test accuracy')
plt.title('CIFAR-10: CNN vs MLP')
plt.legend(); plt.grid(alpha=0.3)
plt.tight_layout(); plt.show()

print(f'CNN test acc: {hist_cnn["test_acc"][-1]:.2%}')
print(f'MLP test acc: {hist_mlp["test_acc"][-1]:.2%}')
```

| 模型 | 参数量 | 测试准确率（约） |
|------|--------|------------------|
| MLP（2048-1024） | ~170 万 | 53% ~ 57% |
| SmallCNN（VGG-style） | ~170 万 | 76% ~ 79% |

**同样参数量，CNN 比 MLP 高出 20 多个点**，这就是局部连接 + 参数共享 + 平移等变这套归纳偏置的直接价值。MLP 把算力浪费在学习"平移不变"这件事上，CNN 从结构上就免费拥有了它。

还可以顺手做两个加深理解的小实验：

- **感受野验证**：把 `SmallCNN` 的池化全删掉、只堆 3×3 卷积，准确率会明显掉——分辨率降太快、深层看不到全局上下文；反过来全用池化不下采样，计算量爆掉也没必要，"深+下采样"的平衡就是架构设计本身；
- **数据增强消融**：注释掉 `RandomCrop` 和 `RandomHorizontalFlip`，测试准确率通常掉 2~4 个点——上一章的数据增强结论在真数据上再次成立。

### 参数量的来源

打印一下各层参数分布会发现，尽管我们用全局平均池化砍掉了 VGG 式的大 FC，分类头之外的卷积部分仍占大头：

```python
for name, p in cnn.named_parameters():
    if p.ndim >= 2 and 'weight' in name:
        print(f'{name:35s} {tuple(p.shape)}  {p.numel():>9,}')
```

block 越深通道越宽，参数涨得越快（64→128→256）。第 6 章会看到 ResNet 怎么用 1×1 bottleneck 把这笔账再压一压，以及为什么现代网络宁可加深也不加宽——不过在继续往下之前，把这一章的公式自己手推一遍：输出尺寸、感受野递推、3×3 vs 7×7 参数对比，这三样是 CNN 里最常用的心算。

## 小结

卷积层用两个先验换取效率：**局部连接**（只看邻域）和**参数共享**（同一核扫全图），附赠平移等变；步幅和填充控制输出尺寸，公式一个就够；池化下采样、扩感受野、添不变性；感受野随深度和下采样增长，"深 + 下采样"是 CNN 架构的主旋律。

LeNet 证明了卷积能落地，AlexNet 证明了深+大+GPU 能碾压传统方法，VGG 证明了堆 3×3 能一路涨——直到堆不动为止。VGG 堆到 56 层训练误差反而高于 16 层的退化现象（degradation），以及怎么用残差连接解掉它，是下一章现代 CNN 架构的开场。
