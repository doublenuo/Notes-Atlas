# Actor-Critic框架

有了基线之后，策略梯度方法就自然演化成了 Actor-Critic 框架。Actor 是策略网络，负责选动作；Critic 是价值网络，负责估计$V^{\pi}(s)$并给 Actor 提供优势信号，Actor 根据优势调整动作概率，Critic 根据实际回报调整价值估计。

这个框架的具体形式取决于几个设计选择。优势估计用一步 TD 误差，还是多步回报，还是 GAE？策略更新用原始策略梯度，还是加裁剪，还是加熵正则化？这些选择的不同组合，就产生了 A2C、A3C、TRPO、PPO、SAC 等一系列算法。它们的共同骨架都是 Actor-Critic，区别只在于细节。

## 优势函数估计

回顾一下，在 REINFORCE 算法中，目标函数的梯度中有一项轨迹回报，用于指导策略的更新。REINFOCE 算法用蒙特卡洛方法来估计$Q(s,a)$，能不能考虑拟合一个值函数来指导策略进行学习呢？这正是 Actor-Critic 算法所做的。

优势函数的标准定义是$A_t=Q^{\pi}(s,a)-V^{\pi}(s)$，它衡量的是在状态$s$下选动作$a$，比遵循策略$\pi$的平均水平好多少，要用它，你需要同时估计$Q$和$V$，或者用$G_t$来代替$Q$，不同的估计方式，构成了不同的算法。

### 单步TD误差

动作价值函数$Q$的定义是：

$$Q^\pi(s,a)=\mathbb{E}\left[R_{t+1}+\gamma V^\pi(S_{t+1})\mid S_t=s,A_t=a\right]$$

这个期望的含义在状态$s$做了动作$a$之后，拿到的即时奖励加上下一状态的价值。如果只取一次采样，就得到$Q$的一步估计：

$$Q(s,a)\approx r+\gamma V(s^{\prime})$$

其中$r$是这一步实际拿到的奖励，$s^{\prime}$这一步实际到达的下一状态，把这个代入优势函数定义：

$$\hat{A}_t=Q(s,a)-V(s)\approx r+\gamma V(s^{\prime})-V(s)$$

这右边的部分就是TD误差：

$$\delta = r+\gamma V(s^{\prime})-V(s)$$

用TD误差作为策略梯度的信号有两个显著的好处：
- **不需要等 episode 结束**：每走一步就能更新；
- **显著降低方差**：$\delta$只涉及到一步的随机性。

但是它只用了一步真实奖励，剩下的全靠 Critic 的估计，如果 Critic 估计不准，优势就是错的，也就是它的特点是**偏差大，方差小**。

### 多步回报

如果把动作价值函数进行多步展开，就得到了多步回报进行优势函数的估计：

$$\hat{A}_t=r_{t+1}+\gamma r_{t+2}+\cdots+\gamma^{n-1}r_{t+n}+\gamma^nV(s_{t+n})-V(s_t)$$

它用了$N$步真实奖励，信息更充分，但累积的随机性也更多，因此它的特点是**偏差小，方差大**。

### 蒙特卡洛回报

如果继续把多步回报展开到无穷步，也就是一直走到回合结束，中间不再用 Critic 的估计来截断，那就得到了蒙特卡洛回报：

$$\hat{A}_t=r_{t+1}+\gamma r_{t+2}+\gamma^2r_{t+3}+\cdots+\gamma^{T-t-1}r_T-V(s_t)=G_t-V(s_t)$$

这里的$G_t$是从时刻$t$到回合结束的真实累积回报，$V(s)$是 Critic 对当前状态价值的估计。

这个优势估计是**无偏的**，因为它用的是真实的奖励序列，没有引入任何对未来的猜测。但它也是方差最大的，因为整条轨迹上所有的随机性,动作采样、环境转移、奖励噪声全部被累加进了$G_t$。


### 广义优势估计

把以上三种估计放在一起看，会发现它们排列在一条清晰的光谱上。

| 估计方式 | 用了多少真实奖励 | 偏差 | 方差 |
|:---:|:---:|:---:|:---:|
| 一步 TD 误差 | 1 步 | 大 | 小 |
| n 步回报 | n 步 | 中 | 中 |
| 蒙特卡洛回报 | 全部 | 小 | 大 |

这张表揭示了一个根本性的权衡：**你用的真实奖励越多，估计越准，但累积的随机性也越多；你越依赖 Critic 的估计，方差越小，但 Critic 一旦估错，偏差就直接传导进来**。

广义优势估计（Generalized Advantage Estimation，GAE）就是对这个问题的回答。它的核心思想是**不选一个$n$，而是把从 1 步到无穷步的所有回报做指数加权平均，用一个参数$\lambda$控制权重衰减的速度。**

$$\hat{A}_t^{\mathrm{GAE}(\gamma,\lambda)}=\sum_{l=0}^\infty(\gamma\lambda)^l\delta_{t+l}=\delta_t+\gamma\lambda\delta_{t+1}+(\gamma\lambda)^2\delta_{t+2}+\cdots$$

其中$\delta_t=r_{t+1}+\gamma V(s_{t+1})-V(s_t)$就是前面的一步 TD 误差，也就是说，GAE 是**所有未来 TD 误差的指数加权和**。
- $\lambda=0$时：GAE退化为单步TD误差，偏差大、方差小；
- $\lambda=1$时：GAE 退化为带基线的蒙特卡洛回报，偏差小、方差大。

实践中通常取$\lambda=0.95$，在偏差和方差之间找到一个经验上最优的平衡点。

GAE 还有一个等价形式，更直观地展示它的结构，把$\delta_{t+l}$展开并重新整理可以得到：

$$\hat{A}_t^{\mathrm{GAE}(\gamma,\lambda)}=\sum_{l=0}^\infty(\gamma\lambda)^lr_{t+l+1}+\gamma\lambda V(s_{t+1})-V(s_t)+\cdots$$

这个形式把 GAE 理解成对所有未来奖励做指数加权平均，再减去一个经过修正的基线，这避免了$n$取多少这个生硬的超参数选择，换成了一个连续的、更柔和的衰减参数$\lambda$.

GAE 的另一个优点是可以**反向递归计算**，从轨迹末端往前算，每一步只需要用到下一步的 TD 误差：

$$\hat{A}_t=\delta_t+\gamma\lambda\hat{A}_{t+1}$$

这个递归形式在代码里非常容易实现：

```python
def compute_gae(rewards, values, dones, gamma=0.99, lam=0.95):
    advantages = []
    gae = 0
    values = values + [0]  # 最后一步的下一状态价值为 0
    for t in reversed(range(len(rewards))):
        delta = rewards[t] + gamma * values[t + 1] * (1 - dones[t]) - values[t]
        gae = delta + gamma * lam * (1 - dones[t]) * gae
        advantages.insert(0, gae)
    return advantages
```

从后往前遍历，每一步的 GAE 等于当前 TD 误差加上折扣后的下一步 GAE，这样一次遍历就能算出整条轨迹所有时刻的优势，计算效率很高。

## Actor-Critic框架

Actor-Critic 方法的核心思想是**利用 Critic 网络来评估当前策略的好坏，然后 Actor 网络根据 Critic 的评估结果来更新策略**。它是一种结合了策略梯度方法和时序差分学习的方法。
- **Actor**：Actor 是一个策略网络$\pi_{\theta}(a|s)$，它接收当前状态
$s$作为输入，输出一个动作$a$的概率分布，Actor 的目标是学习一个好的策略，使得智能体可以获得尽可能高的回报；
- **Critic**：Critic 是一个值函数网络$Q_{\varphi}(s)$，它接收当前状态$s$作为输入，输出一个对当前状态的评估值，Critic 的目标是准确地评估当前策略的好坏。

### Actor策略梯度估计

在策略梯度中，可以把梯度写成下面这个更加一般的形式：

$$\nabla J(\theta)=\mathbb{E}\left[\sum_{t=0}^\infty\Psi_t\nabla\log\pi_\theta(a_t|s_t)\right]$$

其中$\Psi_t$是一个通用的系数，不同的选择方式会产生不同的策略梯度更新算法，并且它们的性质也会有所不同。

- **蒙特卡洛回报**：当$\Psi_t=G_t=\sum_{k=0}^{\infty}\gamma^kr_{t+k+1}$时，这就是蒙特卡洛回报。此时的梯度更新是无偏的，但是方差较大；
- **带有基线的蒙特卡洛回报**：当$\Psi_t=G_t-V^{\pi}(s_t)$时，这是带有基线的蒙特卡洛回报。通过减去基线，降低了梯度估计的方差；
- **优势函数**：当$\Psi_t=A^\pi(s_t,a_t)=Q^{\pi}(s_t,a_t)-V^{\pi}(s_t)$时，这是前面讨论的优势函数，它也是一种降低方差的手段;
- **Q函数**：当$\Psi_t=Q^\pi(s_t,a_t)$时，这是 Q 函数,使用 Q 函数能够得到比优势函数更准确的更新方向，但方差较大；
- **TD误差**：当$\Psi_t=r_{t+1}+\gamma V^\pi(s_{t+1})-V^\pi(s_t)$时，这是一种单步时序差分算法，偏差较高，但方差较低。

### Critic网络实现

要计算TD误差$\delta=r+\lambda V(s^\prime)-V(s)$，你需要知道$V(s)$和$V(s^\prime)$，但是在实际问题中$V$是未知的，因此需要一个Critic网络来估计它。

Critic 网络通常用$V_{\phi}(s)$来表示，参数是$\phi$，输入状态$s$，输出一个标量价值估计，它的训练目标就是让这个估计越来越准，也就是让预测值逼近时序差分给出的更新目标。

$$\mathcal{L}(\phi)=\mathbb{E}\left[\left(r_{t+1}+\gamma V_\phi(s_{t+1})-V_\phi(s_t)\right)^2\right]$$

Critic 是在用自己的一部分估计去更新另一部分估计，这种自举是时序差分学习的本质特征，为了让训练稳定，通常会用目标网络来计算下一步的价值，或者把状态$s_{t+1}$的价值估计做`detach`处理，防止梯度回传到目标上。

### Actor-Critic 完整流程

把优势函数和 Critic 训练整合起来，就得到了强化学习中最经典的架构。Actor 负责选择动作，Critic 负责评估动作的好坏，两者通过优势函数$A(s,a)$协作。

把 Actor 和 Critic 放在一起，一次完整的训练循环是这样的：
1. 用当前 Actor 策略在环境中交互，收集一批轨迹$\tau=(s_0,a_0,r_1,s_1,a_1,r_2,\cdots)$；
2. 用 Critic 计算每个状态的$V_{\phi}(s_t)$和$V_{\phi}(s_{t+1})$;
3. 计算每一个时刻的TD误差$\delta_t=r_t+\gamma V_{\phi}(s_{t+1})-V_{\phi}(s_t)$;
4. 计算 Critic 损失$\mathcal{L}(\phi)=\sum_t\left(r_{t+1}+\gamma V_\phi(s_{t+1})-V_\phi(s_t)\right)^2$，使用梯度下降更新$\phi$;
5. 计算 Actor 损失$\mathcal{L}(\theta)=-\sum_t\log\pi_\theta(a_t|s_t)\cdot\hat{A}_t$，更新$\theta$
6. 重复以上过程。

### A2C算法

A2C，全称 Advantage Actor-Critic，是 Actor-Critic 框架最直接的实现。它做的事情很简单，**用多个环境并行采样，用优势函数作为策略梯度的权重，同步更新 Actor 和 Critic**。

为什么要并行采样？因为 Actor-Critic 是 on-policy 算法，每更新一次策略，之前的数据就作废了，必须重新采样。如果只用一个环境，采样速度会非常慢，GPU 大部分时间都在等环境返回数据。A2C 的做法是同时开 N 个环境，比如 16 个或 32 个，每个环境各自跑一段轨迹，然后把数据汇总在一起，算一次梯度，更新一次参数。这样 GPU 的利用率大幅提升，训练速度也快得多。

A2C 的损失函数由三部分组成。**策略损失**是带优势的策略梯度：

$$L_\mathrm{actor}(\theta)=-\mathbb{E}\left[\log\pi_\theta(a_t|s_t)\cdot\hat{A}_t\right]$$

**价值损失**是 Critic 的时序差分误差平方：

$$L_{\mathrm{critic}}(\phi)=\mathbb{E}\left[\left(r_{t+1}+\gamma V_{\phi}(s_{t+1})-V_{\phi}(s_{t})\right)^2\right]$$

**熵正则项**鼓励探索，防止策略过早坍缩到确定性：

$$L_{\mathrm{entropy}}(\theta)=-\mathbb{E}\left[\mathcal{H}\left(\pi_\theta(\cdot|s_t)\right)\right]$$

把三者加权求和，得到 A2C 的完整损失：

$$L(\theta,\phi)=L_\mathrm{actor}(\theta)+c_1L_\mathrm{critic}(\phi)+c_2L_\mathrm{entropy}(\theta)$$

其中$c_1$通常取 0.5，$c_2$通常取0.01，熵项系数不宜太大，否则策略会一直保持随机，学不到确定的行为。

A2C 的优点是简单、稳定、易于实现。它的同步更新让所有并行环境共享同一份策略，训练过程清晰可控。缺点是样本效率不高，每次更新都要重新采样，数据用完就扔。

### A3C算法

A3C，全称 Asynchronous Advantage Actor-Critic，是 A2C 的异步版本。它的核心思想是：**不再让所有环境同步等待，而是让多个线程各自独立地采样、计算梯度、更新全局参数**。每个线程有自己的环境和策略副本，它们异步地向全局参数推送梯度，不需要等待其他线程。

A3C 的动机来自一个朴素的观察：同步更新时，最快的环境要等最慢的环境，GPU 利用率低。异步更新打破了这种等待，每个线程按照自己的节奏跑，谁先跑完谁先更新。这让训练速度大幅提升，尤其是在 CPU 多核的环境下。

A3C 的几个关键设计
- **本地副本**让每个线程用独立的策略采样，不会互相干扰；
- **全局参数**让所有线程共享学习成果；
- **异步更新**让线程之间不需要同步等待。

A3C 的缺点是**梯度陈旧**。一个线程在更新全局参数时，可能其他线程已经更新过了，导致它计算梯度时用的策略已经过时。这个“参数滞后”会让训练不稳定，尤其是在线程数量多的时候。另外一个缺点是**可复现性差**，因为线程的调度顺序不确定，训练结果每次都不一样。
