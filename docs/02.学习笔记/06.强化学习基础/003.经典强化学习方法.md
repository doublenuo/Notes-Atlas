# 求解MDP最优策略

前面我们定义了 MDP 的五元组，也推导了贝尔曼期望方程和贝尔曼最优方程。但方程本身不会告诉你最优策略长什么样，它只是一个条件——满足这个条件的策略就是最优的。真正要找到最优策略，还需要一套求解方法。

## 动态规划算法

动态规划（Dynamic Programming）是求解 MDP 最优策略最经典的方法。它的基本思想是将待求解问题分解成若干个子问题，先求解子问题，然后从这些子问题的解得到目标问题的解。动态规划会保存已解决的子问题的答案，在求解目标问题的过程中需要时直接利用，避免重复计算。

要把动态规划用在 MDP 上，需要两个前提条件。第一，**环境模型完全已知**，即状态转移概率$P(s^{\prime}|s,a)$和奖励函数$R(s,a)$都是已知的，这是一个白盒环境，不需要通过智能体和环境的大量交互来学习；第二，**问题具有最优子结构和重叠子问题**，MDP 恰好满足这两个性质：贝尔曼方程本身就是递归结构，同一个状态会被多次访问，子问题的解可以复用。

基于动态规划的强化学习算法主要有两种：策略迭代和价值迭代。策略迭代由策略评估和策略提升两部分交替进行，策略评估使用贝尔曼期望方程来得到状态价值函数；而价值迭代直接使用贝尔曼最优方程来进行动态规划，得到最终的最优状态价值。两者的核心区别在于：策略迭代先让价值函数完全收敛，再更新策略；价值迭代则不等价值函数完全收敛，每一步都直接朝着最优价值逼近。这两种算法通常只适用于有限马尔可夫决策过程，即**状态空间和动作空间是离散且有限的**。

> 本节动态规划算法使用GridWorld环境作为演示，同时使用策略迭代和价值迭代来求解GridWorld环境的最优策略。

GridWorld环境是一个有限确定性马尔可夫决策过程，智能体从左上角起点 $(0,0)$ 出发，目标是到达右下角终点 $(4,4)$，状态为 $25$ 个格子，动作包括上、下、左、右四种；网格中设置了非对称障碍格 $(0,1)、(1,2)、(2,0)、(2,3)、(3,3)$，智能体撞墙或撞障碍时原地不动，每走一步获得 $-1$ 奖励，到达终点即回合终止，折扣因子取 $0.9$，因此最优策略等价于在避开障碍的前提下用最少步数到达终点；

由于状态和动作空间小、转移与奖励完全已知，该环境非常适合用动态规划中的策略迭代和价值迭代求解，并能通过价值函数热力图和策略箭头图直观展示收敛过程与最优路径。

![动态规划算法](https://static.lovetulin.cn/images/2026/11/09/c9d28a89-ad44-4b3d-bc5c-7960175bd150-1793965296-vzwx-1794221567-bpVQ.webp)

我们现在来编写这个环境的代码以及一些后续绘图使用的函数：

```python
class GridWorld:
    def __init__(self, n=5, gamma=0.9, theta=1e-10,
                 start=(0, 0), goal=(4, 4),
                 obstacles=((0, 1), (1, 2), (2, 0), (2, 3), (3, 3))):
        self.N = n
        self.GAMMA = gamma
        self.THETA = theta
        self.START = start
        self.GOAL = goal
        self.OBSTACLES = set(obstacles)
        self.ACTIONS = [(-1, 0), (1, 0), (0, -1), (0, 1)]
        self.ARROWS = ['↑', '↓', '←', '→']
        self.ACTION_NAMES = ['上', '下', '左', '右']
        self.n_states = n * n
        self.n_actions = len(self.ACTIONS)
        self.TERM_S = self.rc2s(*goal)
        self.OBST_S = {self.rc2s(*o) for o in self.OBSTACLES}

    def rc2s(self, r, c): return r * self.N + c
    def s2rc(self, s): return divmod(s, self.N)
    def is_terminal(self, s): return s == self.TERM_S
    def is_obstacle(self, s): return s in self.OBST_S
    def is_decision_state(self, s):
        return not self.is_terminal(s) and not self.is_obstacle(s)

    def step(self, s, a):
        r, c = self.s2rc(s)
        dr, dc = self.ACTIONS[a]
        nr, nc = r + dr, c + dc
        if not (0 <= nr < self.N and 0 <= nc < self.N) or self.rc2s(nr, nc) in self.OBST_S:
            nr, nc = r, c
        ns = self.rc2s(nr, nc)
        return ns, -1.0, (ns == self.TERM_S)

    def q_value(self, V, s, a):
        ns, r, done = self.step(s, a)
        return r + (0.0 if done else self.GAMMA * V[ns])

    def best_action(self, V, s, eps=1e-9):
        qs = [self.q_value(V, s, a) for a in range(self.n_actions)]
        max_q = max(qs)
        candidates = [a for a in range(self.n_actions) if qs[a] >= max_q - eps]
        def dist_to_goal(a):
            ns, _, done = self.step(s, a)
            if done:
                return -1
            nr, nc = self.s2rc(ns)
            return abs(nr - self.GOAL[0]) + abs(nc - self.GOAL[1])
        return min(candidates, key=lambda a: (dist_to_goal(a), a))

    # ---------------- 可视化 ----------------
    def _base_grid(self, ax):
        for r in range(self.N):
            for c in range(self.N):
                if (r, c) in self.OBSTACLES:
                    ax.add_patch(plt.Rectangle((c - 0.5, r - 0.5), 1, 1, color='black'))
                else:
                    ax.add_patch(plt.Rectangle((c - 0.5, r - 0.5), 1, 1,
                                               fill=False, edgecolor='#999999', linewidth=1))
        ax.set_xlim(-0.5, self.N - 0.5)
        ax.set_ylim(self.N - 0.5, -0.5)
        ax.set_xticks(range(self.N))
        ax.set_yticks(range(self.N))
        ax.set_aspect('equal')

    def draw_layout(self, ax, title='Grid World'):
        ax.set_xlim(-0.5, self.N - 0.5)
        ax.set_ylim(self.N - 0.5, -0.5)
        for r in range(self.N):
            for c in range(self.N):
                if (r, c) in self.OBSTACLES:
                    ax.add_patch(plt.Rectangle((c - 0.5, r - 0.5), 1, 1, color='black'))
                elif (r, c) == self.START:
                    ax.add_patch(plt.Rectangle((c - 0.5, r - 0.5), 1, 1, color='#b7e4c7'))
                    ax.text(c, r, 'S', ha='center', va='center', fontsize=18, fontweight='bold')
                elif (r, c) == self.GOAL:
                    ax.add_patch(plt.Rectangle((c - 0.5, r - 0.5), 1, 1, color='#ffd166'))
                    ax.text(c, r, 'G', ha='center', va='center', fontsize=18, fontweight='bold')
                else:
                    ax.add_patch(plt.Rectangle((c - 0.5, r - 0.5), 1, 1,
                                               fill=False, edgecolor='gray'))
        ax.set_xticks(range(self.N))
        ax.set_yticks(range(self.N))
        ax.set_aspect('equal')
        ax.set_title(title)

    def draw_value(self, ax, V, title):
        Vg = V.reshape(self.N, self.N).astype(float).copy()
        for o in self.OBST_S:
            Vg[self.s2rc(o)] = np.nan
        im = ax.imshow(Vg, cmap='viridis')
        for r in range(self.N):
            for c in range(self.N):
                if (r, c) in self.OBSTACLES:
                    ax.add_patch(plt.Rectangle((c - 0.5, r - 0.5), 1, 1, color='black'))
                else:
                    ax.text(c, r, f'{Vg[r, c]:.2f}', ha='center', va='center',
                            color='white', fontsize=8)
        plt.colorbar(im, ax=ax, fraction=0.046)
        ax.set_title(title)

    def draw_policy(self, ax, policy, title):
        self._base_grid(ax)
        for r in range(self.N):
            for c in range(self.N):
                if (r, c) in self.OBSTACLES:
                    continue
                s = self.rc2s(r, c)
                if s == self.TERM_S:
                    ax.add_patch(plt.Rectangle((c - 0.5, r - 0.5), 1, 1, color='#ffd166'))
                    ax.text(c, r, 'G', ha='center', va='center', fontsize=14, fontweight='bold')
                else:
                    ax.text(c, r, self.ARROWS[policy[s]], ha='center', va='center', fontsize=22)
        ax.set_title(title)

    def save_round_figure(self, outer, V, policy, n_scan, n_chg, fname=None):
        fig, axes = plt.subplots(1, 2, figsize=(10, 4.5))
        self.draw_value(axes[0], V, f'Round {outer} - V after evaluation ({n_scan} scans)')
        self.draw_policy(axes[1], policy, f'Round {outer} - Policy after improvement ({n_chg} changes)')
        plt.tight_layout()
        fname = fname or f'pi_round_{outer:02d}.png'
        plt.savefig(fname, dpi=120)
        plt.close(fig)
        print(f"    [已保存图片] {fname}")
```

### 策略迭代

策略迭代的核心思想是：**先评估当前策略有多好，然后基于评估结果改进策略，反复交替，直到策略不再变化**。
- **策略评估**：给定当前策略$\pi$，计算它的状态价值函数$V^{\pi}(s)$，这是一个动态规划过程，用贝尔曼期望方程迭代更新，直到价值函数收敛；
- **策略提升**：基于计算出的价值函数$V^{\pi}(s)$，在每个状态都选择能带来最大期望回报的动作，从而生成一个更优的新策略$\pi^{\prime}$.

$$
\pi^{\prime}=\arg\max_{a}\sum_{s^{\prime}}P(s^{\prime}|s,a)[R(s,a,s^{\prime})+\gamma V^{\pi}(s^{\prime})]
$$

如果新策略$\pi^{\prime}$和旧策略$\pi$在所有状态上选择的动作都相同，说明策略已经收敛，此时的策略就是最优策略。策略迭代的每一步都保证了策略不会变差。策略提升定理告诉我们，基于当前价值函数进行贪婪改进得到的新策略，其价值函数一定不低于旧策略，再加上有限 MDP 中策略数量有限，所以策略迭代一定在有限步内收敛到最优策略。

我们现在来看一下策略迭代算法的代码实现过程：


```python
class PolicyIteration:
    def __init__(self, env, verbose=True, save_round_figures=True):
        self.env = env
        self.verbose = verbose
        self.save_round_figures = save_round_figures
        self.policy = np.zeros(env.n_states, dtype=int)
        self.V = np.zeros(env.n_states)
        self.history = []
        self.outer = 0
        self.total_scan = 0

    def evaluate(self):
        env = self.env
        scan, deltas = 0, []
        while True:
            scan += 1
            delta = 0.0
            for s in range(env.n_states):
                if not env.is_decision_state(s):
                    continue
                ns, r, done = env.step(s, self.policy[s])
                target = r + (0.0 if done else env.GAMMA * self.V[ns])
                delta = max(delta, abs(target - self.V[s]))
                self.V[s] = target
            deltas.append(delta)
            if self.verbose:
                print(f"    评估扫描 #{scan:2d}: delta = {delta:.3e}")
            if delta < env.THETA:
                return scan, deltas

    def improve(self):
        env = self.env
        stable, changes = True, []
        for s in range(env.n_states):
            if not env.is_decision_state(s):
                continue
            best = env.best_action(self.V, s)
            if best != self.policy[s]:
                changes.append((s, self.policy[s], best))
                self.policy[s] = best
                stable = False
        if self.verbose:
            if changes:
                print(f"    策略提升: 改动 {len(changes)} 个状态")
                for s, old, new in changes:
                    r, c = env.s2rc(s)
                    print(f"      ({r},{c}): {env.ACTION_NAMES[old]}({env.ARROWS[old]}) → "
                          f"{env.ACTION_NAMES[new]}({env.ARROWS[new]})")
            else:
                print("    策略提升: 无改动，策略已稳定 ✓")
        return stable, changes

    def run(self):
        env = self.env
        if self.verbose:
            print("=" * 70)
            print("策略迭代开始（初始策略：全部向上 ↑）")
            print("=" * 70)
        while True:
            self.outer += 1
            if self.verbose:
                print(f"\n┌── 外层第 {self.outer} 轮 ──────────────────────────────────────")
                print(f"│ [阶段 1] 策略评估")
            n_scan, deltas = self.evaluate()
            self.total_scan += n_scan
            if self.verbose:
                print(f"│ [阶段 2] 策略提升")
            stable, changes = self.improve()
            self.history.append((self.outer, n_scan, deltas[-1], len(changes)))
            if self.save_round_figures:
                env.save_round_figure(self.outer, self.V, self.policy, n_scan, len(changes))
            if self.verbose:
                print(f"└── 本轮结束：评估 {n_scan} 次扫描，提升改动 {len(changes)} 个状态")
            if stable:
                if self.verbose:
                    print(f"\n✓ 策略稳定，策略迭代在第 {self.outer} 轮收敛\n")
                break
        return self.policy, self.V, self.outer, self.total_scan, self.history
```


### 价值迭代

策略迭代有一个明显的缺点：每次策略评估都需要让价值函数完全收敛才进行策略提升，在状态和动作空间较大时，这个步骤的计算量会非常大。能不能降低策略评估的要求？答案是肯定的，这就是价值迭代。

价值迭代可以看作一种策略评估只进行了一轮更新的策略迭代算法，它直接利用贝尔曼最优方程进行迭代更新。价值迭代中不存在显式的策略，我们只维护一个状态价值函数。它的迭代公式是：

$$V_{k+1}(s)=\max_a\left[R(s,a)+\gamma\sum_{s^{\prime}}P(s^{\prime}|s,a)V_k(s^{\prime})\right]$$

等到$V_{k+1}$和$V_k$相同时，它就是贝尔曼最优方程的不动点，此时对应着最优状态价值函数$V^{*}$。然后利用

$$\pi(s)=\arg\max_a\left[R(s,a)+\gamma\sum_{s^{\prime}}P(s^{\prime}|s,a)V^*(s^{\prime})\right]$$

从中恢复出最优策略即可，接下来我们来准备一下价值迭代的代码：

```python
class ValueIteration:
    def __init__(self, env, verbose=False):
        self.env = env
        self.verbose = verbose
        self.V = np.zeros(env.n_states)
        self.policy = np.zeros(env.n_states, dtype=int)
        self.iters = 0

    def run(self):
        env = self.env
        while True:
            self.iters += 1
            delta = 0.0
            for s in range(env.n_states):
                if not env.is_decision_state(s):
                    continue
                best = max(env.q_value(self.V, s, a) for a in range(env.n_actions))
                delta = max(delta, abs(best - self.V[s]))
                self.V[s] = best
            if self.verbose:
                print(f"  价值迭代扫描 #{self.iters:2d}: delta = {delta:.3e}")
            if delta < env.THETA:
                break
        for s in range(env.n_states):
            if env.is_decision_state(s):
                self.policy[s] = env.best_action(self.V, s)
        return self.policy, self.V, self.iters
```

### 动态规划的局限

动态规划有一个致命的限制：**它要求环境模型完全已知**。而且动态规划的计算复杂度随状态空间增长而指数上升。当状态空间是几万个离散状态时，值迭代还能跑；当状态空间是连续的四十维关节空间时，动态规划就彻底无能为力了。

这也是为什么后来的强化学习走向了采样：既然写不出模型，那就用**交互来代替建模**。但动态规划的思想并没有消失——贝尔曼方程、值迭代的收敛性、策略提升定理，这些都是无模型算法的理论基础。Q-learning 在用采样估计贝尔曼最优方程，PPO 的 Critic 在用神经网络拟合价值函数，它们的灵魂都来自动态规划。

## 蒙特卡洛算法

**蒙特卡洛方法**（Monte-Carlo）也被称为统计模拟方法，是一种基于概率统计的数值计算方法。运用蒙特卡洛方法时，我们通常使用重复随机抽样，然后运用概率统计方法来从抽样结果中归纳出我们想求的目标的数值估计，核心是**用频率逼近概率、用样本均值逼近期望**。

一个最常见的例子是用蒙特卡洛方法来计算圆的面积，正方形内部随机产生若干个点，细数落在圆中点的个数，圆的面积与正方形面积之比就等于圆中点的个数与正方形中点的个数之比，如果我们随机产生的点的个数越多，计算得到圆的面积就越接近于真实的圆的面积。

![蒙特卡洛算法](https://static.lovetulin.cn/images/2026/11/09/9f9793cd-f214-4f06-a43c-7e87b984ead6-1793966531-yXYH-1794221567-WgFT.webp)

蒙特卡洛的思想就是用策略在 MDP 上采样很多条序列，计算从这个状态出发的回报再求其期望就可以了。

$$V^\pi(s)=\mathbb{E}_\pi[G_t|S_t=s]\approx\frac{1}{N}\sum_{i=1}^NG_t^{(i)}$$

多次访问同一个状态后，这些完整回报的平均值会逼近$V^{\pi}(s)$，实际写程序时，不一定保存所有历史回报再求平均，也可以让旧值向本次回报移动一步。

$$V(s)\leftarrow V(s)+\alpha\left[G_t-V(s)\right]$$

其中$\alpha$是学习率，控制每次更新的幅度。它和保存所有回报再求平均在$\alpha=\frac{1}{N}$是等价的，但增量形式更灵活，可以处理非平稳环境和持续型任务。

这个增量形式的好处是，你不需要保存每条轨迹的完整回报，只需要维护一个当前的估计值，每来一条新样本就把它往新样本的方向推一点。

蒙特卡洛有一个前提：**它必须等到一整条轨迹结束后，才能计算$G_t$**.这让它天然适合回合制任务，比如一局游戏、一次抓取、一个从起点到终点的回合，但持续型任务里没有终止状态，蒙特卡洛就没法用了。具体实现上蒙特卡洛有两种实现方式：
- **首次访问蒙特卡洛**：只在一局中第一次访问某状态时，用该次的回报更新该状态的价值；
- **每次访问蒙特卡洛**：在一局中每次访问该状态时都更新一次。

蒙特卡洛的优点是**无偏**，它用真实的累积回报$G_t$作为更新目标，不依赖任何对未来的估计，所以它的价值估计不会因为其他状态的估计不准而被带偏。但代价是**方差大**，同一策略跑两次，同一起点的回报可能差很多，梯度噪声大，收敛慢，而且它必须等轨迹结束才能更新，不能在线学习，样本效率低。

## 时序差分算法

你不可能用一个公式精确描述状态转移概率，模型未知，动态规划就无法使用。智能体只能换一条路，与环境交互，从采样到的数据中学习。这类方法统称为**无模型的强化学习**（model-free reinforcement learning）。

它不需要事先知道奖励函数和状态转移函数，直接使用交互过程中采样到的数据来估计价值、改进策略。时序差分算法就是无模型强化学习中最核心的一类方法。

> 本节动态规划算法使用冰湖环境作为演示，同时使用Q-learning和Sarsa来求解冰湖环境的最优策略。

冰湖是 OpenAI Gym 库中的一个环境，它也是是一个GridWorld，大小为$4\times 4$，每一个方格是一个状态，智能体起点状态$S$在左上角，目标状态$G$在在右下角，中间还有若干冰洞$H$，在每一个状态都可以采取上、下、左、右 4 个动作。由于智能体在冰面行走，因此每次行走都有一定的概率滑行到附近的其它状态，并且到达冰洞或目标状态时行走会提前结束，每一步行走的奖励是 $0$，到达目标的奖励是$1$.

### 时序差分方法

时序差分是一种估计策略价值函数的方法，它同时借鉴了蒙特卡洛和动态规划的思想。和蒙特卡洛一样，它不需要环境模型，可以从样本数据中学习；和动态规划一样，它利用贝尔曼方程的递归结构，用后续状态的价值估计来更新当前状态的价值估。

先回顾蒙特卡洛的增量更新方式：

$$
V(S_t)\leftarrow V(S_t)+\alpha [G_t-V(S_t)]
$$

蒙特卡洛必须等整个序列结束后才能计算$G_t$，因为$G_t$是整条轨迹的累积回报。但贝尔曼方程告诉我们，回报本身有递归结构：

$$
G_t=R_{t+1}+\gamma G_{t+1}
$$

把$G_{t+1}$替换成它的估计值$V(S_{t+1})$,就得到了时序差分的更新目标:

$$
V(S_t)\leftarrow V(S_t)+\alpha [R_{t+1}+\gamma V(S_{t+1})-V(S_t)]
$$

括号里的$R_{t+1}+\gamma V(S_{t+1})-V(S_t)$被称为**时序差分误差**(TD Error)，它衡量的是“当前对$V(S_t)$的估计”与“基于下一步实际奖励和下一步价值估计得到的更新目标”之间的差距。蒙特卡洛用$G_t$作为更新目标，时序差分用$R_{t+1}+\gamma V(S_{t+1})-V(S_t)$作为更新目标。区别在于：蒙特卡洛要等到回合结束才能算$G_t$，时序差分**每走一步就能更新一次**。

这就是时序差分的核心优势：**在线学习**。智能体不需要等一局游戏打完，每执行一个动作、观察到奖励和下一状态，就可以立刻修正当前的价值估计。对于持续型任务（机器人永远在走，没有“结束”这个概念），蒙特卡洛根本没法用，时序差分却可以一直更新下去。

### Sarsa 算法

有了时序差分来估计价值，接下来要解决策略提升的问题。在模型未知的情况下，我们可以直接用时序差分来估计动作价值函数$Q(s,a)$，然后用贪婪策略选取$Q$值最大的动作。这就构成了一个完整的强化学习算法：用$\epsilon$-greedy策略与环境交互，根据交互数据更新$Q$，再根据新的$Q$改进策略。

Sarsa 的名字来自它每次更新所用到的一串变量：$(S_t,A_t,R_{t+1},S_{t+1},A_{t+1})$，它的更新公式是:

$$Q(S_t,A_t)\leftarrow Q(S_t,A_t)+\alpha\left[R_{t+1}+\gamma Q(S_{t+1},A_{t+1})-Q(S_t,A_t)\right]$$

注意，这里的$A_{t+1}$是**实际在下一步执行的那个动作**，而不是下一步最优的动作，Sarsa 用当前正在执行的$\epsilon$-greedy策略来选择$A_{t+1}$，也用同一个策略来估计$Q(S_{t+1},A_{t+1})$，这意味着**行为策略和目标策略是同一个**，Sarsa 是**在线策略**（on-policy）算法。

在线策略的含义可以用一个比喻来理解：你用水龙头洗手，水一直在流，洗过的水直接排走，不会存起来再用。Sarsa 每走一步，就用这一步的数据更新$Q$，更新完之后那步数据就过期了，因为策略已经变了。

### Q-learning算法

Q-learning 和 Sarsa 的更新公式只差一个符号：

$$Q(S_t,A_t)\leftarrow Q(S_t,A_t)+\alpha\left[R_{t+1}+\gamma\max_aQ(S_{t+1},a)-Q(S_t,A_t)\right]$$

Sarsa 用的是$Q(S_{t+1},A_{t+1})$，即实际选出的那个动作的价值，Q-learning用的是$\max_{a}Q(S_{t+1},a)$，,a)，即下一步最优动作的价值，不管实际会选什么。

这个差别看似微小，却改变了算法的本质。Q-learning 的更新目标里不包含当前策略的探索行为，它假设下一步会选最优动作，而不是$\epsilon$-greedy策略随机选出来的动作。因此，行为策略和目标策略可以是不同的，Q-learning 是离线策略（off-policy）算法。

离线策略的比喻是用脸盆接水洗手：采样得到的数据被存起来，可以反复用来更新，因为目标策略不依赖于当前的行为策略，Q-learning 学到的始终是最优策略的价值，不管它当前在用什么策略探索。

### 多步Sarsa和期望Sarsa

Sarsa 和 Q-learning 都是一步时序差分方法：它们只用了一步奖励和一步价值估计来构造更新目标。但蒙特卡洛用的是整条轨迹的回报，理论上信息更充分。介于一步和无穷步之间的，是**多步时序差分**。

多步 Sarsa 的更新目标是：

$$G_t^{(n)}=R_{t+1}+\gamma R_{t+2}+\gamma^2R_{t+3}+\cdots+\gamma^{n-1}R_{t+n}+\gamma^nQ(S_{t+n},A_{t+n})$$

当$n=1$时退化为标准 Sarsa,当$n\to \infty$时退化为蒙特卡洛，多步 Sarsa 综合了更多后继状态的影响，状态估计偏差更小，通常收敛更快，代价是需要缓存最近$n$步的数据，实现上稍微复杂一些。

期望 Sarsa（Expected Sarsa）是另一种变体。Sarsa 用实际选出的$A_{t+1}$来估计下一步价值，期望 Sarsa 则用策略在$S_{t+1}$上所有可能动作的期望价值。

$$Q(S_t,A_t)\leftarrow Q(S_t,A_t)+\alpha\left[R_{t+1}+\gamma\sum_a\pi(a|S_{t+1})Q(S_{t+1},a)-Q(S_t,A_t)\right]$$

期望 Sarsa 比标准 Sarsa 方差更小，因为它在动作维度上做了平均，而不是依赖一次随机的采样。同时，它仍然是在线策略算法，因为它用当前策略的概率分布来计算期望。Q-learning 可以看作是期望 Sarsa 的一个极端版本：如果把期望 Sarsa 里的策略$\pi$换成贪婪策略，期望 Sarsa 就变成了 Q-learning。

## 从时序差分到现代算法

Sarsa 和 Q-learning 是表格型方法：它们用一张二维表来存储每个状态动作对的 Q 值。当状态空间是几十个网格时，表格够用；当状态空间是机器人 40 维的连续关节向量时，表格就完全不够用了。解决方法是把 Q 表换成神经网络输入状态（和动作），输出 Q 值。这就是 DQN 的核心思想。

但更深层的影响是时序差分的核心思想，**用一步奖励 + 下一步价值估计来构造更新目标**，这是几乎所有现代强化学习算法的基石。
- PPO 的 Critic 网络用时序差分误差来训练价值函数；
- SAC 的 Q 网络用时序差分误差来更新动作价值；
- A3C 的并行 actor 用多步时序差分来估计优势。
